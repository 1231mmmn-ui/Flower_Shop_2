**この文書は、⓪感情設計書と同じ高さに置きます。**

## この文書を読む前に ── 二つの戒め

**この二つは、以下のすべての章に優先します。**  
設計に迷ったとき、実装で手が滑りそうなとき、ここに戻ります。

### 一．花の数を増やすことより、一輪一輪を好きになれることを優先してください

```
182種は「仕様」であって、「ゴール」ではありません。
```

| | |
|---|---|
| **成功** | 50種しかなくても、「あ、この花好き」と思えた |
| **失敗** | 182種あっても、全部が同じように見えた |

**「182種類作ること」が目的になった時点で、このゲームは失敗しています。**

だから、こう決めておきます。

```
1種を足すときの条件

  □ この花には、他の花と違うところがあるか
  □ この花を選びたくなる人が、思い浮かぶか
  □ この一輪だけで、絵として成立するか

  ひとつでも「いいえ」なら、その花は足しません。
  数が足りなくても、足しません。
```

**枠が182あっても、埋める義務はありません。**

### 二．知識を、覚えさせない

図鑑には、花言葉・旬・市場価格・香り・日もち・相性が全部あります。  
**でも、プレイヤーは勉強しに来たのではありません。**

```
×   「覚えてね」
○   「気がついたら、覚えていた」
```

理想は、こうです。

```
ガーベラを10回使う  →  そのうち「希望」を覚えている
```

**覚えさせる仕掛けを作りません。**

| 作らないもの | なぜ |
|---|---|
| 花言葉のクイズ・テスト | 勉強になる |
| 「この花の花言葉は？」という確認 | 試されている |
| 覚えた数のカウント | 数えた時点で勉強 |
| 「今日の花の豆知識」の押しつけ | 読まされている |
| 未読の印、バッジ、赤い点 | 消化させられている |

### 図鑑は、辞典ではなくアルバムです

```
辞典    引くもの。正確で、網羅的で、冷たい
アルバム 見返すもの。ぬけがあって、順不同で、あたたかい
```

**このゲームの図鑑は、アルバムです。**

だから、

- **♡お気に入り**が、開いた最初の画面にある（→ 3-2章）
- **「出会った日」**の欄がある。日付と、お客さまと、その一言（→ 3章）
- **絵が大きい。文字が少ない**（★と絵で分かることは書かない）
- **索引・検索・並べ替えを、前に出さない**
- **埋まっていない欄を、欠けているように見せない**

> 図鑑を開いた人が最初に見るのは、
> **五十音順の一覧ではなく、自分が好きになった花**です。

### 順番だけは、最後まで守ります

```
覚えさせる  →  好きになる     ×  逆です
好きになる  →  覚えていた     ○
```

## 0. 順番を、逆にしていました

これまで私は、こう積み上げていました。

```
前（まちがい）   人生 → お客さま → 感情 → 花
                                        ↑ 花が最後に来ている
```

**花が、想いを運ぶための道具になっていました。**

正しくはこうです。

```
後（これから）   花を知る → 花を好きになる → その花で、誰かの想いを届ける
```

### 割合

```
花    60%   ← 主役であり、入口
人生  40%   ← 花に意味を与えるもの
```

**花が6割です。** 人生の話が、花の話を上回ってはいけません。

このゲームは **「人生を知るゲーム」ではありません。**  
**「花を知り、花を好きになり、その花で誰かの想いを届けるゲーム」**です。

## 1. 花から人へ、という道

いただいた流れを、そのまま設計の中心にします。

```
「ガーベラって可愛い」            ← 入口。見た目だけ。理屈がない
        ↓  詳細を見る
「希望、っていう花言葉なんだ」      ← 知る
        ↓
「そういえば、元気になってほしい友達がいた」  ← 思い出す
        ↓
「この花にしよう」                ← 決める
```

**入口が「かわいい」であることが大事です。** 誰かの話から始まっていません。

### 道は、二本あります

| 向き | 道すじ | 割合 | いまの設計 |
|---|---|---|---|
| **花 → 人** | かわいい → 花言葉 → あの人を思い出す → 決める | **60%** | **抜けていた** |
| 人 → 花 | メモを読む → 合う花を探す → 見つける | 40% | これだけ作っていた |

前の設計（エプロンのメモ、呼応表）は、**すべて「人 → 花」**でした。  
それは40%ぶんの設計です。**60%のほうが、まだ作られていません。**

### 「花 → 人」の道を通すために、変えること

| # | 変えること | 理由 |
|---|---|---|
| 1 | **開店前に、棚を見る時間を作る** | お客さまが来る前に、花と二人きりになる時間が要る |
| 2 | **花の詳細は、誰の話も抱えずに見られる** | 「かわいい」だけで開いてよい |
| 3 | **図鑑を、おまけから本体に上げる** | ここが武器（→3章） |
| 4 | **図鑑から、一輪の画面に入れる** | 買わなくても、花を眺められる |
| 5 | **花言葉は、値札の時点で読める** | 知るのに、買う必要はない |

**1番が新しい要素です。** 朝、市場から帰ってきて、扉を開けるまでのあいだ。  
お客さまはまだ来ません。**そこにあるのは花だけ**です。

```
朝、市場から帰る  →  棚に並べる  →  ★見て回る  →  扉を開ける  →  お客さまが来る
                                   ↑ ここが新しい。ここが60%の入口
```

この時間には、**目的がありません。** 注文もメモもなく、ただ花を見ます。  
目的がないからこそ、「かわいい」だけで立ち止まれます。

## 2. 花は、182種に「対応」する。実装は50種から

21種では足りない、というのはそのとおりです。**21種は、季節ごとに5種しかない**ということです。

ただし、**第一弾を108種にするのは、こちらの見立て違いでした。**

```
前（まちがい）   第一弾 108種  →  ゆくゆく 182種
後（これから）   設計   182種対応  →  第一弾 50種実装  →  更新で増える
```

### なぜ、この順番なのか

ご指摘のとおりです。**108枚を、写真のようなリアルさで描くのは相当な仕事**です。  
描き終わるまで遊べない、という状態がいちばん危ない。

```
数を先に作る   →  絵が薄くなる。または、いつまでも遊べない
器を先に作る   →  50種で遊べる。そのあと、いくらでも増やせる
```

**器（データ構造・図鑑・季節の割り当て・図鑑の分母）は、最初から182種ぶん作ります。**  
あとから花を足すときに、**コードには一行も触りません。**

### 第一弾の50種を、どう選ぶか

**「季節がひと巡りできること」**だけを条件にします。

## 3. 図鑑が、このゲームのいちばんの武器

ここは完全に同意です。**図鑑を、⑨番目の画面から、本体に上げます。**

```
前   図鑑 = 集めた記録を見るところ（おまけ）
後   図鑑 = 花を知るところ（このゲームの武器）
```

遊んでいるうちに、**本当に花に詳しくなる。** これが他のゲームにないところです。

### 図鑑の1ページに書くこと

```
┌────────────────────────────────────────┐

### 項目の一覧

| 項目 | 中身 | なぜ入れるか |
|---|---|---|
| **♡ お気に入り** | **押すだけ。理由も条件もなし** | **好きな花を、自分で決められる**（→ 3-2章） |
| 名前 | 流通名・学名・和名 | 花屋で言える名前を覚えられる |
| 絵 | 1024×1024 | 主役 |
| **花言葉** | 1〜3個 | **「花 → 人」の道の要** |
| 出回る時期 | 一年じゅう／◯月〜◯月 | 旬と分ける |
| 旬 | いちばんいい時期 | 季節を知る |
| **値段** | **★5段階＋相場＋やさしい一行** | **花屋の知識そのもの**（→5章） |
| 色 | 色玉を並べる（文字にしない） | 花は一色ではない、と知る |
| 香り | ★5段階＋香りの言葉 | 病室・食卓で効く |
| 日もち | ★5段階＋◯〜◯日 | 贈る先で変わる |
| **相性** | **花の絵を並べる**＋短い一行 | **見て覚えられる**（→7章） |
| 水あげ | 扱いのコツ（1行） | 本物の知識 |
| ひとこと | その花だけの一言 | 好きになる引き金 |
| 出会った日 | 日付・お客さま・その一言 | ⑫のアルバムと同じ行 |

**最後の欄で、図鑑とアルバムがつながります。**  
花のページから、その花を選んだ日のことを思い出せます。

### 読む量を、増やしすぎない

項目は多いのですが、**文字は少なくします。**

```
★で分かるもの   値段・香り・日もち
絵で分かるもの   色・相性
文字で読むもの   花言葉・水あげ・ひとこと（各1〜2行まで）
```

**★と絵で分かることは、文章にしません。** 図鑑は、読むものではなく**見るもの**です。

### アルバムの軸は「花」です

作り始める前に、決めておくべき問いがありました。

> **このアルバムは、花を思い出す場所なのか、人を思い出す場所なのか。**

**花です。ただし、花のページに人が沈殿します。**

### なぜ花を軸にするのか

**1. アルバムは、このゲーム自身の問いに答えられなければならない**

最後の問いは「好きな花は、できましたか？」であって、
「忘れられない人はいましたか？」ではありません。  
人を軸にしたアルバムは、この問いに答える場所になれません。

**2. 人を軸にすると、順番が逆に戻る**

一度「人生 → お客さま → 感情 → 花」と積んで、訂正しました。  
人を軸にしたアルバムは、**花をその人の属性にします。**
直した逆流が、アルバムだけで再発します。

**3. 人は使い切るが、花は溜まる**

```
人を軸  →  会った人が一列に並ぶ。増えるだけ。      ＝ 記録
花を軸  →  同じ花のページに、月をまたいで人が溜まる。 ＝ アルバム
```

ガーベラのページは、遊ぶほど厚くなります。人のページは、増えても厚くなりません。

### 「花を見に行ったら、人に会った」

望んでいる体験は、花を軸にしたほうが強く起きます。

```
人を軸   よしこさんを探して開く   →  ラナンキュラスが出てくる
         （知っている人を、確かめに行っただけ）

花を軸   ラナンキュラスを見に行く  →  よしこさんが出てくる
         （花を見に行ったら、人に会った）
```

**探しに行った人には、出会えません。** 出会いは、探していなかったから出会いです。

### 集める場所ではなく、思い出す場所

```
×   このアルバムは、何を集める場所か
○   このアルバムは、何を思い出す場所か
```

**花を集めることが目的ではありません。**  
花を見返したときに、**その花と出会った時間や人が、自然に思い出される**こと。  
それができれば、このアルバムは成立しています。

### 主と従の、上下は崩さない

```
主   花のページ    このゲームの軸
従   人のページ    日付順に見返すための、第二の入口
```

人のページを残すのは、**常連さんのページが来るたびに厚くなる**からです。  
花のページとは別の育ち方をします。**ただし、主従は最後まで入れ替えません。**

### 図鑑は、どう埋まるか（3段階）

```
まだ      影だけ。名前も出ない
棚で見た  絵・名前・花言葉・旬・値段  ← 見ただけで、ここまで開く
束に入れた  香り・日もち・相性・水あげ・ひとこと・出会った日 が加わる
```

**花言葉は「見ただけ」で読めます。** 買わないと読めない設計にはしません。  
知るのに、お金を払う必要はないからです。

```
図鑑    127 / 182
```

**この数字は出します。** ただし、**未収集を責める表示は作りません。**  
「あと55種！」とは書きません。書くのは、いま知っている数だけです。

♡ お気に入り

   ヒマワリ    ガーベラ    ブルースター
   〔 絵 〕    〔 絵 〕    〔 絵 〕

### 決めごと

| | |
|---|---|
| **押し方** | 図鑑のページの右上、♡ を押すだけ |
| **理由を聞かない** | 「なぜ好きか」を書かせません |
| **数の上限なし** | 1つでも、50でもよい |
| **ご褒美なし** | 何個入れても、何も起きません |
| **並び順** | 押した順。並べ替えは作りません |
| **図鑑の入口** | お気に入りが1つ以上あれば、**図鑑を開いた最初の画面**に出ます |

### なぜ、ご褒美を付けないのか

○  お気に入りに入れると、図鑑を開くたびに、その花が最初に出ます

ここが3つ埋まっていたら、このゲームは目的を果たしています。

> こちらからは一度も「好きな花を選んでください」と言いません。
> 言われて選んだものは、好きな花ではないからです。

## 5. 市場価格を、どう扱うか

入れます。**ただし、経営にはしません。**

```
入れる    知識としての値段
          「冬のバラは高い」「夏のヒマワリは安い」「なぜ高いのか」

入れない  売上・利益・原価・資金繰り・仕入れの判断
```

**プレイヤーは店員であって、経営者ではありません。**  
数字を管理させはじめた時点で、5つめの問い（優しく閉じられるか）に引っかかります。

### ★5つと、やさしい一行で

説明は、難しくしません。**★と、1行だけ**です。

```
冬のバラ

  ★★★★☆
  暖房を使って育てるため、冬は少し高くなります。
```

```
夏のヒマワリ

  ★☆☆☆☆
  夏がいちばん元気な時期なので、いちばん安く買えます。
```

```
シャクヤク（5月）

  ★★★☆☆
  咲くのは1年に3週間だけ。この時期にしか会えません。
```

### 書き方の決めごと

| | |
|---|---|
| **★は5段階** | ☆☆☆☆☆＝とても安い　★★★★★＝とても高い |
| **文章は1行** | 2行になったら、書きすぎです |
| **理由を1つだけ** | 「暖房」「旬」「輸入」「日もちしない」など、1つ |
| **専門用語を使わない** | 「相対取引」「セリ値」などは書きません |
| **数字は添えるだけ** | ★の下に小さく `1本 ¥250 〜 ¥600` |

**★を見れば分かる。1行を読めば、理由が分かる。それで終わりです。**

値段が動く理由を知ると、**現実の花屋で花が高い日にも、腹が立たなくなります。**  
そこまで届いたら十分で、それ以上は教えません。

### 値段は、市場とつながります

```
今朝の市場  →  今日の入荷と、今日の値段  →  棚の値札  →  図鑑の相場の帯
```

「今日はシャクヤクが安いな」が、遊んでいるうちに分かるようになります。

### 予算との関係

予算は、これまでどおり **「めやす」であって上限ではありません。**  
超えても叱られません。**値段は、悩みを深くするためにあります。**

## 6. 香り

★5段階と、香りの言葉をつけます。

| ★ | 言い方 | 例 |
|---|---|---|
| ☆☆☆☆☆ | ほとんどありません | ガーベラ、カーネーション、ケイトウ |
| ★★☆☆☆ | ほのかに香ります | チューリップ、トルコキキョウ |
| ★★★☆☆ | 近づくと香ります | バラ（品種による）、ストック |
| ★★★★☆ | よく香ります | フリージア、ヒヤシンス |
| ★★★★★ | 部屋じゅうに広がります | ユリ、スイセン |

香りの言葉も添えます。

```
フリージア   甘くて、少し粉っぽい。春のはじめの匂い
ユリ         濃い。渡したあと、部屋にしばらく残ります
ミモザ       ほとんどないけれど、葉に近づくと青い匂い
```

**香りは、贈る先で意味が変わります。** 病室では強すぎ、食卓ではごちそうになります。  
だから香りは、飾りではなく**判断の材料**です。

## 7. 相性は、絵で見せます

**点数（相性87点）も作らず、長い説明も書きません。** 出すのは**花の絵**です。

```
ガーベラ

  合わせて

   ┌──────┐  ┌──────┐  ┌──────┐
   │  絵   │  │  絵   │  │  絵   │
   └──────┘  └──────┘  └──────┘
    かすみ草     ユーカリ      バラ

  まるい花なので、線のある花と合わせると束が締まります。
```

### なぜ、絵なのか

**見て覚えられるからです。**

```
文字   「ガーベラは、かすみ草・ユーカリ・バラと相性がよい」
        → 読んで、忘れる

絵     〔ガーベラ〕〔かすみ草〕〔ユーカリ〕〔バラ〕が並んでいる
        → 束の姿が、そのまま頭に入る
```

これは実際の花屋で、店員が**花を手に取って並べて見せる**のと同じことです。  
説明ではなく、**見本**です。

### 決めごと

| | |
|---|---|
| **3つまで** | 4つ以上並べると、見本ではなく一覧になります |
| **絵は棚と同じもの** | 図鑑用の別の絵は作りません |
| **ふれると、その花のページへ** | 相性から相性へ、たどっていけます |
| **文章は1行** | なぜ合うか、だけ |
| **点数を出さない** | ★も付けません。**相性に上下はない**からです |

> **香り・値段・日もちには★を付けますが、相性には付けません。**
> 前の3つは測れるもの、相性は好みだからです。

### 相性の四つの見かた（1行を書くときの、こちらの手もと）

**この表はプレイヤーには見せません。** 1行を書く人が、迷わないためのものです。

| 見かた | 中身 | 例 |
|---|---|---|
| **かたち** | まるい／線／面／こまかい | まるい花（ガーベラ）＋線の花（デルフィニウム） |
| **高さ** | 主役／脇役／埋め／流れ | 主役1・脇役2・埋め1が、いちばん失敗しない |
| **色** | 近い色でまとめる／一点だけ差す | 黄色は強いので、少し離して置く |
| **水あげ** | 一緒の水に入れられるか | ガーベラは水を浅く。深水の花と分ける |

**4つめが本物の知識です。** 実際の花屋が、いちばん気をつけているところです。

```
ガーベラ  ×  深水の花
          → 一緒の花瓶に入れると、ガーベラの茎が先に傷みます
```

これを知ると、**現実の花屋で花を買ったときにも役に立ちます。**  
そこまで届いたら、このゲームは成功だと思います。

**ただし、これも1行にします。** 「ガーベラは水を浅く」だけで十分です。

## 9. 21種 → 108種 へ、どう増やすか

### 器を先に、絵はあとから

```

2. 50種ぶんの絵を描く         ← あと29枚。ここまでで遊べる
3. 季節の更新で、絵を足す      ← 1回に5〜10枚ずつ
```

**2と3のあいだで、コードは一行も変わりません。**

### 絵について

いまの絵は、`tools/placeholder_art/` で描いています。

いま   頭の形   13種類（デイジー／バラ／フリル／ラッパ／カップ／
                        チューリップ／ベル／星／スイセン／ドーム／
                        スプレー／穂／ユーカリ）
       花       21種
```

**第一弾の50種まで、どれだけ形を足すか**を数えました。

| 段 | 何を足すか | 何枚 | 到達 |
|---|---|---|---|
| **1** | **いまの13の形で描ける花**（色と大きさを変えるだけ） | **+18枚** | **39種** |
| **2** | **形を4つ足す**（房・実もの・小花の集まり・穂すすき） | **+11枚** | **50種** ← 第一弾 |
| 3 | 形を6つ足す（枝もの、キク科の重ね、ラン科） | +58枚 | 108種 |
| 4 | 形を数種と、色ちがい | +74枚 | 182種 |

**第一弾は、新しい形を4つ足すだけで届きます。** ここが現実的な区切りです。

### データについて

182種を1ファイルには書けません。**季節ごとにファイルを分けます。**

```

**1種を足すのに、コードは触りません。** 該当のファイルに1つ書き足すだけです。

### 絵がまだ無い花は、どう扱うか

**器は182種ぶんありますが、絵は50枚しかありません。** ここを間違えないようにします。

```
絵がある花    棚に並ぶ。図鑑に載る。分母に数える
絵がない花    どこにも出ない。分母にも数えない
```

**「準備中」「Coming Soon」は出しません。** 無いものは、無いままにします。  
花が増えるのは、**更新が来たときだけ**です。そのほうが、増えたときに嬉しいからです。

## 13. 順番だけ、間違えないように

```
花を知る  →  花を好きになる  →  その花で、誰かの想いを届ける
  ↑ ここが入口
```

**この順番を逆にすると、花が道具になります。**

「花」と「人の想い」は、どちらも同じくらい大切です。  
**ただし、先に来るのは花です。**

判断に迷ったら、この一文に戻ります。

> **「これは、プレイヤーが花を好きになることに、つながるか」**

つながらないなら、どんなに物語が良くても、入れません。

## 最後に

この文書に書いたことのうち、**忘れてはいけないのは冒頭の二つだけ**です。

```
一．花の数を増やすことより、一輪一輪を好きになれることを優先する
二．覚えさせない。好きになった結果、覚えていた
```

182種の表も、図鑑の項目も、★の段階も、**この二つを助けるための道具**です。  
道具が目的になったら、そこで止めて、ここに戻ります。

> **好きな花は、できましたか？**
