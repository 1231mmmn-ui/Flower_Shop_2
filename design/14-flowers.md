# ⑭ 花の設計書 ── 花を知り、花を好きになる

**この文書は、⓪感情設計書と同じ高さに置きます。**

---

## 0. 順番を、逆にしていました

これまで私は、こう積み上げていました。

```
前（まちがい）   人生 → お客さま → 感情 → 花
                                        ↑ 花が最後に来ている
```

**花が、想いを運ぶための道具になっていました。**

正しくはこうです。

```
後（これから）   花を知る → 花を好きになる → その花で、誰かの想いを届ける
```

### 割合

```
花    60%   ← 主役であり、入口
人生  40%   ← 花に意味を与えるもの
```

**花が6割です。** 人生の話が、花の話を上回ってはいけません。

このゲームは **「人生を知るゲーム」ではありません。**  
**「花を知り、花を好きになり、その花で誰かの想いを届けるゲーム」**です。

## 1. 花から人へ、という道

いただいた流れを、そのまま設計の中心にします。

```
「ガーベラって可愛い」            ← 入口。見た目だけ。理屈がない
        ↓  詳細を見る
「希望、っていう花言葉なんだ」      ← 知る
        ↓
「そういえば、元気になってほしい友達がいた」  ← 思い出す
        ↓
「この花にしよう」                ← 決める
```

**入口が「かわいい」であることが大事です。** 誰かの話から始まっていません。

### 道は、二本あります

| 向き | 道すじ | 割合 | いまの設計 |
|---|---|---|---|
| **花 → 人** | かわいい → 花言葉 → あの人を思い出す → 決める | **60%** | **抜けていた** |
| 人 → 花 | メモを読む → 合う花を探す → 見つける | 40% | これだけ作っていた |

前の設計（エプロンのメモ、呼応表）は、**すべて「人 → 花」**でした。  
それは40%ぶんの設計です。**60%のほうが、まだ作られていません。**

### 「花 → 人」の道を通すために、変えること

| # | 変えること | 理由 |
|---|---|---|
| 1 | **開店前に、棚を見る時間を作る** | お客さまが来る前に、花と二人きりになる時間が要る |
| 2 | **花の詳細は、誰の話も抱えずに見られる** | 「かわいい」だけで開いてよい |
| 3 | **図鑑を、おまけから本体に上げる** | ここが武器（→3章） |
| 4 | **図鑑から、一輪の画面に入れる** | 買わなくても、花を眺められる |
| 5 | **花言葉は、値札の時点で読める** | 知るのに、買う必要はない |

**1番が新しい要素です。** 朝、市場から帰ってきて、扉を開けるまでのあいだ。  
お客さまはまだ来ません。**そこにあるのは花だけ**です。

```
朝、市場から帰る  →  棚に並べる  →  ★見て回る  →  扉を開ける  →  お客さまが来る
                                   ↑ ここが新しい。ここが60%の入口
```

この時間には、**目的がありません。** 注文もメモもなく、ただ花を見ます。  
目的がないからこそ、「かわいい」だけで立ち止まれます。

## 3. 図鑑が、このゲームのいちばんの武器

ここは完全に同意です。**図鑑を、⑨番目の画面から、本体に上げます。**

```
前   図鑑 = 集めた記録を見るところ（おまけ）
後   図鑑 = 花を知るところ（このゲームの武器）
```

遊んでいるうちに、**本当に花に詳しくなる。** これが他のゲームにないところです。

### 図鑑の1ページに書くこと

```
┌────────────────────────────────────────┐

│           〔 花の絵 〕                    │

│                                          │
│   相場     1本 ¥180 〜 ¥350                │
│            春 ▃  夏 ▅  秋 ▃  冬 ▅         │
│            夏と冬は少し高くなります          │
│                                          │
│   色       赤 桃 橙 黄 白 緑               │
│   香り     ほとんどありません               │

### 項目の一覧

| 項目 | 中身 | なぜ入れるか |
|---|---|---|
| 名前 | 流通名・学名・和名 | 花屋で言える名前を覚えられる |
| 絵 | 1024×1024 | 主役 |
| **花言葉** | 1〜3個 | **「花 → 人」の道の要** |
| 出回る時期 | 一年じゅう／◯月〜◯月 | 旬と分ける |
| 旬 | いちばんいい時期 | 季節を知る |
| **市場価格** | 相場の帯＋季節の高低 | **花屋の知識そのもの**（→5章） |
| 色 | 同じ花の色ちがい | 花は一色ではない、と知る |
| 香り | 3段階＋香りの言葉 | 病室・食卓で効く |
| 日もち | ◯〜◯日 | 贈る先で変わる |
| 相性 | 相手の花＋**なぜ合うか** | 束がうまくなる |
| 水あげ | 扱いのコツ | 本物の知識 |
| ひとこと | その花だけの一言 | 好きになる引き金 |
| 出会った日 | 日付・お客さま・その一言 | ⑫のアルバムと同じ行 |

**最後の欄で、図鑑とアルバムがつながります。**  
花のページから、その花を選んだ日のことを思い出せます。

### 図鑑は、どう埋まるか（3段階）

```
まだ      影だけ。名前も出ない
棚で見た  絵・名前・花言葉・旬・値段  ← 見ただけで、ここまで開く
束に入れた  香り・日もち・相性・水あげ・ひとこと・出会った日 が加わる
```

**花言葉は「見ただけ」で読めます。** 買わないと読めない設計にはしません。  
知るのに、お金を払う必要はないからです。

```
図鑑    127 / 182
```

**この数字は出します。** ただし、**未収集を責める表示は作りません。**  
「あと55種！」とは書きません。書くのは、いま知っている数だけです。

## 4. 図鑑から、花に会いに行ける

図鑑のページから、**一輪の画面（C4）に入れる**ようにします。

```
図鑑のページ  →  ふれる  →  その花が、目の前に大きく咲く
                             （店の棚と同じ見え方・同じ光）
```

買わなくても、注文がなくても、**好きな花に会いに行けます。**

> これは、花屋で「買わないけど見てるだけ」が許されているのと同じことです。
> 5つの問いも、すべて通ります。

## 5. 市場価格を、どう扱うか

入れます。**ただし、経営にはしません。**

```
入れる    知識としての値段
          「冬のバラは高い」「夏のヒマワリは安い」「なぜ高いのか」

入れない  売上・利益・原価・資金繰り・仕入れの判断
```

**プレイヤーは店員であって、経営者ではありません。**  
数字を管理させはじめた時点で、5つめの問い（優しく閉じられるか）に引っかかります。

### 値段は、季節で動きます

```
バラ    1本  ¥250 〜 ¥600

        春 ▃▃    夏 ▃▄    秋 ▃▄    冬 ▇▇
                                      ↑ 冬がいちばん高い

        冬は暖かい温室で育てるので、その分が値段に乗ります。
```

**この一行が、このゲームで教えたいことです。**  
値段が動く理由を知ると、**花が高い日にも、腹が立たなくなります。**

### 値段は、市場とつながります

```
今朝の市場  →  今日の入荷と、今日の値段  →  棚の値札  →  図鑑の相場の帯
```

「今日はシャクヤクが安いな」が、遊んでいるうちに分かるようになります。

### 予算との関係

予算は、これまでどおり **「めやす」であって上限ではありません。**  
超えても叱られません。**値段は、悩みを深くするためにあります。**

## 6. 香り

3段階と、香りの言葉をつけます。

| 段階 | 例 |
|---|---|
| **ほとんどない** | ガーベラ、カーネーション、ケイトウ |
| **ほのかに** | チューリップ、トルコキキョウ、バラ（品種による） |
| **強い** | ユリ、フリージア、スイセン、ヒヤシンス、ストック |

香りの言葉も添えます。

```
フリージア   甘くて、少し粉っぽい。春のはじめの匂い
ユリ         濃い。渡したあと、部屋にしばらく残ります
ミモザ       ほとんどないけれど、葉に近づくと青い匂い
```

**香りは、贈る先で意味が変わります。** 病室では強すぎ、食卓ではごちそうになります。  
だから香りは、飾りではなく**判断の材料**です。

## 7. 相性は、点数ではありません

**「相性 87点」は作りません。** 出すのは、**なぜ合うのか**の一言です。

### 相性の四つの見かた（花屋の知識そのもの）

| 見かた | 中身 | 例 |
|---|---|---|
| **かたち** | まるい／線／面／こまかい | まるい花（ガーベラ）＋線の花（デルフィニウム） |
| **高さ** | 主役／脇役／埋め／流れ | 主役1・脇役2・埋め1が、いちばん失敗しない |
| **色** | 近い色でまとめる／一点だけ差す | 黄色は強いので、少し離して置く |
| **水あげ** | 一緒の水に入れられるか | ガーベラは水を浅く。深水の花と分ける |

**4つめが本物の知識です。** 実際の花屋が、いちばん気をつけているところです。

```
ガーベラ  ×  深水の花
          → 一緒の花瓶に入れると、ガーベラの茎が先に傷みます
```

これを知ると、**現実の花屋で花を買ったときにも役に立ちます。**  
そこまで届いたら、このゲームは成功だと思います。

## 9. 21種 → 108種 へ、どう増やすか

### 絵について（いちばん大きな仕事です）

いまの絵は、`tools/placeholder_art/` で描いています。

```
いま   頭の形     13種類（デイジー／バラ／フリル／ラッパ／カップ／
                          チューリップ／ベル／星／スイセン／ドーム／
                          スプレー／穂／ユーカリ）
       花         21種
```

**13の頭の形で、21種を描いています。** 108種にするには、頭の形を増やします。

| 段 | 何を足すか | 到達 |
|---|---|---|
| 1 | **いまの13の形で描ける花**（色と大きさを変えるだけ） | 21 → 48種 |
| 2 | **新しい頭の形を10ほど足す**（房・穂・実・小花の集まり・キク科の重ね） | 48 → 78種 |
| 3 | **枝もの・葉もの**（桜、松、南天、ユキヤナギ、パンパス） | 78 → 108種 |

**1段目だけで、いまの倍以上になります。** ここから始めます。

> **⚠ ご確認いただきたいこと**
>
> `IMAGE_ASSETS.md` は「変更せずに実装する」とご指示いただいた仕様書です。
> そこに載っている花は **21種** で、108種はその枠を大きく超えます。
>
> ```
> 案A   仕様書の21種を「第一弾」とし、追加ぶんを別紙にまとめる
> 案B   仕様書の花の表を、108種の一覧に差し替える
> ```
>
> **どちらにするか、ご指示ください。** 勝手には書き換えません。

### データについて

100種を1ファイルには書けません。**季節ごとにファイルを分けます。**

```
src/data/flowers/
  spring.ts     20種
  summer.ts     20種
  autumn.ts     18種
  winter.ts     16種
  allyear.ts    16種
  green.ts      18種
  index.ts      まとめて読み込む
```

**1種を足すのに、コードは触りません。** 該当のファイルに1つ書き足すだけにします。
