# ⑮ 実装の順番 ── 世界観が先、花の数は最後

**この文書は、実装のあいだ手元に置きます。**

---

## 0. このゲームの主人公

> # 花は、想いを運ぶ。

```
想い   →   花   →   笑顔
```

**主人公は、花です。** お客さまでも、プレイヤーでもありません。

想いは目に見えません。笑顔も、この店では見えません。  
**見えるのは、花だけです。**

だから実装では、こう優先します。

```
×  花を増やすこと
○  一輪の花を、思わず見つめたくなるほど美しく表現すること
```

## 1. 実装の順番

```
①  世界観の完成
      店内・光・棚・窓・ボケ・カメラ
           ↓
②  花を10種だけ、本物にする
           ↓
③  UIを、それに合わせる
           ↓
④  最後まで遊べるようにする
           ↓
⑤  花を増やす           ← ここが最後
```

**前の版では、⑤を先にやろうとしていました。** 50種を先に描く計画でした。  
**間違いです。** 50種あっても、店が美しくなければ、誰も見つめません。

### なぜ、この順番なのか

```
美しい店に、10種の花     →  「この花屋にいたい」
ふつうの店に、50種の花   →  「花がたくさんあるゲーム」
```

**最初の30秒で「この花屋にいたい」と思えること。**  
これが、他のすべてより先に来ます。

## 2. 各段でやること

### ① 世界観の完成

**この段が終わるまで、花は21種のままでかまいません。**

| 作るもの | 中身 |
|---|---|
| **店内** | 木の質感、奥行き、使い込まれた感じ |
| **光** | 左上の窓から。ひとつだけ。季節で色が変わる |
| **棚** | 花が並んでいる場所。奥はぼける |
| **窓** | 外の季節。桜 → 青空 → 紅葉 → 雪 |
| **ボケ** | 手前・正面・奥の3層。正面だけがくっきり |
| **カメラ** | C0〜C5 の移動。寄る・引く・下りる |
| **空気** | 埃、風、葉の揺れ、鳥、遠くの物音 |

**終わったかの確かめ方**

```
□ 何も操作せず30秒眺めて、退屈しないか
□ 花を1種も見なくても、「いい店だな」と思えるか
□ 窓の外を見たくなるか
□ スクリーンショットを撮りたくなるか
□ この店で働きたいと思えるか            ← いちばん大事
```

**5つとも「はい」になるまで、②へ進みません。**

### 5つめが、いちばん大事です

**このゲームは「花を見るゲーム」ではなく、「花屋になるゲーム」です。**

30秒眺めたあとに、何を思うか。

```
×   早くゲームを進めたい
○   今日はこの店を開けようかな
```

**下だと思えたなら、世界観は完成に近い。**

上の4つは「きれいか」を見ています。5つめだけが「**ここに立ちたいか**」を
見ています。だから、ここだけは他と別の重さで扱います。

> 「CLOSED」の札を、ボタンにしなかった理由もここにあります。
> ボタンを押すのはプレイヤー、札を裏返すのは**店員**です。

### ② 花を10種だけ、本物にする

代表となる10種を選び、**そこだけに時間を使います。**

| 選ぶ基準 | |
|---|---|
| 形がちがう | まるい／線／房／穂／葉 が混ざるように |
| 季節がちがう | 四季にばらける |
| 誰かが思い浮かぶ | ⑬の呼応セリフに出てくる花を優先 |

**候補（10種）**

```
ヒマワリ      まるい・夏・はるかさん
ガーベラ      まるい・通年・そうたさん
バラ          重なり・通年・代表格
チューリップ  カップ・春・誰でも知っている
スイートピー  ひらひら・春・めいさん
トルコキキョウ フリル・通年・なおきさん
デルフィニウム 線・夏・かたちの対比
かすみ草      こまかい・通年・脇役の代表
ユーカリ      葉・通年・りんさん
ラナンキュラス 重なり・春・よしこさん
```

**終わったかの確かめ方**

```
□ 一輪だけ画面に出して、10秒見ていられるか
□ 花びらの重なりが見えるか
□ 光が当たっている側と、影の側が分かるか
□ 「これ、きれいだな」と声が出るか
```

**この10種で、⑬の呼応セリフが全部成立します。** だから遊びとしても足ります。

### ③ UIを、それに合わせる

**UIを先に作りません。** ①②ができたあとで、その上に最小限だけ載せます。

```
花の間（58%）にUIを置かない
面（紙）は1画面に1枚まで
主ボタンは1画面に1つ
```

### ④ 最後まで遊べるようにする

⓪-a 市場 → ⓪-b 開店前 → ② → ③会話 → ④⑤選ぶ → ⑥⑦束ねる → ⑧渡す → ⑨アルバム。  
**一日を通しで遊べるところまで。**

### ⑤ 花を増やす

**ここでやっと数の話をします。** 10 → 50 → 108 → 182。

**一輪ずつ、①②と同じ基準を通します。** 通らない花は足しません。

## 3. ⓪-b 開店前 ── これはゲームではありません

**体験です。**

### 何があるか

```
・鳥が鳴いている
・風で葉っぱが揺れる
・窓から光が入る
・まだ BGM は無い
・花だけが揺れている
```

**それだけです。**

### 何が無いか

```
・注文  ・メモ  ・予算  ・おすすめ  ・進捗  ・チュートリアル
・BGM   ・効果音（鳥と風以外）  ・演出の合図  ・目的
```

### そして、「OPEN」の札を裏返す

30秒ほど眺めてから、プレイヤーが自分で札を裏返します。

```
×   「ゲームを始める」
○   「今日も、花屋を開けよう」
```

**この違いが、いちばん大きいところです。**

「はじめる」ボタンではなく、**札**である理由がここにあります。  
ボタンを押すのは、プレイヤーです。札を裏返すのは、**店員**です。

### 決めごと

| # | |
|---|---|
| 1 | **BGMを鳴らさない。** 鳥と風だけ。音楽は札を裏返してから |
| 2 | **札は、すぐ押せる。** 30秒待たせません。急ぐ人は3秒で抜けられます |
| 3 | **「30秒眺めてください」と言わない。** 言った時点で作業になります |
| 4 | **滞在時間を数えない。** 記録も、ご褒美もありません |
| 5 | **札のほかに、押せるものを置かない**（アルバムと♪だけ、上の帯に小さく） |
| 6 | **花にふれれば、詳細は開ける。** でも、そう促しません |
| 7 | **何もせずに抜けても、何も失わない** |

### 札の見え方

```
        ╭──────────╮
        │  CLOSED  │      ← 木の札。麻ひもで下がっている
        ╰──────────╯
              ↓  ふれる
        （0.9秒かけて、ゆっくり裏返る）
              ↓
        ╭──────────╮
        │   OPEN   │
        ╰──────────╯
              ↓
        （札が揺れて止まる。そのあと、ベルが一度だけ鳴る）
              ↓
        店の音（BGM）が、ここで初めて入ってくる
```

**裏返す動きは、ゆっくりにします。** 0.9秒。急いで押せますが、急いでは進みません。

### 「何もしなくても心地いい」の作り方

30秒眺めていられるように、**ゆっくり変わり続けるもの**を置きます。

| もの | 周期 | 気づかれ方 |
|---|---|---|
| 花の揺れ | 4〜7秒。花ごとに違う | すぐ気づく |
| 葉の揺れ | 6〜11秒。花より遅い | すぐ気づく |
| 光の強さ | 18秒でゆっくり呼吸する | 言われないと気づかない |
| 埃 | 26〜48秒で漂う | ふと気づく |
| 鳥 | 12〜28秒に一度 | 音で気づく |
| 風 | 20〜46秒に一度、ひと吹き | 葉が大きく揺れて気づく |

**周期をそろえません。** そろうと、機械に見えます。

> **繰り返しに見えた瞬間、この時間は死にます。**

## 3-2. 「今日はどんな朝だろう」── 毎日、ほんの少しだけ違う

一日ごとに、朝の空気を少しだけ変えます。**大きくは変えません。**

> 「今日は少し違うな」と感じる程度で十分です。

### 今日の天気（4つだけ）

| 天気 | 光 | 影 | 埃 | どんな朝か |
|---|---|---|---|---|
| **bright** | 1.16 | くっきり | 20粒 | 朝日が強い日 |
| **soft** | 1.00 | ふつう | 14粒 | ふつうの朝 |
| **hazy** | 0.86 | やわらかい | 8粒 | 少し曇った日 |
| **crisp** | 1.06 | くっきり | 11粒 | 澄んだ空気の朝。明るいのに、色は冷たい |

季節ごとに、出やすい天気が違います。

```
春   soft が多い。ときどき、かすんだ朝
夏   bright が多い。曇っても暗くはならない
秋   crisp と soft が半々
冬   ほとんど crisp
```

**同じ日には、必ず同じ朝が来ます。** 開き直すたびに天気が変わると、
「今日の朝」ではなく「ランダムな演出」になってしまうからです。

### 季節が持ってくるもの

| 季節 | 見えるもの | 聞こえるもの |
|---|---|---|
| **春** | 花びらが舞う（三日に二日） | — |
| **夏** | — | **蝉**。曇った朝だけ、代わりに**風鈴** |
| **秋** | 落ち葉が舞う／**赤とんぼ**が横切る（晴れた朝だけ） | — |
| **冬** | **白い息**（澄んだ朝だけ） | — |

### 決めごと

```
□ 天気を、文字で知らせない
     「今日は晴れです」と書いた瞬間、
     「今日はどんな朝だろう」が「今日の天気を読む」に変わる

□ 舞うものは3粒まで
     9粒だと演出に見えた。3粒だと、ふと目に入るだけの景色になる

□ 赤とんぼは、ただ横切るだけ
     止まらない。追えない。ふれられない。見えた人だけが見る

□ 風鈴は、風が吹いたときにだけ鳴る
     ひとりでには鳴らない

□ どれも「気づかない人がいてよい」大きさにする
```

**気づかせようとした瞬間に、演出になります。**  
毎朝そこにあって、たまたま目に入る。それくらいでちょうどいい。

## 4. 実装中、いちばん上に置くもの

```
花は、想いを運ぶ。     想い → 花 → 笑顔

一．花の数を増やすことより、一輪一輪を好きになれることを優先する
二．覚えさせない。好きになった結果、覚えていた
三．最初の30秒で「この花屋にいたい」と思えることを、すべてより優先する
四．新しい機能を増やすより、世界観を磨くことを優先する
```

### 機能を思いついたら、必ずこの4つに答える

```
□ 1. この機能は、花をもっと好きになれるか
□ 2. この機能は、お客さまや贈られる人の想いを、もっと考えたくなるか
□ 3. この機能は、花屋らしさを強くするか
□ 4. この機能は、このゲームの世界観を壊さないか
```

**4つすべて「はい」なら採用。1つでも「いいえ」なら、一度立ち止まる。**

### 何かを足したくなったら、この一問

> # この追加で、一輪の花をもっと好きになれるか？

**これを、いちばん大切な判断基準にします。**

```
×   何か新しい機能を足せないか
○   一輪の花を、もっと好きになれる方法はないか
```

このゲームは、**花を集めるゲームでも、効率よく遊ぶゲームでもありません。**

### 私（Claude）の癖について、書いておきます

指摘をいただきました。**そのとおりだと思います。**

```
182種   100人   50種   12人   108種
```

こういう数を決めると、**枠を全部埋めにかかる**癖があります。  
設計としてはきれいに見えますが、このゲームの魅力は数ではありません。

> **「数が多いこと」ではなく、「忘れられない一輪があること」**

だから、こう決めておきます。

| 迷ったとき | どうするか |
|---|---|
| 枠が空いている | **埋めなくてよい。** 枠は入れ物であって、宿題ではない |
| 数が中途半端 | **中途半端でよい。** 47種でも、いい47種なら足りている |
| 足せるものがある | 足せることは、足す理由になりません |

**数を増やすことよりも、「好きになれる一輪」を増やすことを優先します。**

> **好きな花は、できましたか？**

この問いに、プレイヤーが**自分の言葉で花の名前を答えられること**。  
それが一番のゴールです。**この軸だけは、最後までぶらしません。**
