# ⑧ フォントのルール

## 1. 二つの書体

### 明朝 ── 心の言葉

```
"Hiragino Mincho ProN", "Yu Mincho", "YuMincho", "Noto Serif JP", serif
```

**使うところ**: タイトル、花の名前、花言葉、お客さまのセリフ、ボタン、説明文。  
つまり **プレイヤーが読んで気持ちが動くもの、ぜんぶ**。

理由: 縦線と横線に太さの差があり、水彩のにじみと相性がよい。
和の花屋の値札や、贈りもののカードの字に近い。

### ゴシック ── 数と、しるし

```
"Hiragino Sans", "Hiragino Kaku Gothic ProN", "Yu Gothic", "Noto Sans JP", sans-serif
```

**使うところ**: 値段の数字、日数、単位、ごく小さな注記。

理由: 数字は明朝だと読み取りにくいため。**ただし「¥」と「本」は明朝**にして、
数字だけがゴシックになるようにします（値札の見た目に近づけるため）。

---

## 2. 大きさは7つだけ

| 名前 | 値 | 使うところ |
|---|---|---|
| xs | 11px | ごく小さな注記、図鑑の花言葉 |
| sm | 13px | 季節・日、注記、しるし、値段 |
| md | 15px | 本文、お客さまのセリフ、紙の中 |
| lg | 18px | 花の名前（④）、主ボタン |
| xl | 23px | 画面の見出し（図鑑など） |
| xxl | 30px | 花の名前（⑤詳細） |
| display | 40px | タイトルロゴ |

**この7つ以外を作りません。**

---

## 3. 字間（トラッキング）

日本語は、字間を空けるほど静かになります。

| 用途 | 値 |
|---|---|
| タイトル | 0.22em |
| 「Flower Shop」（英字） | 0.34em |
| 画面の見出し | 0.16em |
| 花の名前 | 0.12〜0.16em |
| 本文・セリフ | 0.06em |
| 注記 | 0.14em |

字間を空けた文字は、**行頭が右にずれて見える**ので、中央揃えのときは
字間の半分だけ左へ戻します（`text-indent` に同じ値を入れる）。

---

## 4. 行間

| 用途 | 値 |
|---|---|
| 本文・セリフ | 1.9 |
| 見出し・タイトル | 1.5 |
| 2行以内の注記 | 1.9 |

**1.9 は広めです。** 詰めたくなったら、行間ではなく文字数を減らします。

---

## 5. 一行の長さ

| 場所 | 上限 |
|---|---|
| セリフ | 18文字 |
| 本文 | 22文字 |
| 注記 | 26文字 |

超えるときは、**折り返すのではなく、文を書き直します。**

---

## 6. 太さ

- 見出し: 500
- それ以外: 400

**700（太字）を使いません。** 強調したいときは、大きさか余白で示します。

---

## 7. 文字の色と、読みやすさ

| 文字 | 色 | 下地 | 比 |
|---|---|---|---|
| 見出し・名前 | `#4A3F35` | 生成り | 8.9:1 |
| 本文 | `#6E6053` | 生成り | 5.7:1 |
| 注記 | `#94867A` | 生成り | 3.2:1 |

注記の 3.2:1 は、通常のアクセシビリティ基準（4.5:1）を下回ります。  
そのため注記は、

- **13px 以上**にする
- **同じことを別の場所でも伝える**（注記だけにしか書かれていない情報を作らない）

の2つを守ります。

背景が絵の上に来るときは、かならず**文字のうしろに光をにじませます**。

```
text-shadow: 0 1px 12px rgba(255,250,238,0.95), 0 0 3px rgba(255,250,238,0.9);
```

---

## 8. 書き方

- 句点「。」で終える。感嘆符は、お客さまのセリフだけに許す。
- 三点リーダは「……」（2つ重ね）。「...」は使わない。
- 数字は半角。単位は全角の前に半角スペースを入れない（`¥440／本`）。
- 「！」は1文につき1つまで。
- 命令形を避ける（「選んでください」→「選べます」「どうぞ」）。
- カタカナ語をなるべく使わない（「キャンセル」→「そっと戻す」）。

---

## 9. 文字の大きさを変えられるようにする

設定（⑩）で「小・中・大」を選べます。

| 段階 | 倍率 |
|---|---|
| 小 | 0.92 |
| 中 | 1.00（既定） |
| 大 | 1.14 |

大にしたとき、**花の間が 55% を下回らないこと**を確認します。
下回るなら、文字を減らすか、次の画面へ送ります。
