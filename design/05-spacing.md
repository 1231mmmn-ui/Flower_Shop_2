# ⑤ 余白のルール

## 1. 単位

すべての余白は **この6つの値だけ**を使います。中間の値を作りません。

| 名前 | 値 | 使うところ |
|---|---|---|
| xs | 4px | 粒どうし、行内の細かい間 |
| sm | 8px | 文字と、そのすぐ下の注記 |
| md | 14px | 段落の間、カードの内側 |
| lg | 22px | 部品どうし、紙の内側 |
| xl | 34px | かたまりどうし、設定の項目の間 |
| xxl | 52px | 画面の中の大きな区切り |

---

## 2. 画面のふち

| 場所 | 値 |
|---|---|
| 左右 | 14px（＋端末のセーフエリア） |
| 上 | 14px（＋セーフエリア。ノッチのある機種はその下） |
| 下 | 14px（＋ホームバー） |

**画面のふちに、文字を寄せません。** どんなに小さな注記でも 14px は空けます。

---

## 3. 三つの帯

| 帯 | 高さ | 中身 |
|---|---|---|
| 空の帯 | 画面高の 14%（130px） | 季節・日／しるし |
| 花の間 | 画面高の 58%（541px） | 花・店内・お客さま |
| 手の帯 | 画面高の 28%（261px） | ことば・ボタン |

**花の間は、どんな理由があっても 55% を下回らせません。**  
文字が入らないときは、文字を減らします。帯を削りません。

---

## 4. 花のまわりの余白

花は、まわりに空きがあるほど美しく見えます。

| 画面 | 花の左右の空き |
|---|---|
| ④ 花選択（正面の花） | 各 24%（隣が半分見える） |
| ⑤ 花詳細 | 各 11% |
| ⑥⑦ ブーケ | 各 5% |
| ⑨ 図鑑のカード | 各 14px |

⑤で余白がいちばん狭いのは、**そこだけは花を大きく見せたいから**です。

---

## 5. 文字まわり

| 場所 | 値 |
|---|---|
| 行間 | 1.9（本文）／1.5（見出し） |
| 段落と段落 | 14px |
| 見出しと本文 | 8px |
| 紙の内側 | 22px |
| 一行の長さ | **最大 22文字**。超えたら折り返すのではなく、文を短くする |

---

## 6. ボタンまわり

| 場所 | 値 |
|---|---|
| 主ボタンの上 | 22px 以上 |
| 主ボタンの下（画面の底まで） | 14px 以上 |
| ボタンとボタン | 34px（文字ボタンどうし）／14px（並ぶ場合） |
| ボタンの内側（左右） | 34px |

---

## 7. やってはいけない詰め方

- **余白を削って、要素を1つ増やすこと。** 増やしたいときは、何かを消します。
- **左右の余白を、上下の余白より広く取ること。** たて長の画面では窮屈に見えます。
- **紙の中に、さらに枠を作ること。** 紙の中は余白だけで区切ります。
- **中央揃えと左揃えを、同じ紙の中で混ぜること。**

---

## 8. 確かめかた

画面のスクリーンショットで、**要素を全部真っ黒に塗りつぶします。**

- 黒い部分が画面の **45% 以下**なら合格。
- 黒が上下左右のどこかに偏っていたら、重心を見直します。
- 黒いかたまりが 4つ以上あったら、多すぎます。3つまでにまとめます。
