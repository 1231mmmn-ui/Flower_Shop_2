# ⑦ アニメーションのルール

## 1. 考え方

このゲームの動きは、**風で花が揺れるくらいの速さ**です。

プレイヤーを驚かせるためではなく、**いま何が起きたかを、静かに知らせるため**に動かします。

---

## 2. 時間は6つだけ

| 名前 | 値 | 使うところ |
|---|---|---|
| とっさ | 120ms | 指の追従（ドラッグ中） |
| すぐ | 200ms | 押した反応、浮き上がり |
| ふつう | 340ms | 現れる・消える、切り替え |
| ゆっくり | 620ms | 画面遷移、前へ出る |
| 咲く | 1100ms | 花が開く、光が差す |
| 呼吸 | 7200ms | 店内の明るさ、埃（くり返し） |

**この6つ以外の時間を作りません。**

---

## 3. カーブは3つだけ

| 名前 | 値 | 性格 |
|---|---|---|
| やわらか | `cubic-bezier(0.33, 0.02, 0.24, 1)` | すっと始まり、長く止まる。既定 |
| おだやか | `cubic-bezier(0.4, 0.14, 0.3, 1)` | 出入りが均等。切り替え用 |
| 立ち上がる | `cubic-bezier(0.22, 0.68, 0.32, 1.0)` | 少し勢いがある。浮き上がり用 |

行き過ぎて戻るカーブ（overshoot / bounce）は**作りません**。

---

## 4. 基本の動き

### 現れる

```
opacity  0 → 1
transform  translateY(10px) → 0
時間  620ms・やわらか
```

### 消える

```
opacity  1 → 0
transform  なし（動かさずに消える）
時間  340ms・やわらか
```

現れるときは動き、消えるときは動かない。**去り際は静かに。**

### 花が咲く（ブーケに1本増えたとき）

```
opacity  0 → 1
大きさ    0.86 → 1.00
位置      結び目の近く → 決められた角度
時間  1100ms・立ち上がる
```

### 花にふれる

```
浮く    0 → -6px
影      「花」→ 濃さ 1.4倍
彩度    そのまま
時間  200ms・立ち上がる
```

指示にあった「0.2秒ほどで少し浮き上がる／影が濃くなる」を、そのまま数字にしたものです。

---

## 5. 画面遷移

すべての遷移は、**カメラ移動**と**ピント送り**の組み合わせだけで作ります。

### カメラ移動

```
大きさ  1.00 → 1.06（寄る）／1.06 → 1.00（引く）
時間    620ms・やわらか
```

### ピント送り

```
ぼかし  0 → 10px
彩度    1.0 → 0.90
時間    340ms・おだやか
```

### 暗くする（⑤花詳細だけ）

```
幕      0 → rgba(58,46,38,0.46)
時間    340ms・やわらか
```

### 順序（同時に起こさない）

⑤花詳細を開くときの、正確な時間表。

```
 0ms  花が浮く（200ms）
100ms  画面が暗くなる（340ms）
200ms  花が前へ出る（620ms）
200ms  背景がぼける（340ms）
450ms  花に光が当たる（620ms）
700ms  紙が下から上がる（500ms）
900ms  文字が上から順に現れる（各120msずらし、5要素）
```

閉じるときは、この逆を 500ms で。

---

## 6. くり返す動き（環境）

いつも動いていて、止まらないもの。**ごく弱く**します。

| 動き | 内容 | 周期 |
|---|---|---|
| 店内の呼吸 | 光の量が 84% ↔ 100% | 7.2s |
| 光の帯 | 3% だけ横にずれる | 26s |
| 埃 | 下から上へ流れる。14粒 | 26〜48s（粒ごとに違う） |
| カメラ | 1.000 ↔ 1.012 倍 | 7.2s |

これらは**プレイヤーに気づかれないくらい**が正解です。気づいたら弱めます。

---

## 7. 音との関係

音は、動きの**あと**に鳴らします（同時ではなく）。

| 動き | 音 | ずれ |
|---|---|---|
| 扉を開ける | ベル | 動きの 100ms後 |
| 花を取る | 紙のような、かすかな音 | 150ms後 |
| リボンを結ぶ | 布がこすれる音 | 200ms後 |
| 完成 | ピアノが一音 | 400ms後 |

---

## 8. 禁止

- 弾む・跳ねる（バウンス）
- 光る・きらめく（グロー、パーティクルの放出）
- 回る（スピナー、ローディング表示）
- 点滅する
- 120ms より短い動き
- 画面全体が横にスライドして切り替わること（**ページに見えるため**）
- 同時に3つ以上のものが動くこと
- 音を先に鳴らして、あとから動かすこと

---

## 9. 動きを止めたい人のために

端末の「視差効果を減らす」が入っているときは、

- くり返す動き（呼吸・埃・光の帯）を**全部止める**
- 画面遷移は 1ms にして、**内容だけ切り替える**
- 花が浮く・影が濃くなるは**残す**（操作の手ごたえなので）
