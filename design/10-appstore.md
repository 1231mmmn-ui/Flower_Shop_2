# App Store スクリーンショット 5枚（完成品としての設計）

このゲームを知らない人が、**5枚を上から下へ眺めるだけで、遊びの正体と空気が伝わる**ことを目指します。
5枚は「花屋の一日」の順に並びます。キャッチコピーも、5枚つづきの文章として読めるようにしました。

---

## 共通の仕様

### 書き出しサイズ

| 用途 | 寸法 |
|---|---|
| マスター | **1320 × 2868**（6.9インチ） |
| 書き出し | 1290 × 2796（6.7インチ）／1242 × 2688（6.5インチ） |

> 提出時に、App Store Connect の必須サイズを再確認します。

### レイアウト（5枚すべて共通）

```
     0 ┌──────────────────────────────────┐
       │                                  │
       │            （余白 200px）           │
   200 │                                  │
       │   花を見ている時間が、               │  ← キャッチコピー
       │   そのまま遊びになる。               │     72px 明朝 500 / 字間0.14em
       │                                  │     行間1.5 / 墨 #4A3F35
   470 │                                  │     最大2行・1行14文字まで
       │   小さな街の、木造の花屋さん。         │  ← 添え書き
   540 │                                  │     34px 明朝 400 / 墨・淡 #6E6053
       │            （余白 80px）             │
   620 ├──────────────────────────────────┤
       │ ╭──────────────────────────────╮ │
       │ │                              │ │  ← ゲーム画面（実機キャプチャ）
       │ │                              │ │     幅 1160px（左右に各80px）
       │ │        画 面                  │ │     上角丸 56px
       │ │                              │ │     影 0 40px 80px rgba(96,74,54,0.18)
       │ │                              │ │
       │ │                              │ │     下端は裁ち落とし
  2868 └─┴──────────────────────────────┴─┘        （画面がまだ続く感じを出す）
```

### 背景

```
下地   #FBF6EC（生成り）
光     左上から楕円のグラデーション
       radial-gradient(90% 60% at 18% 0%,
         rgba(255,246,224,0.55) 0%, rgba(255,246,224,0) 60%)
粒子   紙の粒を 6% だけ乗せる（画像素材と同じ質感）
```

**枠（端末のベゼル）は描きません。** 枠を描くと「アプリの宣伝」に見えます。
画面をそのまま置いて下端で裁ち落とすと、**世界がまだ続いている**ように見えます。

### 添えるもの

- 1枚目の左上に、店の看板のような小さな飾り（乾いた葉の枝）を 1つだけ。
- 2〜5枚目には飾りを置きません。**花以外の色を増やさない**ためです。

### やらないこと

- 端末の枠、手、指
- 矢印、吹き出し、「NEW」「無料」などのバッジ
- 画面を斜めに傾けること
- 1枚に2つ以上の画面を並べること
- 影を濃くすること（drop shadow は 18% まで）

## 5枚の設計

### 1枚目 ── 花

```
キャッチ   花を見ている時間が、
          そのまま遊びになる。
添え書き   小さな街の、木造の花屋さん。
画面       ④ 花選択
```

- **写すもの**: ヒマワリが正面。両隣（トルコキキョウ・ユリ）は半分だけ、ぼけて見える。
- **状態**: 春・1日目。財布 `¥0 ／ ¥2,000`。「束ねる」は押せない濃さ（35%）。
- **狙い**: 一覧でこの1枚しか見ない人にも、**「花が大きい」「静か」**の2つが伝わること。
- **確認**: 画面の中でいちばん彩度が高いのがヒマワリであること。

### 2枚目 ── 人

```
キャッチ   お客さまの想いを、
          聞くところから。
添え書き   8人のお客さま。それぞれに、渡す相手がいます。
画面       ③ お客さまとの会話
```

- **写すもの**: はるかさん（customer-01）。セリフは2行目まで出た状態。
- **状態**: メモは「誕生日プレゼント（同僚へ）／明るい色・明るい・華やか／2,000円ほど」。
- **狙い**: これが**接客のゲーム**で、相手に人格があることを伝える。
- **確認**: 顔に文字がかかっていないこと。

### 3枚目 ── 手

```
キャッチ   一本ずつ、
          手で束ねていく。
添え書き   21種の切り花と、6種の包み紙。
画面       ⑥ ブーケ制作（花にふれている状態）
```

- **写すもの**: 7本の束。ガーベラをつかんでいて、その花だけ浮いて影が濃い。
  道具の行は `ガーベラ　手前へ　戻す　手をはなす`。
- **狙い**: **自分の手で作れる**こと、そして**自由度がある**ことを伝える。
- **確認**: 束が画面高の 50% 以上あること。

### 4枚目 ── 想い

```
キャッチ   世界に一つだけの
          ブーケが、できあがる。
添え書き   どんな束でも、必ず笑顔で受け取ってくれます。
画面       ⑧ 完成・お渡し
```

- **写すもの**: くすみピンクの紙で包んだ束を、笑顔のはるかさんが受け取っているところ。
  花のしるしは5つとも灯った状態。
- **状態**: 「眺める間」に入る**直前**（言葉と紙が両方見えている瞬間）。
- **狙い**: **この5枚のなかで、いちばん美しい1枚**にする。ここで心を決めてもらう。
- **確認**: ブーケと顔が重ならず、どちらも切れていないこと。

### 5枚目 ── 残るもの

```
キャッチ   花言葉は、
          図鑑に残ります。
添え書き   時間制限も、ランキングもない、静かなゲームです。
画面       ⑨ 図鑑
```

- **写すもの**: 21種のうち 12種が集まった状態（`12／21`）。
  上の6枚は色が付いていて、下の2枚は淡い影だけ。**まだ先がある**ことを見せる。
- **狙い**: 遊びが積み重なること、そして**焦らせないゲームである**ことを最後に伝える。
- **確認**: 花言葉の文字が読めること。

## 5枚を続けて読むと

> 花を見ている時間が、そのまま遊びになる。  
> お客さまの想いを、聞くところから。  
> 一本ずつ、手で束ねていく。  
> 世界に一つだけのブーケが、できあがる。  
> 花言葉は、図鑑に残ります。

一覧でざっと流し見る人にも、1枚ずつ読む人にも通じるようにしています。

## 作り方

1. デザインガイドどおりに画面を実装する
2. 上の「状態」のとおりに操作して、**実機の画面をそのまま撮る**（1320×2868 相当）
3. この文書の共通レイアウトに置き、キャッチコピーを載せる
4. 5枚を並べて、**彩度を抜いた状態**で見る。花がいちばん目立っていれば完成

> 作り絵（実際には無い画面）は使いません。**ゲームの中に本当にある景色**だけを載せます。
