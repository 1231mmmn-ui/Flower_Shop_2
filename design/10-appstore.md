# ⑩ App Store スクリーンショット ── 5枚の物語

5枚を「機能の紹介」ではなく、**初めて見た人の心が動いていく一本の物語**として設計します。

---

## 1. 前提 ── 見る人はこう見る

| 枚 | 見られる時間 | そのとき起きること |
|---|---|---|
| 1枚目 | **0.8秒** | 読まれない。**絵だけ**で判断される |
| 2枚目 | 1.5秒 | ここで初めて文字が読まれる |
| 3枚目 | 2秒 | 「何をするゲームか」を探される |
| 4枚目 | 2秒 | 「自分にもできそうか」を測られる |
| 5枚目 | 3秒 | 「長く遊べるか」を確かめられる |

だから **1枚目に説明を書きません。** 空気だけで引き込みます。  
説明が要るのは3枚目です。

---

## 2. 5枚の物語

```
1枚目  花屋に入る       → 「わ、きれい」          （引き込まれる）
2枚目  想いを聞く       → 「誰かのために選ぶんだ」  （物語が始まる）
3枚目  花を選ぶ         → 「これ、選ぶの楽しそう」  （遊びが分かる）
4枚目  ブーケができる    → 「作ってみたい」        （達成感の予感）
5枚目  笑顔と、続き      → 「明日も開きたくなりそう」（続けたくなる）
```

各枚は、**⑪感情設計書の感情**とそのまま対応しています。

| 枚 | 起こしたい感情 | ゲーム内の対応 |
|---|---|---|
| 1 | 期待 | ①②タイトル・店内 |
| 2 | 共感 | ③会話 |
| 3 | 迷い・発見 | ⑤花詳細 |
| 4 | 達成 | ⑦包み終わり |
| 5 | 感動・余韻 | ⑧完成（眺める間） |

## 3. 共通の仕様

### 書き出しサイズ

| 用途 | 寸法 |

| 書き出し | 1290 × 2796（6.7インチ）／1242 × 2688（6.5インチ） |

       │ │                              │ │  ← 実機キャプチャ
       │ │          画 面                │ │     幅1160px（左右各80px）

**枠（端末のベゼル）は描きません。** 枠は「アプリの宣伝」に見えます。  
画面をそのまま置いて下端で裁ち落とすと、**世界がまだ続いている**ように見えます。

### 背景

```
下地  #FBF6EC（生成り）
光    radial-gradient(90% 60% at 18% 0%,
        rgba(255,246,224,0.55) 0%, rgba(255,246,224,0) 60%)
粒子  紙の粒を6%
```

**5枚とも同じ背景。** 背景を変えると、5枚がバラバラの広告に見えます。

### 5枚に共通して、やらないこと

- 端末の枠、手、指
- 矢印、吹き出し、バッジ（NEW／無料／人気）
- 画面を斜めに傾ける
- 1枚に2つ以上の画面を並べる
- 「機能」を説明する言葉（○○モード／○○種類以上／やりこみ要素）

## 4. 一枚ずつの設計

### 1枚目 ── 花屋に入る

```
キャッチ    花屋に、
           入ってみませんか。
添え書き    小さな街の、木造の花屋さん。
画面        ② お花屋さん（誰も来ていない朝）
```

- **見た人の心**: 「わ、きれい」だけで十分。ここでは何も理解させません。
- **写すもの**: 窓から差す光、天井から下がる灯り、カウンターの花のカゴ、
  はさみと麻ひも。**人もUIも、ほとんど写らない。**
- **状態**: 春・1日目。文字は「春・1日目」と「今日も、いい光です。」だけ。
- **狙い**: 一覧で**この1枚しか見ない人**に、空気だけを渡す。
- **落とし穴**: ここで花を大きく見せたくなるが、**我慢する**。
  花は3枚目まで取っておきます。先に見せると、3枚目の驚きが減ります。
- **確認**: 文字を隠しても、絵として成立するか。

### 2枚目 ── 想いを聞く

```
キャッチ    お客さまの想いを、
           聞くところから。
添え書き    8人のお客さま。それぞれに、渡す相手がいます。
画面        ③ お客さまとの会話
```

- **見た人の心**: 「これは、誰かのために花を選ぶゲームなんだ」
- **写すもの**: はるかさん。セリフは2行目まで出た状態。
  > 同僚の誕生日プレゼントにしたくて。  
  > あの子、笑うと本当に元気が出る子なんです。
- **狙い**: **物語の始まりを見せる。** 相手に人格があることを、セリフ1つで伝える。
- **落とし穴**: メモ（条件）を目立たせない。**セリフが主役**です。
- **確認**: 顔に文字がかかっていないか。セリフが2行で読み切れるか。

### 3枚目 ── 花を選ぶ

```
キャッチ    花言葉を読んで、
           この人に贈る一本を決める。
添え書き    21種の切り花。どれにも、意味があります。
画面        ⑤ 花詳細（ヒマワリ）
```

- **見た人の心**: 「**それが遊びなのか**」── ここで初めて、ゲームの正体が分かる。
- **写すもの**: 画面いっぱいのヒマワリ。背景は暗くぼけ、花にだけ光。
  紙には「憧れ」「あなただけを見つめる」の花言葉が見えている。
- **狙い**: **このゲームで唯一、説明が必要な1枚。**
  2枚目のセリフ（笑うと元気が出る子）と、この花言葉が結びつくことを、
  **並べて見せるだけで気づかせる**。
- **落とし穴**: 花選択画面（④）ではなく**詳細画面（⑤）を使う**。
  一覧を見せると「選択肢の多さ」の話になり、**花言葉の話にならない**。
- **確認**: 花言葉の2語が、縮小表示でも読めるか。

### 4枚目 ── ブーケができる

```
キャッチ    一本ずつ、
           手で束ねていく。
添え書き    包み紙6種、リボン5種。同じ束は、二つとできません。
画面        ⑦ ラッピング（包み終わった瞬間）
```

- **見た人の心**: 「作ってみたい」── 手を動かしたくなる。
- **写すもの**: くすみピンクの紙で包み終わった束。リボンが結ばれている。
  棚には紙のロールとリボンの巻きが並んでいる。
- **狙い**: **自分の手が入る余地**を見せる。素材が並んでいることで、
  「自分なら違う紙にする」と考え始めてもらう。
- **落とし穴**: 完成形（⑧）を使わない。**⑧は5枚目のためにとっておく。**
  ここで完成させてしまうと、5枚目が繰り返しになります。
- **確認**: 束が画面高の50%以上あるか。棚の資材が判別できるか。

### 5枚目 ── 笑顔と、続き

```
キャッチ    喜んでもらえた日は、
           図鑑に残ります。
添え書き    時間制限も、ランキングもない、静かなゲームです。
画面        ⑧ 完成（笑顔で受け取った瞬間）
```

- **見た人の心**: 「明日も開きたくなりそう」
- **写すもの**: ブーケを受け取って笑っているはるかさんと、その手の中の束。
  お客さまの言葉が1行見えている。
  > これを渡したら、あの子どんな顔するかな。
- **狙い**: **感動と、続きの予感を同時に渡す。**
  絵は感動（笑顔）、コピーは継続（図鑑に残る）を担当します。
- **落とし穴**: 花のしるし（笑顔の数）を写さない。**点数に見えます。**
  眺める間に入る直前、言葉が出ていてしるしがまだ灯っていない瞬間を撮ります。
- **確認**: 顔とブーケが両方切れずに入っているか。

## 5. 5枚を続けて読むと

> 花屋に、入ってみませんか。  
> お客さまの想いを、聞くところから。  
> 花言葉を読んで、この人に贈る一本を決める。  
> 一本ずつ、手で束ねていく。  
> 喜んでもらえた日は、図鑑に残ります。

**流し見る人にも、1枚ずつ読む人にも通じる**ようにしています。

## 6. 6枚目（任意）── 図鑑

App Store は10枚まで置けます。5枚で物語は完結していますが、
「どれくらい遊べるか」を確かめたい人のために、6枚目を用意できます。

```
キャッチ    集めた花と、その花言葉。
添え書き    21種。季節がめぐると、店先が入れ替わります。
画面        ⑨ 図鑑（12／21）
```

上6枚は色が付き、下は淡い影だけ。**まだ先がある**ことを見せます。

## 7. 作り方

1. デザインガイドどおりに画面を実装する
2. 上の「状態」のとおりに操作し、**実機の画面をそのまま撮る**
3. この版面に置き、キャッチコピーを載せる
4. 5枚を並べ、次の3つを確かめる

   - **彩度を抜いて見る** → 花がいちばん目立っているか
   - **文字を隠して見る** → 5枚だけで話が通じるか
   - **1枚目だけを0.8秒見せる** → 「きれい」と言われるか

> 作り絵（実際には無い画面）は使いません。**ゲームの中に本当にある景色**だけを載せます。
