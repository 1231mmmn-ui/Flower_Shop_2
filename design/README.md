# Flower Shop ～花咲く時間～ デザイン一式

**この一式は承認されました。** ここからは、これを唯一の基準として実装します。

---

# 花は、想いを運ぶ。

```
想い   →   花   →   笑顔
```

このゲームは、この一行でぜんぶです。

**主人公は、花です。** お客さまでも、プレイヤーでもありません。  
花は主役であり、**想いを運ぶ存在**です。

| | |
|---|---|
| **想い** | 誰かを想う気持ち。お客さまが預けに来るもの |
| **花** | それを受け取り、形にして、運ぶもの ── **ここがこのゲーム** |
| **笑顔** | 運ばれた先で咲くもの。贈られる人の顔 |

想いは目に見えません。笑顔は、この店では見えません（贈られる人は画面に出ません）。  
**見えるのは、花だけです。** だから花が主人公になります。

---

## 実装のあいだ、いちばん上に置く三つ

**この三つは、この一式のすべてに優先します。**

### 一．花の数を増やすことより、一輪一輪を好きになれることを優先する

```
182種は「仕様」であって、「ゴール」ではありません。

成功   50種しかなくても、「あ、この花好き」と思えた
失敗   182種あっても、全部が同じように見えた
```

一輪一輪に個性があり、思い出があり、自然と名前を覚えてしまう花にします。  
**枠が182あっても、埋める義務はありません。**

### 二．知識を、覚えさせない

```
×   「覚えてね」
○   「気がついたら、覚えていた」
```

図鑑は**辞典ではなく、思い出のアルバム**です。  
花言葉も旬も市場価格も、勉強として覚えるのではなく、
**遊んでいるうちに自然と知っていた**、という体験にします。

```
覚えさせる  →  好きになる     ×  逆です
好きになる  →  覚えていた     ○
```

詳しくは **⑭花の設計書の冒頭「二つの戒め」** に書きました。

### 三．最初の30秒で「この花屋にいたい」と思えることを、すべてより優先する

```
美しい店に、10種の花     →  「この花屋にいたい」
ふつうの店に、50種の花   →  「花がたくさんあるゲーム」
```

だから実装の順番を変えました。

```
①  世界観の完成（店内・光・棚・窓・ボケ・カメラ）
②  花を10種だけ、本物にする
③  UIを、それに合わせる
④  最後まで遊べるようにする
⑤  花を増やす           ← ここが最後
```

**「花を増やすこと」より、「一輪の花を、思わず見つめたくなるほど
美しく表現すること」を最優先します。** 詳しくは **⑮実装の順番** に書きました。

## このゲームのテーマ

> # 好きな花は、できましたか？

**この問いが、このゲームのテーマです。**

聞くのは「面白かったですか？」ではありません。  
プレイヤーが、**自分の言葉で花の名前を答えられること。**  
それがこのゲームの、一番のゴールです。

実装中に迷ったら、書いているコードがこの問いに近づくものか、遠ざかるものかで決めます。  
**この軸だけは、最後までぶらしません。**

## 演出は、この一問で決めます

いまは **「世界観を作る」段階から「感動を作る」段階**に移りました。

> # この演出は、プレイヤーの心を動かしているか？

```
動いていない   →   どれだけ綺麗でも、入れない
動く           →   どれだけ小さくても、入れる
```

目指すのは、動くものを増やすことではなく、**心が動く瞬間を増やすこと**です。

```
1.  窓の外を、思わず眺めたくなる
2.  一輪の花を、しばらく見つめてしまう
3.  お客さまの言葉を、もう一度読み返したくなる
4.  ブーケが完成したあと、少し眺めていたくなる
5.  また明日も、この花屋を開けたいと思う
```

この**「少し立ち止まる時間」**が、このゲームのいちばんの価値です。  
詳しくは **⑯立ち止まる時間** に書きました。

## このゲームの主題

> **「花を知り、花を好きになり、その花で誰かの想いを届けるゲーム」**
>
> ジャンルは **「心を贈るシミュレーションゲーム」**。

**この順番が、いちばん大事です。**

```
花を知る  →  花を好きになる  →  その花で、誰かの想いを届ける
  ↑ ここが入口
```

### 花60% ／ 人生40%

```
花    60%   ← 主役であり、入口。まず花に興味を持つ
人生  40%   ← 花に意味を与えるもの
```

**これは「人生を知るゲーム」ではありません。**

遊んでいるあいだの道は、二本あります。

```
花 → 人（60%）                    人 → 花（40%）

「ガーベラって可愛い」               「あの子、笑うと元気が出る子で」
      ↓                                 ↓
「希望、って花言葉なんだ」            「明るい花は、どれだろう」
      ↓                                 ↓
「そういえば、あの友達」              「あ、ヒマワリだ」
      ↓                                 ↓
「この花にしよう」                   「この花にしよう」
```

**左のほうが多い**、というのが今回の訂正です（→ ⑭花の設計書）。

### 花に意味を与えるのが、人生の40%

```
プレイヤー  →  お客さま  →  贈られる人
                （目の前）    （画面に出てこない）
```

**お客さまだけに寄りすぎないこと。** 想いの行き先は、その先にいます。

### 何かを足すときの、4つの問い

**「ゲームとして面白いか」は、判断の基準にしません。**  
機能を思いつくたびに、**必ず**この4つに答えます。

```
□ 1. この機能は、花をもっと好きになれるか
□ 2. この機能は、お客さまや贈られる人の想いを、もっと考えたくなるか
□ 3. この機能は、花屋らしさを強くするか
□ 4. この機能は、このゲームの世界観を壊さないか
```

**4つすべて「はい」なら採用します。**  
**1つでも「いいえ」があるなら、一度立ち止まって考え直します。**

この4つが、以前の5つ（花屋にあるか／関係が深まるか／相手を想像できるか／
花を好きになれるか／優しく閉じられるか）を置き換えます。  
中身は失われていません。**4つめの「世界観を壊さないか」**が、
「優しい気持ちで閉じられるか」を含んでいます。

### 迷ったときは、機能を増やさない

```
×   何か新しい機能を足せないか
○   一輪の花を、もっと好きになれる方法はないか
```

**このゲームは、花を集めるゲームでも、効率よく遊ぶゲームでもありません。**

新しい機能を増やすより、**世界観を磨くことを優先します。**

### このゲームの心臓

```
心臓  =  プレイヤーが「この人にぴったりの花を見つけられた」と感じる瞬間
セリフ =  その感情を、そっと後押しするもの
```

**セリフは心臓ではありません。** だから、うまいことを言わせません。  
日常の一言なのに、あとから思い返すと温かい。それで十分です。

## 決める順番

```
⑭ 花（60%）        ＋        ⑫ 人生（40%）      ← このゲームの中身
        ＼                    ／
              ⓪ 感情                            ← 二つが出会う瞬間を設計する
                 ↓ そのために
              体験（何を考えながら過ごすか）
                 ↓ そのために
           ①② 空間・カメラ（どこで、どう見せるか）
                 ↓ そのために
           ③〜⑧ UIの決めごと（どう作るか）
                 ↑ その土台
                ⑨ 世界観
```

**前の版では、花が下に置かれていました。** 人生 → お客さま → 感情 → 花 の順で、
花が最後でした。**それでは、花が想いを運ぶ道具になります。** 訂正しました。

迷ったときは、この一文に戻ります。

> **「これは、プレイヤーが花を好きになることに、つながるか」**

```
×   面白かったですか？
```

だから、そこにご褒美を付けません。**答えを買収してはいけない**からです。

## 感情の骨格

```
ワクワク → 共感 → 悩む → 発見 → 嬉しい → 感動 → 余韻
```

```
  高 │                    ◆発見             ◆感動
     │                   ／  ＼            ／  ＼
     │          ◆悩む  ／     ＼  ◆嬉しい ／     ＼
  中 │   ◆共感 ／     ＼        ＼／  ＼／        ＼
     │  ／     ＼                ▽                ＼
  低 │◆ワクワク               （谷）               ◆余韻
     └──────────────────────────────────────────────

お客さま 姿なし  目の前  ★手元  ★手元  ★手元  目の前   気配だけ
```

**山はふたつだけ**（発見・感動）。**谷はわざと作ります**（手を動かす時間）。  
★ = 前回の設計でお客さまがいなくなっていたところ。ここを取り戻します。
