# Flower Shop ～花咲く時間～ デザイン一式

実装より先に、デザインを決めるための文書です。  
**承認が出るまで実装は進めません。** 承認後は、この一式を唯一の基準とします。

---

## このゲームの主題

> **「花を知り、花を好きになり、その花で誰かの想いを届けるゲーム」**
>
> ジャンルは **「心を贈るシミュレーションゲーム」**。

**この順番が、いちばん大事です。**

```
花を知る  →  花を好きになる  →  その花で、誰かの想いを届ける
  ↑ ここが入口
```

### 花60% ／ 人生40%

```
花    60%   ← 主役であり、入口。まず花に興味を持つ
人生  40%   ← 花に意味を与えるもの
```

**これは「人生を知るゲーム」ではありません。**

遊んでいるあいだの道は、二本あります。

```
花 → 人（60%）                    人 → 花（40%）

「ガーベラって可愛い」               「あの子、笑うと元気が出る子で」
      ↓                                 ↓
「希望、って花言葉なんだ」            「明るい花は、どれだろう」
      ↓                                 ↓
「そういえば、あの友達」              「あ、ヒマワリだ」
      ↓                                 ↓
「この花にしよう」                   「この花にしよう」
```

**左のほうが多い**、というのが今回の訂正です（→ ⑭花の設計書）。

### 花に意味を与えるのが、人生の40%

```
プレイヤー  →  お客さま  →  贈られる人
                （目の前）    （画面に出てこない）
```

**お客さまだけに寄りすぎないこと。** 想いの行き先は、その先にいます。

### 何かを足すときの、5つの問い

**「ゲームとして面白いか」は、判断の基準にしません。**

```
□ 1. 本当にこの花屋に、自然に存在するものか
□ 2. お客さまとの関係が、深まるか
□ 3. プレイヤーが、渡す相手を想像できるか
□ 4. 花そのものを、もっと好きになれるか
□ 5. 遊び終わったあと、優しい気持ちでゲームを閉じられるか   ← いちばん上
```

1〜4は「この花屋にあるか」を見る問い。**5つめだけが、閉じたあとを見ています。**  
花屋に実在しても5つめで落ちるもの（売れ残り、廃棄、不満そうな顔）があります。

ひとつでも「いいえ」なら、採用しません。

### このゲームの心臓

```
心臓  =  プレイヤーが「この人にぴったりの花を見つけられた」と感じる瞬間
セリフ =  その感情を、そっと後押しするもの
```

**セリフは心臓ではありません。** だから、うまいことを言わせません。  
日常の一言なのに、あとから思い返すと温かい。それで十分です。

## 決める順番

```
⑭ 花（60%）        ＋        ⑫ 人生（40%）      ← このゲームの中身
        ＼                    ／
              ⓪ 感情                            ← 二つが出会う瞬間を設計する
                 ↓ そのために
              体験（何を考えながら過ごすか）
                 ↓ そのために
           ①② 空間・カメラ（どこで、どう見せるか）
                 ↓ そのために
           ③〜⑧ UIの決めごと（どう作るか）
                 ↑ その土台
                ⑨ 世界観
```

**前の版では、花が下に置かれていました。** 人生 → お客さま → 感情 → 花 の順で、
花が最後でした。**それでは、花が想いを運ぶ道具になります。** 訂正しました。

迷ったときは、この一文に戻ります。

> **「これは、プレイヤーが花を好きになることに、つながるか」**

## 感情の骨格

```
ワクワク → 共感 → 悩む → 発見 → 嬉しい → 感動 → 余韻
```

```
  高 │                    ◆発見             ◆感動
     │                   ／  ＼            ／  ＼
     │          ◆悩む  ／     ＼  ◆嬉しい ／     ＼
  中 │   ◆共感 ／     ＼        ＼／  ＼／        ＼
     │  ／     ＼                ▽                ＼
  低 │◆ワクワク               （谷）               ◆余韻
     └──────────────────────────────────────────────

お客さま 姿なし  目の前  ★手元  ★手元  ★手元  目の前   気配だけ
```

**山はふたつだけ**（発見・感動）。**谷はわざと作ります**（手を動かす時間）。  
★ = 前回の設計でお客さまがいなくなっていたところ。ここを取り戻します。

    │      花 の 間           │  ← ここにUIを置かない

72% ├ ─ ─ ─ ─ ─ ─ ─ ─ ─ ─ ─ ┤
    │  手の帯   ことば／ボタン    │  ← UIを置いてよい
