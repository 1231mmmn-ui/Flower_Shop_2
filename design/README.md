実装より先に、デザインを決めるための文書です。  
**承認が出るまで実装は進めません。** 承認後は、この一式を唯一の基準とします。

---

## このゲームの主題

> **ジャンル：心を贈るシミュレーションゲーム**
>
> これは「花を選ぶゲーム」でも「ブーケを作るゲーム」でもありません。  
> **「誰かを想って、花を選ぶゲーム」**です。主題は **「想いを届けること」**。

プレイヤーは、**二人のことを同時に想います。**

```
プレイヤー  →  お客さま  →  贈られる人
                （目の前）    （画面に出てこない）
```

**お客さまだけに寄りすぎないこと。** 想いの行き先は、その先にいます。

```
想いが生まれる → 想いを預かる → 花の形にする → 想いが届く
              （ここがこのゲーム）
```

花は**主役**（画面でいちばん大きく、美しく映るもの）。  
お客さまの気持ちは**主題**（遊んでいるあいだ、ずっと考えていること）。

この二つは別のものです。花をきれいに並べただけでは、このゲームになりません。

### 何かを足すときの、4つの問い

**「ゲームとして面白いか」は、判断の基準にしません。**  
基準は **「本当にこの花屋に存在しそうか」** です。

```
□ 1. 本当にこの花屋に、自然に存在するものか
□ 2. お客さまとの関係が、深まるか
□ 3. プレイヤーが、渡す相手を想像できるか
□ 4. 花そのものを、もっと好きになれるか
```

ひとつでも「いいえ」なら、採用しません。

## 感情の骨格

```
ワクワク → 共感 → 悩む → 発見 → 嬉しい → 感動 → 余韻
```

```
  高 │                    ◆発見             ◆感動
     │                   ／  ＼            ／  ＼
     │          ◆悩む  ／     ＼  ◆嬉しい ／     ＼
  中 │   ◆共感 ／     ＼        ＼／  ＼／        ＼
     │  ／     ＼                ▽                ＼
  低 │◆ワクワク               （谷）               ◆余韻
     └──────────────────────────────────────────────

お客さま 姿なし  目の前  ★手元  ★手元  ★手元  目の前   気配だけ
```

**山はふたつだけ**（発見・感動）。**谷はわざと作ります**（手を動かす時間）。  
★ = 前回の設計でお客さまがいなくなっていたところ。ここを取り戻します。

## 空間の設計にある、たった一つの考え

**10の画面を「別々のページ」にしない。**

ひとつの花屋の中で、**カメラが動くだけ**にします。  
ただしカメラは**感情を運ぶための道具**であって、目的ではありません。

## 全画面に共通する、破らない3つの決めごと

```

    │      花 の 間           │  ← ここにUIを置かない
    │  （花・店内・お客さま）    │     画面の 58%

    │  手の帯   ことば／ボタン    │  ← UIを置いてよい
```

## レビューでご確認いただきたいこと

**いま、いちばん見ていただきたいもの**

**⑬セリフ集（13-lines.md）** ── 呼応セリフ8行と、エプロンのメモの文面。  
設計だけでは決められない部分です。**気になる行だけ**お知らせいただければ書き直します。  
私自身が迷っている3点も、同じ文書の3章に正直に書きました。

**お客さまと世界観について**

1. **扱わないテーマ**（月命日・葬儀・離婚など）の線引き。
   切なさは「その人と、また会えるか」で見分ける、という基準でよいか
2. **よしこさんの差し替え**（月命日 → 孫のピアノ発表会）
3. **一期一会（36人以上）＋ 常連（6人）** という構成
4. **常連は曜日と季節のリズムで来る**（ランダムではない）
5. 新しい常連 **たけしさん**（理由もなく妻に花を買う定年後の人）
6. **お見舞い → 快気祝い** で一期一会の人にもう一度だけ会える案
7. **図鑑を「店の記録帳」に広げる**（花のページ＋お客さまのページ）
8. **温室を保留**にしたこと（花屋は花を育てず、仕入れるため）

**感情について**

9. **エプロンのメモ** ── 選んでいる間ずっと、お客さまの言葉が手元にある仕掛け
10. **三人めの人**（渡す相手）を、画面に一度も出さないという判断
11. **呼応表と呼応セリフ**（⓪4章）── このゲームでいちばん大事な文章です
12. 「達成感」を **「嬉しい」**（相手の喜びの先取り）に置き換えたこと

**空間・見せ方について**

13. 「カメラが動くだけ」を、感情の下位に置く整理でよいか
14. ⑧完成の「眺める間」（UIが3秒後に消えて、ブーケだけが残る）を入れるか
15. App Store 5枚の物語（1枚目は説明せず空気だけ／3枚目で花言葉を見せる）でよいか

ここが決まってから①②を改訂し、そのあと実装へ移ります。
