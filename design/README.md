# Flower Shop ～花咲く時間～ デザイン一式

実装より先に、デザインを決めるための文書です。  
**承認が出るまで実装は進めません。** 承認後は、この一式を唯一の基準とします。

---

## このゲームの主題

> **ジャンル：心を贈るシミュレーションゲーム**
>
> これは「花を選ぶゲーム」でも「ブーケを作るゲーム」でもありません。  
> **「誰かを想って、花を選ぶゲーム」**です。主題は **「想いを届けること」**。

プレイヤーは、**二人のことを同時に想います。**

```
プレイヤー  →  お客さま  →  贈られる人
                （目の前）    （画面に出てこない）
```

**お客さまだけに寄りすぎないこと。** 想いの行き先は、その先にいます。

```
想いが生まれる → 想いを預かる → 花の形にする → 想いが届く
              （ここがこのゲーム）
```

花は**主役**（画面でいちばん大きく、美しく映るもの）。  
お客さまの気持ちは**主題**（遊んでいるあいだ、ずっと考えていること）。

この二つは別のものです。花をきれいに並べただけでは、このゲームになりません。

### 何かを足すときの、5つの問い

**「ゲームとして面白いか」は、判断の基準にしません。**

```
□ 1. 本当にこの花屋に、自然に存在するものか
□ 2. お客さまとの関係が、深まるか
□ 3. プレイヤーが、渡す相手を想像できるか
□ 4. 花そのものを、もっと好きになれるか
□ 5. 遊び終わったあと、優しい気持ちでゲームを閉じられるか   ← いちばん上
```

1〜4は「この花屋にあるか」を見る問い。**5つめだけが、閉じたあとを見ています。**  
花屋に実在しても5つめで落ちるもの（売れ残り、廃棄、不満そうな顔）があります。

ひとつでも「いいえ」なら、採用しません。

### このゲームの心臓

```
心臓  =  プレイヤーが「この人にぴったりの花を見つけられた」と感じる瞬間
セリフ =  その感情を、そっと後押しするもの
```

**セリフは心臓ではありません。** だから、うまいことを言わせません。  
日常の一言なのに、あとから思い返すと温かい。それで十分です。

```
⓪ 感情       何を感じてほしいか        ← ここから決める。最上位
      ↓ そのために
   体験       何を考えながら過ごすか
      ↓ そのために
①② 空間・カメラ  どこで、どう見せるか
      ↓ そのために
③〜⑧ UIの決めごと  どう作るか
      ↑ その土台
⑨ 世界観
```

**⓪が他のすべてに優先します。** 迷ったときは⓪に従います。

## 感情の骨格

```
ワクワク → 共感 → 悩む → 発見 → 嬉しい → 感動 → 余韻
```

```
  高 │                    ◆発見             ◆感動
     │                   ／  ＼            ／  ＼
     │          ◆悩む  ／     ＼  ◆嬉しい ／     ＼
  中 │   ◆共感 ／     ＼        ＼／  ＼／        ＼
     │  ／     ＼                ▽                ＼
  低 │◆ワクワク               （谷）               ◆余韻
     └──────────────────────────────────────────────

お客さま 姿なし  目の前  ★手元  ★手元  ★手元  目の前   気配だけ
```

**山はふたつだけ**（発見・感動）。**谷はわざと作ります**（手を動かす時間）。  
★ = 前回の設計でお客さまがいなくなっていたところ。ここを取り戻します。

## 全画面に共通する、破らない3つの決めごと

### 1. 画面中央は「花の間」。UIを置かない

```
 0% ┌────────────────────────┐
    │  空の帯   季節・日／しるし   │  ← UIを置いてよい（最小限）
14% ├ ─ ─ ─ ─ ─ ─ ─ ─ ─ ─ ─ ┤
    │      花 の 間           │  ← ここにUIを置かない
    │  （花・店内・お客さま）    │     画面の 58%
72% ├ ─ ─ ─ ─ ─ ─ ─ ─ ─ ─ ─ ┤
    │  手の帯   ことば／ボタン    │  ← UIを置いてよい
100%└────────────────────────┘
```

1画面に置いてよい紙は **1枚まで**。
