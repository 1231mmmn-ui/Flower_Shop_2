# ⑥ ボタンのルール

## 1. 三段階だけ

ボタンは3種類しかありません。増やしません。

### 主ボタン ── 1画面に1つだけ

その画面で「次へ進む」ための、ただひとつの行き先。

```
大きさ   幅 220px（最小）× 高 52px
角丸     999px（完全な丸）
文字     18px 明朝 字間 0.06em
色       上 #A9BCA5 → 下 #7C9376（170°の縦グラデーション）
文字色   #FBF6EC
影       0 10px 30px rgba(96,74,54,0.14)
       ＋ inset 0 1px 0 rgba(255,253,245,0.7)   ← 上端の光
余白     左右の内側 34px
```

例: `はじめる` `扉を開ける` `わかりました` `束ねる` `包む` `お渡しする` `次のお客さまへ`

### 副ボタン ── 面を持たない、下線付きの文字

戻る・やり直す・切り替えるなど、進まない操作。

```
文字     15px 明朝 字間 0.10em
文字色   #6E6053
下線     1px rgba(124,95,68,0.18)
背景     なし
影       文字に 0 1px 12px rgba(255,250,238,0.95)（光でにじませる）
内側     上下 4px のみ（当たり判定は 44px を確保）
```

例: `花を選ぶ` `整える` `ひとつ前へ` `そっと戻す` `閉じる`

### しるし ── 輪郭だけ

いつでも行ける場所。ふだんは 62% の濃さで、ふれると 100% になる。

```
文字     13px 明朝 字間 0.14em
文字色   #6E6053（不透明度 62%）
背景     なし／下線なし
```

例: `図鑑` `♪`

---

## 2. 押したときの動き

| 状態 | 動き | 時間 |
|---|---|---|
| ふれる前 | そのまま | — |
| 指を近づける（ホバー） | 2px 浮く。影が「持ち上げた」に変わる | 0.2s |
| 押している | 1px 沈む。影が「やわらか」に戻る | 0.2s |
| 離した | 元に戻りながら、画面が切り替わり始める | 0.2s |

**弾みません。** 行き過ぎて戻る動き（バウンス）は使いません。

---

## 3. 押せないとき

```
不透明度  35%
影        やわらか（弱める）
動き      なし
```

灰色に塗ったり、×を出したり、理由を赤字で書いたりしません。  
**押せない理由は、画面を見れば分かるようにします。**
（例: 花を1本も取っていないから「束ねる」が押せない）

---

## 4. 置き場所

- 主ボタンは **手の帯の中、画面の下から 14〜80px** の間。
- 主ボタンは、**画面の横中央**（①②③⑧）か、**右寄せ**（④⑥⑦）。
  - 中央 = ゆっくり読んでから進む画面
  - 右寄せ = 作業を続けながら、いつでも進める画面
- 副ボタンは主ボタンの**左**に置きます。右には置きません
  （右手の親指の近くを、進む操作のために空けておくため）。

---

## 5. 言葉づかい

| 良い | 良くない |
|---|---|
| 束ねる | 決定 |
| 包む | 次へ |
| お渡しする | 完了 |
| そっと戻す | キャンセル |
| ひとつ前へ | 元に戻す |
| 扉を開ける | スタート |
| 閉じる | 戻る |

**動作の名前ではなく、花屋でその人がすることを書きます。**

---

## 6. 禁止

- 1画面に主ボタンを2つ以上置くこと
- 枠線だけの四角いボタン
- ボタンの中にアイコンを入れること
- 赤・橙の警告色
- 「〜しますか？」と聞く確認ダイアログ
  （取り消せる操作しかないので、確認は要りません）
- ボタンを画面の下端に貼り付けて固定すること（14px は必ず空ける）
