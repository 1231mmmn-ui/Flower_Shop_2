# ⑯ 立ち止まる時間 ── 感動の設計

**段階が変わりました。**

```
これまで   世界観を作る
ここから   感動を作る
```

動くものや演出を増やすことではなく、  
**「プレイヤーの心が動く瞬間を増やすこと」**を優先します。

---

## 1. すべての演出は、この一問で決めます

> # この演出は、プレイヤーの心を動かしているか？

```
動いていない   →   どれだけ綺麗でも、入れない
動く           →   どれだけ小さくても、入れる
```

**綺麗さは、採用の理由になりません。**

これまでの問い（花を好きになれるか／想いを考えたくなるか／花屋らしいか／
世界観を壊さないか）は、**足すかどうか**を決める問いでした。  
この問いは、**演出をひとつ書くたび**に自分に聞くものです。

---

## 2. 五つの「少し立ち止まる時間」

このゲームのいちばんの価値は、ここにあります。

```
1.  窓の外を、思わず眺めたくなる
2.  一輪の花を、しばらく見つめてしまう
3.  お客さまの言葉を、もう一度読み返したくなる
4.  ブーケが完成したあと、少し眺めていたくなる
5.  また明日も、この花屋を開けたいと思う
```

**この5つが、実装の到達点です。** 機能の数ではありません。

### いまの状態

| # | 立ち止まる時間 | いま | これから |
|---|---|---|---|
| 1 | 窓の外を眺めたくなる | **窓に季節を入れた**（→ 3章） | 季節ごとの手触りを詰める |
| 2 | 一輪を見つめてしまう | 花が画面高の55%まで大きくなる | **絵そのものを良くする**（②の10種） |
| 3 | 言葉を読み返したくなる | エプロンのメモ（設計のみ） | 実装。**押されずに、いつでも触れる**形で |
| 4 | 完成後、眺めていたくなる | 眺める間（設計のみ） | 実装。UIが3秒後に消え、束だけが残る |
| 5 | また明日も開けたい | 開店前の時間・今日の朝 | 積み重ね |

---

## 3. 窓の外 ── 「もっと動かす」ではなく「もっと季節を感じる」

**ここを取り違えないこと。**

```
×   窓の外を、もっと動かす
○   窓の外で、もっと季節を感じる
```

| 季節 | 窓の外 |
|---|---|
| **春** | 花びらが、**一枚だけ**流れる |
| **夏** | 木々が、風にゆっくり揺れる |
| **秋** | 葉が、**一枚だけ**舞う |
| **冬** | **何も動かない。** 静かな朝の空気だけ |

**どれも控えめで十分です。**

### 「一枚だけ」を、本気で守る

```
9枚   →  演出に見える。目が追ってしまう
3枚   →  景色に見える。ふと目に入る
1枚   →  記憶に残る。「あ、いま散った」
```

窓の外の花びらは、**22秒に一度、一枚だけ**流れます。  
しかも落ちているのは周期の3割ほどで、**残りの7割は何もありません。**

> 見ていない人には、一度も見えないかもしれません。**それでいい。**

数を増やしたくなったときは、**心を動かしたいのではなく、動かしたいだけ**に
なっています。手を止めて、この章に戻ります。

### 冬に、何も置かなかった理由

冬だけ、落ちるものも揺れるものもありません。  
ガラスがうっすら曇って、また澄む。それだけです。

**「静かな朝の空気」は、動かさないことで伝わります。**  
ここに雪を降らせた瞬間、冬は「雪が降る季節」になって、静けさが消えます。

## 3-2. 揺れをどうするか ── 測ってから決めた

「止める・戻す・弱める」を決めるために、**実際に何px動いているか**を測りました。

```
常時のゆれ      8.4px  （画面幅430pxのうち約2%。3秒かけて片道）
風のひと吹き   19.2px  （はっきり見える）
```

判断の枠組みはこうでした。

```
止めると成立しない            →  揺れは必要
止めても成立するが、戻すと良い  →  揺れは価値を足している
どちらでも変わらない           →  削ってよい
```

**結果は真ん中でした。** 8.4pxは、見ようとすれば見えて、見なければ気づかない大きさ。  
ちょうどいい。**弱めると、見えなくなってしまいます。**

### 問題は大きさではなく、周期でした

5.6秒の一本調子だと、30秒眺めるあいだに**5回以上くり返されます。**  
自分で書いた決めごとに、自分で引っかかっていました。

> 繰り返しに見えた瞬間、この時間は死にます。

そこで、**弱めるのではなく、くり返さないようにしました。**

| 層 | 周期 | 振れ |
|---|---|---|
| 花（速い） | 4.3 / 5.6 / 6.7 / 7.9 / 9.1 秒 | ±0.7° |
| 花全体（遅い） | 17 / 19 / 23 秒 | ±0.34° |

二つの周期が割り切れないので、見えている動きは長いあいだ同じ形に戻りません。

**測り直した結果**

```
30秒の振れ幅              15.3px
5.5秒後との差の平均        4.7px   （0に近いほど「ループ」に見える）
```

前は5.5秒でほぼ同じ位置に戻っていました。いまは戻りません。

> **動かす量を決めるより、くり返さないようにするほうが効きます。**

### ただし、すべてを直す必要はありません ── 線があります

同じ考えで他の動きも見直したところ、**直すべきものと、そのままでよいものが
はっきり分かれました。**

| | 例 | 一定周期でよいか |
|---|---|---|
| **続いている動き** | 埃・光の呼吸・木々の揺れ・花の揺れ | **よい** |
| **一度きりの出来事** | 花びらが散る・とんぼが横切る・息が白くなる | **だめ** |

理由は、**目印があるかどうか**です。

```
続いている動き   どこが「はじまり」か分からない
                 → くり返していても、人はそれに気づけない

一度きりの出来事  起きた瞬間が、はっきりした目印になる
                 → 間隔が一定だと「さっきも同じ間だった」と分かる
```

**一度きりの出来事に、CSS の `infinite` は使えません。**

| 直したもの | 前 | 後 |
|---|---|---|
| 窓の花びら・落ち葉 | 22秒ちょうど。同じ位置から | 14〜38秒。横位置も毎回ちがう |
| 赤とんぼ | 46秒ちょうど。同じ高さを | 26〜70秒。高さも毎回ちがう |
| 白い息 | 21秒ちょうど | 15〜34秒 |

**そのままにしたもの**（続いている動きなので、周期があってよい）

```
埃           26〜48秒（14粒がそれぞれ違う周期。すでにばらけている）
光の呼吸      18秒 ＋ 光の帯 26秒（重なって234秒。しかも目印がない）
木々の揺れ    13秒・19秒（同じ理由）
```

> **「動いているもの」と「起きること」は、別の決めごとで扱います。**

### 三つめの区分 ── プレイヤーに応えることは、必ず応える

二分法では足りませんでした。**プレイヤーの行いに返ってくるもの**が抜けています。

| # | 種類 | 決めごと |
|---|---|---|
| 1 | **続いている動き** | 一定周期でよい（始まりが分からない） |
| 2 | **世界が勝手に起こすこと** | 間隔をばらす（始まりが目印になる） |
| 3 | **プレイヤーに応えること** | **必ず起きる。ばらしてはいけない** |

3番の例。

```
扉のベル      札を裏返したとき      必ず
呼応セリフ    ぴったりの花が入っていたとき  必ず
笑顔          束を渡したとき        必ず
紙が下がる    花にふれたとき        必ず
```

**ここをばらしたら、世界が信用できなくなります。**  
「ふれたのに、たまに何も起きない」は、生命感ではなく**故障**です。

### 3番には、待ち時間のあるものも含みます

```
束ね終わる    →  少し置いて、光が差す
包み終わる    →  少し置いて、束が仕上がる
札を裏返す    →  0.9秒かけて返り、ベルが鳴る
```

**遅れて返ってくることはあっても、返ってこないことがあってはいけません。**  
これが「この世界は、自分の行いを受け止めてくれる」という信頼になります。

```
世界が勝手にすることは、読ませない。
プレイヤーに応えることは、必ず応える。
```

### 見落としていた実例

⓪感情設計書の【余韻】に、こうあります。

> お客さまが帰ったあと、店が静かになる1.5秒。**カウンターに、花びらが一枚残っている。**

これは2番なのに、設計上**毎回必ず**起きます。間隔が一定どころか**100%予測できます。**  
2日目には「ああ、また花びらか」になります。

**三日に二日くらい**に直します。残っていない日があるから、残っている日が目に入ります。

## 4. 心が動かない演出の、見分け方

書いたあとで、この4つに当てはまっていないか確かめます。

| 当てはまったら | それは |
|---|---|
| **気づかせようとしている** | 演出です。景色ではありません |
| **目で追える速さ・数になっている** | 見せ物です |
| **毎回きっかり同じところで起きる** | 仕掛けです |
| **「すごい」と思わせたい** | こちらの手柄です |

心が動く演出は、逆になります。

```
気づかない人がいてよい
目で追えないくらい、ゆっくり
いつ起きるか分からない
「きれいだな」で終わってよい
```

**このゲームで、プレイヤーに「すごい」と思わせる必要はありません。**

## 5. 立ち止まる時間を、邪魔しないための決めごと

せっかく立ち止まっても、こちらが急かせば台無しになります。

```
□ 自動で次へ進めない
□ 「次へ」を光らせない、震わせない
□ 滞在時間を数えない
□ 見なかった人に、何も損をさせない
□ 立ち止まった人に、ご褒美を出さない   ← これも同じくらい大事
```

**最後のひとつが抜けやすい。**  
眺めていたらご褒美が出た瞬間、**眺めることが作業に変わります。**

### 測ることの危うさと、その扱い

「眺める間」の二案を選ぶために、滞在秒数を測っています（→ 6章）。  
これは**上の決めごとと矛盾しかねません。**

```
滞在時間を測る  →  滞在時間を伸ばす設計につながる
                  それは、このゲームがいちばん避けたいもの
```

だから、こう扱います。

```
□ 測るのは、設計をひとつ選ぶあいだだけ
□ 決まったら、測る仕組みを丸ごと外す
□ ただし「何を比べ、何を理由に選んだか」は設計書に残す
```

**三つめが大事です。** 数字は消えても、判断の理由は残る。  
一年後の自分は、数字を覚えていません。**理由だけが、このゲームを守ります。**

---

## 6. 「眺める間」の二案 ── 比べ方

```
自動版   完成の3秒後、UIがひとりでに消える
手動版   プレイヤーがふれたときに、UIが消える
```

札・メモ・カードは、どれも「プレイヤーが自分で決める」形でした。  
その一貫性からすれば手動版ですが、**余韻は自動のほうが強いかもしれません。**  
決められないので、**両方作って測ります。**

### 測るもの（主と副を、はっきり分ける）

| | 測るもの | 役目 |
|---|---|---|
| **主** | **花だけになってから、次の操作までの秒数** | これがこのゲームの価値 |
| 副 | 画面に入ってから、出るまでの秒数 | 裏づけ |

**一度は「合計だけ見ればよい」と考えましたが、誤りでした。**

```
自動版   UIあり 3秒 ＋ 束だけ 8秒  = 11秒
手動版   UIあり 6秒 ＋ 束だけ 8秒  = 14秒
```

合計では手動が勝ちますが、**束を見ていた時間は同じ**です。  
合計だけ見ると「UIを長く読んだ」ことを「余韻が良かった」と読み違えます。

### 比べ方の決めごと

```
□ 4日ずつまとめて案を入れ替える（日ごとに替えない）
□ 各ブロックの初日は、集計から外す
□ 手動版では「束にふれたか」を別に記録する
□ 主指標は「束だけの時間」。合計は裏づけにしか使わない
□ 遊ぶのは人。この数字は、こちらでは作れない
□ 決まったら、測る仕組みは外す。理由だけ残す
```

### 一日ごとの入れ替えをやめた理由

最初は一日ごとに替えるつもりでした。**穴が二つありました。**

```
1.  「昨日と違う」こと自体が、体験に混ざる

2.  手動版の初日、プレイヤーは「束にふれると消える」ことを知らない
      → 束だけの状態に一度も入らない
      → 主指標が 0秒 になる
      → それは「眺めたくなかった」ではなく「知らなかった」
```

**2番のほうが重い。** 設計の善し悪しではなく、**分かりにくさを測ってしまいます。**

しかも、こちらから「ふれてください」とは言えません。  
それは札もメモもカードも守ってきた「押させない」の、ちょうど逆だからです。

だから「ふれたかどうか」を別に記録して、**0秒の意味を二つに分けます。**

### そして、この数字は判定者ではありません

遊ぶ人は1人、日数も数日。**これは統計ではありません。**

```
数字が決める     ×
数字が確かめる   ○
```

遊んだ感触と数字が同じ向きなら、そのまま採用。  
**食い違ったときだけ、もう一度見る。** それが唯一の使い道です。

数字を主役にすると、こんどは**数字のために設計してしまいます。**

## 7. 実装中の、確かめ方

演出をひとつ書いたら、これで確かめます。

```
□ 声に出して「これは心を動かすか」と聞いて、はいと言えるか
□ 5つの立ち止まる時間の、どれかに効いているか
□ 気づかない人がいても、成立するか
□ 気づいた人に、ご褒美を出していないか
```

**1つめが「いいえ」なら、どれだけ綺麗でも消します。**

## 8. 迷ったら

```
×   何か新しい演出を足せないか
○   一輪の花を、もっと好きになれる方法はないか
```

そして、いちばん最後に戻る問い。

> # 好きな花は、できましたか？

この問いに、プレイヤーが自然と「はい」と答えられる体験を、  
**一つずつ積み重ねていきます。**
