# ⑪ 感情設計書 ── プレイヤーの心の動き

この文書が、このゲームの**最優先の設計図**です。  
画面・色・動きは、すべてここに書かれた感情を起こすための手段です。

判断に迷ったときは、01〜10ではなく**この文書に従います**。

---

## 1. 感情には、順番がある

感情は「良いものを並べれば起きる」ものではありません。**前の感情との差**で起きます。

- **達成感**は、その前に**迷い**がないと生まれません。
- **発見**は、その前に**分からない時間**がないと生まれません。
- **感動**は、その前に**静かな作業の時間**がないと生まれません。
- **余韻**は、その前に**山**がないと生まれません。

だから、このゲームには意図的に**谷**を作ります。  
谷とは、退屈でも不快でもなく、**心が平らになっている時間**のことです。

---

## 2. 一回の遊びの、感情曲線

```
感情の高さ
  高 │                        ◆発見              ◆感動
     │                       ／  ＼             ／  ＼
     │                      ／    ＼   ◆達成  ／     ＼
  中 │        ◆共感  ◆迷い ／      ＼ ／  ＼ ／        ＼
     │      ／     ＼／                ▽        　        ＼
  低 │ ◆期待                        （谷）                 ◆余韻
     └──────────────────────────────────────────────────────
       ①②     ③      ④      ⑤      ⑥⑦     ⑧完成   ⑧眺める間
       0:30   1:00   2:30   3:30    5:00    7:00      8:00

       ↑ 静    ↑ 動   ↑ 動   ↑ 山①   ↑ 谷    ↑ 山②    ↑ 静
```

**山はふたつだけ。**（発見と感動）  
山を3つ以上作ると、どれも印象に残りません。

一回 **8分前後**。うち **3分半が花を見ている時間**（④⑤）になるよう配分します。

## 3. 七つの感情の設計

### 【期待】「今日はどんなお客さまが来るのだろう」── ①タイトル・②店内

| | |
|---|---|
| **なぜ起きるか** | まだ誰もいない店に、自分だけがいるから。空席は期待を生みます |
| **強さ** | 弱くていい。ここで盛り上げると、後の山が下がります |

**仕掛け**

1. **扉を閉めたまま始める。** 店内は見えているが、まだ誰も来ていない。
2. カウンターに、**今朝切ってきた花のカゴ**を置く。誰かのために用意された感じ。
3. 窓の外の季節を見せる。「今日はどんな日か」を先に知らせる。
4. ボタンの言葉を「はじめる」ではなく **「扉を開ける」**にする。開ける主体はプレイヤー。
5. 2日目以降、**前日の余韻を1行だけ持ち越す**。
   > 昨日のはるかさん、喜んでくれたでしょうか。

**殺すもの**

- ロゴのアニメーション／音楽の盛り上がり／「タップしてスタート」
- 「今日のお客さま: はるかさん」と先に見せること（**誰が来るかは、開けるまで分からない**）

**確かめる問い**: 扉を開ける前に、一呼吸おく人がいるか。

---

### 【共感】「この人を笑顔にしたい」── ③会話

| | |
|---|---|
| **なぜ起きるか** | 目的ではなく、**その人の暮らし**が見えたとき |
| **強さ** | 中。ここは山にしない。山にすると、花を選ぶ前に満足してしまう |

**仕掛け**

1. **要望より先に、事情を話してもらう。**
   > ×「明るい花束をください。予算は2,000円です」  
   > ○「同僚の誕生日プレゼントにしたくて。あの子、笑うと本当に元気が出る子なんです」

2. **セリフを1行ずつ、0.55秒間隔で出す。** これは「話を聞いている速度」です。
   全部同時に出すと、読む作業になります。

3. **少し言いよどませる。** 完璧に説明する人は、現実にいません。
   > 「……その、大事な話をするので。」

4. **要望を箇条書きにしない。** メモは紙一枚・3行まで。
   条件表にした瞬間、お客さまは「発注書」になります。

5. お客さまは**必ず、渡す相手のことを話す**。自分のために買う人は8人中1人だけ。

**殺すもの**

- 要望を「条件」として並べること（○○の花／○○円以内／○○な雰囲気）
- 適合度・達成率の表示
- お客さまが毎回同じ話し方をすること

**確かめる問い**: 遊んだ人が、お客さまの名前を覚えているか。

---

### 【迷い】「どれが似合うかな」── ④花選択

| | |
|---|---|
| **なぜ起きるか** | **どれも正解だから。** 選べない苦しさではなく、選び放題の贅沢 |
| **強さ** | 中。長く続く。ここがいちばん長い時間 |

**仕掛け**

1. **正面の一輪だけが美しく見える。** 隣は少しぼける。
   → 「隣も見たい」が生まれ、横に流す手が止まらなくなる。
2. **どの花にも、必ず「おすすめの用途」がある。** 外れの花を作らない。
3. **予算は「めやす」であって上限ではない。** 超えても止められないし、叱られない。
   → 迷いが、罰への恐れに変わらない。
4. 21種を **1周およそ20秒**で流せる速さにする。多すぎると、迷いが疲れになります。
5. 取った花は、**数字ではなく小さな粒**で示す。数えさせない。

**殺すもの**

- 適合度・★・「この花は向いていません」
- おすすめの花を光らせること
- 残り予算が赤くなること

**確かめる問い**: 一度取った花を、戻してから別の花を取る人がいるか。  
（迷いが起きている、いちばん確かな証拠です）

---

### 【発見】「この花がぴったりだ」── ⑤花詳細

**この感情が、このゲームでいちばん大切です。**  
→ 設計が長いので、次の章（4章）にまとめます。

---

### 【谷】手を動かす時間 ── ⑥ブーケ・⑦ラッピング

**ここは、あえて感情を上げません。**

| | |
|---|---|
| **なぜ必要か** | 山②（感動）を立てるため。平らな時間がないと、次の山が山に見えない |
| **心の状態** | 集中。無心。手が動いているだけ |

**仕掛け**

1. **新しい情報を出さない。** ここで花言葉や助言を見せない。
2. **音を減らす。** ピアノの音数を半分にし、風の音だけを残す。
3. **決断を求めない。** 整えるボタンを押せば、それなりに整う。
4. ただし**手で動かせる**ようにしておく。動かした人だけが、あとで「自分が作った」と思える。
5. 包み紙を替えると、**束の印象が本当に変わる**。ここが唯一の小さな驚き。

**殺すもの**

- ここに演出を足すこと（きらめき、拍手、効果音）
- 「あと○本でバランスが良くなります」という助言

**確かめる問い**: この時間を「退屈」ではなく「静か」と言う人がいるか。

---

### 【達成】「素敵なブーケができた」── ⑦の終わり〜⑧の直前

| | |
|---|---|
| **なぜ起きるか** | **自分の手が加わった証拠**が、目に見えるから |
| **強さ** | 中の上。山②の助走 |

**仕掛け**

1. 包み終わった瞬間、**一拍おく（0.4秒の無音）**。すぐ次へ行かせない。
2. その一拍のあと、**束にだけ光が当たる**（0.62秒）。
3. **「お渡しする」を押すのはプレイヤー。** 自動で進めない。
   → 「これで完成だ」と決めるのは、プレイヤーの権利です。
4. 束の値段は出すが、**評価はまだ出さない**。ここで点をつけたら達成感が消えます。

**殺すもの**

- 点数・星・「完成度」
- 完成時の派手なエフェクト（達成感は、静けさの中でこそ立ちます）

**確かめる問い**: 「お渡しする」を押すまでに、間があるか。

---

### 【感動】「喜んでもらえて良かった」── ⑧完成

| | |
|---|---|
| **なぜ起きるか** | お客さまが、**ブーケの話ではなく「これからの話」**をするから |
| **強さ** | 最高。この日のいちばん高いところ |

**仕掛け**

1. **順番を守る。** 花のしるし（笑顔）より先に、**言葉**を出す。
   点が先に出ると、その瞬間に「評価画面」になります。

   ```
   受け取る（0.9s） → 一拍（0.4s） → 光が差して笑顔（1.1s）
     → 言葉（1行ずつ） → 花のしるしが灯る → 紙（褒める→助言）
   ```

2. **お客さまは、ブーケを褒めない。** 渡したあとの未来を話します。
   > ×「素敵なブーケですね」  
   > ○「これを渡したら、あの子どんな顔するかな。」  
   > ○「今日はいい話ができそうです。」

3. **褒めるが先、助言は後。** 紙の中は、必ずこの順。
4. **発見していた人には、呼応セリフが出る**（→ 4章）。
5. 笑顔は必ず出る。ただし**言葉の温度は3段階**あり、それが唯一の差です。

**殺すもの**

- 点数発表、比較、ランキング
- 「もっとこうすれば良かったですね」を先に言うこと
- お客さまの反応が毎回同じであること

**確かめる問い**: 遊んだ人が、お客さまのセリフを引用できるか。

---

### 【余韻】「また明日も花を選びたい」── ⑧のあと

| | |
|---|---|
| **なぜ起きるか** | **終わりきらないから。** きれいに終わると、そこで満足してしまう |
| **強さ** | 弱い。でも、いちばん長く残る |

**仕掛け**

1. **眺める間。** 紙が出そろって3秒後、UIが1.1秒かけて全部消え、
   **ブーケと笑顔だけが残る**。画面にふれると戻る。
   → ここでスクリーンショットが撮られます。撮りたくなる瞬間を、こちらから用意します。

2. **自動で次へ進めない。** 「次のお客さまへ」を押すのはプレイヤー。

3. お客さまが帰ったあと、**店が静かになる時間**を1.5秒だけ作る。
   カウンターに花びらが一枚残っている。

4. **引き止めない。**
   > ×「明日も来てね！」「ログインボーナス」  
   > ○「また来月、寄らせてもらいますね。」

5. 図鑑に**一行だけ増える**。数字ではなく、出会った記録として。

**殺すもの**

- 通知、デイリーボーナス、連続記録
- 「明日は○○が来ます」という予告（期待は、開けるまで取っておく）
- 終了時のまとめ画面

**確かめる問い**: 閉じたあと、もう一度開く人がいるか。**その日のうちに開かないほうが良い**  
（余韻とは、時間をおいて効くものです）。

## 4. 【発見】の設計 ── このゲームの心臓

### 発見とは何が起きているのか

```
お客さまの言葉（3章で聞いた）  ┐
                            ├→ プレイヤーの中で結ばれる → 「あ」
花言葉（5章で読んだ）         ┘
```

**結ぶのはプレイヤーです。ゲームは絶対に結びません。**

### 発見の三条件

1. **手がかりは、お客さまの言葉の中にある。** システムのヒントではない。
2. **答えは、花の側にある。** 花言葉・旬・おすすめ用途のどれか。
3. **その二つを結ぶ線を、ゲームは一度も引かない。**

3つ目を破った瞬間、発見は死にます。「おすすめ！」の2文字で終わります。

### 呼応表（お客さま × 花言葉）

8人それぞれに、**言葉が呼応する花**を用意します。ゲームはこれを指し示しません。

| お客さま | 言葉の中の手がかり | 呼応する花 | 花言葉 |
|---|---|---|---|
| はるか（同僚の誕生日） | 「笑うと本当に元気が出る子」 | ヒマワリ | 憧れ・あなただけを見つめる |
| なおき（恩師の退官） | 「四年間、ずっと見守ってくださった」 | トルコキキョウ | 優美・希望・**感謝** |
| さとみ（毎週の食卓） | 「長もちして」「次の金曜まで」 | アルストロメリア | **持続**・未来への憧れ |
| よしこ（月命日） | 「派手なのは好まない人でした」 | ユリ | **純粋**・無垢 |
| めい（春から家を出る） | 「春から家を出るので、その前に」 | スイートピー | **門出**・優しい思い出 |
| りん（自分のための花） | 「あると一日が違うんです」 | ユーカリ | **再生**・新生 |
| かおる（新居） | 「家族みんなで見られるような」 | アジサイ | **家族団らん**・和気あいあい |
| そうた（入院中の親友） | 「元気が出るものがいいな」 | ガーベラ | **希望**・前進 |

### 呼応セリフ

呼応する花が入っていたとき、**ブーケの感想より先に**、その一言が出ます。

| お客さま | 呼応セリフ |
|---|---|
| はるか | 「ヒマワリ。……あの子、まさにそういう子なんです」 |
| なおき | 「先生、この花の花言葉をご存じでしょうか」 |
| さとみ | 「これなら、来週の金曜まで咲いていてくれますね」 |
| よしこ | 「まぁ、ユリ。あの人が最初にくれた花です」 |
| めい | 「門出……。母、送り出すのが寂しいって言ってました」 |
| りん | 「再生、ですか。ちょっと、今の私に効きますね」 |
| かおる | 「家族団らん。……いい花言葉ですね」 |
| そうた | 「ガーベラ。あいつが昔、好きだって言ってた花です」 |

**この8行が、このゲームでいちばん大事な文章です。**

### 発見しなかった人のために

- **損をさせません。** 呼応花が入っていなくても、笑顔も感想も同じように返ります。
- 呼応セリフが出ないだけ。**「取り逃した」と気づかせません。**
- 図鑑で花言葉を読み返せるので、**あとから気づく道**を残します。
  > 「あ、あのときスイートピーを入れていれば」──この後悔は、次の日を作ります。

### 発見の瞬間に、音を鳴らさない

効果音を鳴らすと、**気づいたのはシステムだった**ことになります。  
気づいたのはプレイヤーです。だから**沈黙**にします。

## 5. 長い時間の感情

一日ではなく、何日も遊んだときの心の動きです。

| 時期 | 起きること | 感情 |
|---|---|---|
| 1日目 | 初めての店。初めてのお客さま | 驚き |
| 2〜4日目 | 花の名前を覚え始める | 慣れ・安心 |
| 3日目ごろ | 同じお客さまが再訪する | **「あ、この人また来た」** |
| 5日目 | 窓の外が変わる（春→夏） | **「もう季節が変わったのか」** |
| 7日目ごろ | 旬の花が入れ替わる | 新しい迷い |
| 12日目ごろ | 図鑑が半分埋まる | 集める楽しみ |
| 20日目ごろ | 8人 × 四季を一巡 | 愛着 |

### 提案：再訪したお客さまが、前回に触れる

長く遊ぶ理由として、**これがいちばん強い**と考えています。

> 「この前いただいた花、母がまだ飾ってくれてます」  
> 「先生、あの花束を研究室に置いてくださって」

- 前回そのお客さまに渡した束の**印象（明るい／静か／ナチュラル）を1つだけ覚えておく**
- 2回目以降の来店で、その一言を添える
- 点数は覚えない。**覚えるのは「どんな束だったか」だけ**

これが入ると、お客さまが「機能」から「知り合い」に変わります。  
実装は承認後で構いませんが、**データ構造だけは最初から用意しておきたい**項目です。

## 6. 感情を殺す12のこと

ひとつでも入れたら、そこで設計が崩れます。

1. 点数・星・達成率を出す
2. 正解の花を指し示す
3. 「失敗」という言葉を使う
4. 自動で次の画面へ進む
5. お客さまの反応が毎回同じ
6. 要望を箇条書きの条件表にする
7. 花を小さく表示する
8. 読み込みの待ち時間を見せる
9. 完成時に派手な演出を出す
10. 助言を、褒め言葉より先に出す
11. 「明日は○○が来ます」と予告する
12. 通知・デイリーボーナス・連続記録

## 7. 感情が起きているかの、確かめ方

点数では測れません。**遊んでもらって、次の3つを見ます。**

| 見るもの | 何が分かるか |
|---|---|
| 一度取った花を戻して、別の花を取ったか | **迷い**が起きた |
| 花詳細の画面で、3秒以上止まったか | **発見**が起きかけている |
| 「お渡しする」を押すまでに間があったか | **達成感**がある |
| 眺める間に、画面を撮ったか | **感動**がある |
| お客さまの名前を覚えているか | **共感**があった |
| その日は開かず、翌日また開いたか | **余韻**がある |

遊んだ人に聞く質問は、**「面白かったですか」ではなく**、

> **「どの花を選びましたか。それはどうしてですか」**

これに物語で答えられたら、感情設計は成功しています。
