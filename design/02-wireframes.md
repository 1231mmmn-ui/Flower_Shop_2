
> **目的がないことが、この画面の目的です。**

### ここは「探す場所」ではなく「見て回る場所」です

⓪-b とまったく同じ棚、同じ動き。違うのは、上に一行あることだけです。

```
□ 絞り込み・並べ替え・検索を作らない
□ 望みに合う花を光らせない
□ 「おすすめ」を出さない
□ 合わない花に印を付けない（外れの花を作らない）
□ 呼応する花は、必ずその日の棚にある（意地悪にしない）
```

**探す作りにすると、「花 → 人」の発見（60%）が起きなくなります。**  
見て回っていたら思い出した、という順番を守ります。

### 決めごと

| | |
|---|---|
| **花言葉は、いつでも読める** | 買わなくても、使ったことがなくても読めます |
| **★は3つだけ** | 値段・香り・日もち。**相性には★を付けない** |
| **相性は絵で** | 名前だけの行にしない。ふれると、その花のページへ |
| **説明の1行は、ここには出さない** | 「暖房を使うので冬は高い」は⑨アルバムのほうへ |
| **♡は音を鳴らさない** | ご褒美にしないため |
| **♡を押しても、何も増えない** | 数も、印も、通知も出ません |

> **この紙に、覚えさせる言葉を置きません。**
> 「花言葉を覚えましょう」「豆知識」は、ひとつも書きません（→ ⑭冒頭 二．）。

### ⓪-b と ⑨ から来たときの違い

```
④ から  →  「そっと戻す」「この花を取る」
⓪-b から →  「戻る」だけ（取れません。まだ開店していないので）
⑨ から  →  「閉じる」だけ（買う場面ではないので）
```

**花の見え方は、どこから来ても同じ**です。ボタンだけが変わります。

## 実装のあいだ、いちばん上に置く二つ

```
一．花の数を増やすことより、一輪一輪を好きになれることを優先する
二．覚えさせない。好きになった結果、覚えていた
```

画面を作っていて迷ったら、**その画面がこの問いに近づくか**で決めます。

> **好きな花は、できましたか？**
