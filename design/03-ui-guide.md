# ③ UIデザインガイド

## 1. UIの役目

UIは、花を見るための**額縁**です。絵ではありません。

だから、この3つを守ります。

1. **UIは、必要になった瞬間にだけ現れる。** 常に出しておかない。
2. **UIは、花より手前に出ない。** 花にかぶるUIを作らない。
3. **UIは、消えても遊べる。** 消したときに何が起きているか分からなくなる画面は、作り直す。

---

## 2. 面（サーフェス）は3段階だけ

面を増やすと、画面はすぐ「メニュー」になります。使えるのは3つだけです。

### 段階0 ── 光（いちばん多く使う）

面を持ちません。文字のうしろに、店内の光がにじんでいるだけ。

```
背景: 楕円のグラデーション
      中心 rgba(255,252,244,0.94) → 外 rgba(255,252,244,0)
影:   文字に 0 1px 12px rgba(255,250,238,0.95)
```

**使うところ**: 季節・日、花の名前、値段、お客さまの言葉、道具の文字、注記。  
つまり **UIの8割**。

### 段階1 ── 紙（1画面に1枚まで）

木のカウンターに置かれた、一枚の紙。

```
背景:   linear-gradient(172deg, rgba(253,249,238,0.92), rgba(246,238,221,0.88))
角丸:   16px
影:     0 6px 18px rgba(96,74,54,0.10)
内側:   22px
傾き:   -0.6°（手で置いた感じ。会話メモと完成メモだけ）
```

**使うところ**: ③のメモ、⑤の花の説明、⑧の感想、⑩の設定。

### 段階2 ── ガラス（例外）

半透明でぼかしのかかった面。**⑤花詳細の紙**だけに使います。
背景を暗くしている画面なので、紙よりもう少し不透明にします。

```
背景:   rgba(250,245,236,0.975)
ぼかし: backdrop blur 14px
角丸:   24px
```

> **禁止**: 段階1と段階2を同じ画面に同時に置くこと。面が2枚見えたら作り直します。

---

## 3. 角丸

| 用途 | 値 |
|---|---|
| 小さなしるし・値札 | 10px |
| 紙・カード | 16px |
| 大きな紙 | 24px |
| いちばん大きな面 | 32px |
| ボタン・粒 | 999px（完全な丸） |

**この5つ以外は使いません。**

---

## 4. 影

光源は**左上**。だから影は**右下**に落ちます。例外なし。

| 名前 | 値 | 使うところ |
|---|---|---|
| やわらか | `0 6px 18px rgba(96,74,54,0.10)` | 紙、値札 |
| 置いた | `0 10px 30px rgba(96,74,54,0.14)` | カード |
| 持ち上げた | `0 18px 44px rgba(96,74,54,0.22)` | 押している最中のボタン |
| 花 | `drop-shadow(5px 10px 12px rgba(96,74,54,0.20))` | 花・お客さま・小物 |
| 内側の光 | `inset 0 1px 0 rgba(255,253,245,0.7)` | ボタンの上端 |

影に**黒**（#000）は使いません。かならず木の色（96,74,54）を薄めたものにします。

---

## 5. 線

線は、ほとんど引きません。引くのは2か所だけ。

- 紙の中の区切り: `1px rgba(124,95,68,0.10)`
- 文字ボタンの下線: `1px rgba(124,95,68,0.18)`

**枠線でボタンを作りません。** 囲むと、その瞬間に「フォーム」になります。

---

## 6. 情報の量

1画面に置ける文字の上限を決めます。

| 場所 | 上限 |
|---|---|
| 空の帯 | 1行・15文字 |
| 花の間 | 3行まで（お客さまの言葉のみ） |
| 手の帯 | 5行 |
| 紙の中 | 8行 |
| **1画面の合計** | **14行** |

数えて超えたら、**減らすのではなく、次の画面へ送ります。**

---

## 7. しるし（アイコン）

アイコン画像は使いません。**日本語の短い言葉**にします。

- 図鑑 → 「図鑑」
- 音 → 「♪」（切のときは斜線を重ねる）
- 戻る → 「← 閉じる」

理由: 半写実の水彩の中に、線画のアイコンが入ると急に「アプリ」になるからです。

---

## 8. 状態の見せ方

| 状態 | 見せ方 | 使わないもの |
|---|---|---|
| 押せる | ふつうの濃さ | — |
| 押せない | 不透明度 35% | 灰色に塗る／×印 |
| 選んでいる | 5px 手前に出る＋影が濃くなる | 枠で囲む／色を反転 |
| 数が増えた | 小さな粒が1つ増える | 数字のバッジ |
| 予算を超えた | 文字の色が桃色に寄る | **赤／警告／！** |
| 読み込み中 | 何も出さない（画像が出るまで背景のまま） | ぐるぐる回るもの |

---

## 9. 触れる大きさ

- 指で押すところは **44 × 44px 以上**。
- 花そのものは例外で、見た目どおりの大きさで押せます（花は大きいので問題になりません）。
- 押せるところと押せないところが、見た目で区別できること。
  区別できないときは、押せるほうを 5px 手前に出します。

---

## 10. この画面は正しいか、を確かめる6つの問い

新しい画面を作ったら、必ずこれに答えます。ひとつでも「いいえ」なら作り直します。

1. 開いた瞬間、最初に目に入るのは花か店内か
2. 花と店内が、画面の 55% 以上を占めているか
3. 面（紙・ガラス）は 1枚以内か
4. 主ボタンは 1つだけか
5. 文字は 14行以内か
6. UIを全部消しても、絵として成立するか
