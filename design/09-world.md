# ⑨ 世界観ガイド

## 1. このゲームは何か

> **誰かを想って、花を選ぶ時間。**

ジャンルは **「心を贈るシミュレーションゲーム」**。主題は **「想いを届けること」**。

ブーケを作るゲームではありません。  
**お客さまと、その先にいる贈られる人。二人を想いながら花を選ぶ**ゲームです。

プレイヤーが遊び終えたあと、**「今日、花屋に寄ってみようかな」**と思うこと。  
それがこのゲームの、唯一の成功です。

---

## 2. 場所

小さな街の、木造の花屋。**一軒だけ。**

- 間口はせまく、奥に長い。
- 正面に大きな窓があり、そこから一日じゅう光が入る。
- 手前に、使い込まれた木のカウンター。
- 天井から、乾いた花と灯りが下がっている。
- 右手にラッピングの棚。紙のロールとリボンの巻き。
- カウンターの上には、はさみ、麻ひも、じょうろ。

**この店から、一度も外へ出ません。** 地図も、他の店も、街も出てきません。

### 市場だけは、外にあります

花屋は毎朝、市場へ仕入れに行きます。**でも、市場の画面は作りません。**

```
見せない   市場そのもの（外に出てしまう）
見せる     市場から帰ってきた、カウンターの上のカゴ
```

朝いちばん、カウンターに**今朝の入荷**が置かれています。  
「シャクヤクが入りました」「デルフィニウム、今日だけ」。**それだけです。**

これは育成ではありません。**今日の棚が、日によって少し違う**というだけの仕掛けです。  
（温室はなくしました → ⑫お客さま設計書 9-2章）

---

## 3. 時間

- 一日にひとり、お客さまが来ます。
- 5日で季節がひとつ進みます。
- 窓の外だけが変わります。**桜 → 青空 → 紅葉 → 雪。**
- 時計はありません。「朝」「昼下がり」といった言葉も、なるべく使いません。

**日付は、内側にだけ持ちます。**（→ ⑫お客さま設計書 7章）

```
画面に出す     春・3日目
内側に持つ     2027.5.12（金）
```

日付があると、常連さんの曜日が本物になり、季節の行事が来て、  
アルバムが時系列になります。**でも、画面には大きく出しません。**  
日付が意味を持つのは、**あとから見返したとき**だけで十分です。

---

## 4. 光

**光源は、左上の窓。ひとつだけ。**

画像の影も、UIの影も、すべてこの一つの光に従います。
影は右下に落ちます。例外はありません。

光は季節でわずかに色を変えます（→ 04-color.md）。
一日のうちで光が動くことはありません。**ずっと、いちばんきれいな時間です。**

## 5. 手ざわり

このゲームに出てくるものは、すべて**触れる質感**を持っています。

| もの | 手ざわり |
|---|---|
| カウンター | ざらついた木。角が丸くなっている |
| 花びら | 薄く、光を通す。指で押すと戻る |
| 茎 | 冷たく、少し湿っている |
| ガラスの花瓶 | つるりとして、水の重みがある |
| クラフト紙 | かさりと鳴る |
| サテンのリボン | なめらかで、すべる |
| 和紙 | 繊維が見える。光を通す |
| 麻ひも | ちくちくする |

**つるつるした、量産品の質感**（プラスチック、金属、ガラスの板）は出しません。

## 6. 人

### お客さま

**二種類います**（→ ⑫お客さま設計書）。

```
一期一会のお客さま  ──  人生の節目を持ってくる（100人以上・上限なし）
常連のお客さま      ──  暮らしの繰り返しを持ってくる（12人・ここは増やさない）
```

それぞれに、暮らしと、渡す相手がいます。

- 同僚の誕生日を毎年こっそり祝う人
- 孫の発表会のために、月に一度来るおばあさん
- 理由もなく、妻に花を買っていく定年後の人
- 家族の食卓に、毎週金曜に花を飾る人
- 春から家を出る前に、母に渡したい高校生
- 入院している親友に会いに行く人
- **散歩の帰りに、日曜だけ一輪買っていく人**
- **玄関に置くためだけに、毎週木曜に来る人**

**面白さは、花の数ではなく、人生の数です。**  
花は21種のままでも、人生が100通りあれば、100通りの選び方になります。

**共通していること**:

- 誰かのために花を買いに来る（自分のために買う人も少しいます）
- 急いでいない
- 花に詳しくない人もいる
- **どんな束を渡しても、必ず笑顔で受け取る**
- **常連さんは、前に渡した束を覚えている**（一言だけ触れる）

### プレイヤー

この店の店員です。名前も顔もありません。**手だけが、たまに見えます。**

## 7. 言葉

- 敬体（です・ます）で書きます。
- 主語を省きます。「あなたは〜」と呼びかけません。
- 命令しません。「〜してください」より「〜できます」。
- 説明しすぎません。分からないことがあっても、それは味です。
- **感嘆符は、お客さまのセリフの中だけ。**

### 扱わないテーマ

```
月命日   お墓参り   葬儀   亡くなった家族   離婚   事故   病気の悪化
```

死と、強い喪失感を直接あつかいません。切なさは扱いますが、
**「その人と、また会えるか」**を見分けの基準にします（→ ⑫お客さま設計書 2章）。

### 絶対に書かない言葉

```
失敗   間違い   もう一度   足りない   残念   だめ   × ！注意
ミス   減点     ランキング  ノルマ     期限    急いで
```

## 8. このゲームに無いもの

指示にあったものを、そのまま守ります。

- ガチャ
- ランキング
- 対戦
- 時間制限
- 焦らせる演出
- 広告
- 派手なエフェクト
- 赤文字の警告
- 失敗して怒るお客さま
- ストレスを与えるしくみ

加えて、こちらで決めたもの:

- レベル、経験値、称号
- 連続ログイン記録
- 通知
- 他のプレイヤー
- 「あと◯日」という表示

## 9. 新しいものを入れるときの、5つの問い

**「ゲームとして面白いか」は、判断の基準にしません。**  
基準は **「本当にこの花屋に存在しそうか」**、そして **「優しい気持ちで閉じられるか」** です。

```
□ 1. 本当にこの花屋に、自然に存在するものか
□ 2. お客さまとの関係が、深まるか
□ 3. プレイヤーが、渡す相手を想像できるか
□ 4. 花そのものを、もっと好きになれるか
□ 5. 遊び終わったあと、優しい気持ちでゲームを閉じられるか
```

**5つめは、1〜4より上に置きます。**  
1〜4は「この花屋にあるか」を見る問い。5つめだけが、**閉じたあと**を見ています。

花屋に実在しても、5つめで落ちるものがあります（売れ残り、廃棄、不満そうな顔）。  
ひとつでも「いいえ」なら、採用しません。  
判定の例は ⑫お客さま設計書 9章にあります。

## 10. 参考にする空気

- 花屋に入った瞬間の、水と青い匂い
- 雨の日の、店先の静けさ
- 花を選んでいるあいだ、店員が黙って待ってくれている時間
- 包んでもらうのを、横で見ている時間
- 帰り道、花を抱えて歩く時間

**このゲームは、この5つの時間を再現するために作ります。**
