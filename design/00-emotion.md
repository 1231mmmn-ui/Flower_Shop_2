# ⓪ 感情設計書 ── このゲームの骨格

**この文書が、すべての出発点です。**  
画面も、カメラも、色も、動きも、ここに書かれた感情を起こすための手段にすぎません。

判断に迷ったときは、他のどの文書でもなく、**この文書に従います**。

---

## 1. このゲームの主題

> **「花を知り、花を好きになり、その花で誰かの想いを届けるゲーム」**

**この順番が、いちばん大事です。**

```
花を知る  →  花を好きになる  →  その花で、誰かの想いを届ける
  ↑ ここが入口
```

ジャンルの名前は **「心を贈るシミュレーションゲーム」**。

### 花と人生の割合

```
花    60%   ← 主役であり、入口
人生  40%   ← 花に意味を与えるもの
```

**前の版では、この順番が逆でした。** 人生 → お客さま → 感情 → 花 と積んでいて、
**花が最後に来ていました。** 花が、想いを運ぶための道具になっていました。訂正します。

これは **「人生を知るゲーム」ではありません。**  
花の設計は **⑭花の設計書（14-flowers.md）** にまとめました。この文書と同じ高さに置きます。

### 誰を想うのか

**お客さまだけではありません。** プレイヤーは、二人のことを同時に想います。

```
プレイヤー  →  お客さま  →  贈られる人
                （目の前）    （画面に出てこない）

              「この人が                「この人は
               どう想っているか」        どんな人だろう」
```

**お客さまだけに寄りすぎないこと。**  
お客さまは、想いを預けに来た人です。想いの行き先は、その先にいます。

```
想いが生まれる（お客さまの中）
        ↓
想いを預かる            ← ここがこのゲーム
        ↓
花という形にする
        ↓
想いが届く（贈られる人へ）
```

このゲームは、**この一本の道**を作るためにあります。

### 「主役」と「主題」は別のもの

| | 何か | どこにあるか |
|---|---|---|
| **主役** | 花 | **画面の上**。いちばん大きく、いちばん美しく映るもの |
| **主題** | 想いを届けること | **プレイヤーの頭の中**。遊んでいるあいだ、ずっと考えていること |

**前の版では、ここに「花は、想いを届けるための道具です」と書いていました。取り消します。**

花は道具ではありません。**花が入口で、人生があとから来ます。**

### 遊んでいるあいだの問いは、二本あります

```
花 → 人（60%）              人 → 花（40%）

「ガーベラって可愛い」          「あの子、笑うと元気が出る子で」
      ↓                            ↓
「希望、って花言葉なんだ」       「明るい花は、どれだろう」
      ↓                            ↓
「そういえば、あの友達」         「あ、ヒマワリだ」
      ↓                            ↓
「この花にしよう」              「この花にしよう」
```

**前の設計は、右側だけでした。** 左側が、まだ作られていません（→ ⑭1章）。

```
×  どれがいちばん高得点だろう
○  この花、かわいいな。……なんの花だろう      ← 60%の入口
○  この花を受け取る人は、どんな気持ちになるだろう  ← 40%の入口
```

**この二つのどちらかが出ている画面**が、正しい画面です。  
どちらも出ていない画面は、たとえ美しくても失敗です。

## 2. 前の設計にあった、決定的な穴

前回の設計を、この主題で見直したところ、**穴が見つかりました。**

```
お客さまが画面にいる時間

③会話  ████                                    （1分）
④選ぶ       ─────────────────────              （3分半）← いない
⑥⑦束ねる                    ─────────         （2分）  ← いない
⑧渡す                                 ████     （1分半）
```

**プレイヤーがいちばん長く過ごす「選ぶ」「束ねる」の5分半、お客さまが画面にいません。**

そこに映っているのは、花の一覧です。  
つまり、いちばん長い時間、プレイヤーは**「どの花がきれいか」を考えていた**ことになります。

主題に反しています。**ここを直すのが、今回の設計の中心です。**

## 3. 七つの感情 ── これが設計の骨格

画面の順番ではなく、**この順番が先にあります。**

```
ワクワク → 共感 → 悩む → 発見 → 嬉しい → 感動 → 余韻
```

### いただいた言葉に、設計を合わせました

前回、私は少し違う言葉を使っていました。言葉が変わると、設計が変わります。

| 前回 | 今回 | 何が変わるか |
|---|---|---|
| 期待 | **ワクワク** | 静かなだけでは足りない。**少し心が弾む**要素を入れる |
| 迷い | **悩む** | 美しさの比べっこではなく、**その人にとって正しいか**で悩む |
| 達成 | **嬉しい** | 自分の成果への満足ではなく、**相手の喜びの先取り** |

とくに **「迷い」→「悩む」** が大きな違いです。  
「どれもきれいで選べない」は迷い。「この人にはどうだろう」は悩み。  
**このゲームが要るのは、後者です。**

### 感情の高さと、お客さまの居場所

```
  高 │                        ◆発見                ◆感動
     │                       ／  ＼               ／  ＼
     │              ◆悩む  ／     ＼   ◆嬉しい  ／     ＼
  中 │      ◆共感  ／     ＼         ＼／   ＼／         ＼
     │    ／      ＼                  ▽                  ＼
  低 │ ◆ワクワク                    （谷）                ◆余韻
     └──────────────────────────────────────────────────────
       0:30    1:30    3:00   4:00    5:30    7:00        8:00

お客さま  姿なし   目の前   ★手元   ★手元    ★手元   目の前     気配だけ
```

★ = **前回いなかったところ。ここにお客さまを取り戻します。**

**山はふたつだけ。**（発見と感動）  
山を3つ以上作ると、どれも印象に残りません。

## 4. 感情ごとの設計

各項目の見出しは、**プレイヤーの心の中の言葉**です。

---

### 【ワクワク】「今日は、どんな花が入ったんだろう」

| | |
|---|---|
| **誰を考えているか** | **まだ、誰も考えていない。花だけ見ている** |
| **お客さまはどこに** | 姿はない。**でも「来る」ことは分かっている** |
| **強さ** | 弱め。ただし、**平坦にはしない** |

**必要なもの**

「まだ誰も来ていない店」が、**空っぽではなく、待っている状態**に見えること。  
そして、**その時間に花を見られること。**

**見出しを変えました**

```
前   「今日は、どんな人が来るんだろう」
後   「今日は、どんな花が入ったんだろう」
```

一日のはじまりは、**人ではなく花**です。ここが60%の入口です。

**仕掛け**

1. **扉を閉めたまま始める。** 開けるのはプレイヤー。
2. **今朝の市場から、今日の花が届いている。**（→ ⑫9-2章）
   「シャクヤクが入りました」「デルフィニウム、今日だけ」
3. **★開店前に、棚を見る時間を作る。**（→ ⑭1章。今回の追加）

   ```
   市場から帰る → 棚に並べる → ★見て回る → 扉を開ける → お客さまが来る
                                ↑ 目的がない。注文もメモもない
   ```

   **目的がないから、「かわいい」だけで立ち止まれます。**
   ここで開いた花の詳細が、そのまま図鑑に残ります。

4. 窓の外の季節を先に見せる。「今日はこういう日」が分かる。
5. 2日目以降、**前日を1行だけ持ち越す**。
   > 昨日のはるかさん、喜んでくれたでしょうか。
6. **少しだけ弾ませる。** 扉を開ける瞬間に、**ベルの音**と、**光が一段明るくなる**。

**殺すもの**

- 「今日のお客さま: はるかさん」と先に見せること
- **開店前を、飛ばせない時間にすること**（見たい人だけが見る）
- ロゴのアニメーション、音楽の盛り上がり
- 逆に、静かすぎて何も起きないこと

**確かめる問い**: **お客さまが来る前に、花の詳細を開く人がいるか。**  
（これが60%が働いている、いちばんの証拠です）

---

### 【共感】「この人を、笑顔にしたい」

| | |
|---|---|
| **誰を考えているか** | 目の前のお客さま。**そして、その人が想っている誰か** |
| **お客さまはどこに** | 目の前。いちばん近い |
| **強さ** | 中。ここは山にしない |

**必要なもの**

**「渡す相手」が見えること。** ここがこのゲームの、いちばん深いところです。

```
プレイヤー  →  お客さま  →  渡す相手
             （目の前）    （画面にいない三人め）
```

プレイヤーは、**「この人が、あの人を想っている」ことを想います。**  
二重になった想いが、このゲームの手ざわりです。

**仕掛け**

1. **お客さまは、自分の話より、渡す相手の話をする。**
   > ×「明るい花束をください」  
   > ○「あの子、笑うと本当に元気が出る子なんです」

2. **セリフは1行ずつ、0.55秒間隔。** これは「話を聞いている速度」です。

3. **要望を条件表にしない。** 条件表にした瞬間、お客さまは発注書になります。

4. **ひとつだけ、譲れないことを言ってもらう**（→【悩む】で効きます）。
   > 「香りの強すぎないものにできますか」（病室だから）

5. 少し言いよどませる。完璧に説明する人は、現実にいません。

**殺すもの**

- 要望の箇条書き（○○の花／○○円以内／○○な雰囲気）
- 適合度・達成率
- 渡す相手の話が出てこないこと

**確かめる問い**: 遊んだ人が、**渡す相手**のことを覚えているか。  
（お客さまの名前より、こちらのほうが大事です）

---

### 【悩む】「この人には、どれだろう」

| | |
|---|---|
| **誰を考えているか** | 花ではなく、**渡す相手** |
| **お客さまはどこに** | **★手元にいる（今回の追加）** |
| **強さ** | 中。長く続く。ここがいちばん長い時間 |

**必要なもの**

**選んでいるあいだ、お客さまの言葉が手元にあること。**

これが今回いちばん大きな追加です。

#### 追加①：エプロンのメモ ── 条件表ではなく、人柄のメモ

```
画面のすみに、小さな紙の角が見えている。
ふれると、聞いたことが、そのままの言葉で開く。
```

**これは注文票ではありません。人のことを書きとめた紙です。**

```
❌ 条件表                     ⭕ 人柄のメモ

   女性・30代                   「明るく笑う人なんです。」
   2,000円                      「白い花が好きだったみたいで。」
   明るい色                      「病室なので、香りの強くないものを。」
   誕生日
```

**メモに書くこと**

| 書く | 書かない |
|---|---|
| **贈られる人がどんな人か** | 年齢・性別 |
| その人の好きな色・花 | 予算の数字 |
| 渡す場所・場面 | 「明るい／上品」などの分類語 |
| お客さまが言った言葉、そのまま | 要約・箇条書き |

- **主語は「その人」**。つまり、贈られる人が中心です
- **3行まで。** 4行めが要るなら、それは条件表になりかけています
- 予算は書きません。**数字は手もとに、人柄はメモに**（手の帯にすでに出ています）
- **いつでも見られる。でも、こちらからは出さない**
- **どの花が合うかは、絶対に書かない**

これで、選んでいる3分半のあいだ、**贈られる人**が手元に居続けます。

#### 追加②：花の情報そのものが、判断材料になる

花の説明文は、飾りではなく**このゲームの中心情報**です。  
**108種すべて**に、**誰かにとって意味を持つ一言**を必ず入れます（→ ⑭2章）。

さらに、花言葉だけでなく **香り・日もち・相場・水あげ**も判断材料になります（→ ⑭3章）。

```
香り     病室では強すぎる。食卓ではごちそうになる
日もち   金曜に替える人には、次の金曜まで持つ花を
相場     冬のバラは高い。理由を知ると、腹が立たなくなる
水あげ   ガーベラは水を浅く。深水の花と分ける
```

**これは全部、本物の花屋の知識です。**  
遊んでいるうちに花に詳しくなる、というのがこのゲームの武器です。

| 花 | ひとこと | これが効く相手 |
|---|---|---|
| ユリ | 香りが強い花です。渡したあと、部屋にしばらく残ります | 病室へ贈る人は、ここで悩む |
| スターチス | 乾いても色が残ります。飾り終えたあとも、しばらく一緒にいられます | 長く残したい人に効く |
| アルストロメリア | 一本にいくつも花が付くので、少ない本数でも豊かになります | 予算の少ない人に効く |
| ヒマワリ | 花びらが、まだ陽の方を向いたままです | 元気づけたい人に効く |
| チューリップ | あたたかい部屋に置くと、ゆっくり開いていきます | 渡したあとの時間を想像させる |

**「この花はこの人に向いています」とは書きません。**  
書くのは事実だけ。結びつけるのはプレイヤーです。

#### そのほかの仕掛け

- 正面の一輪だけが美しく見える。隣は少しぼける → 「隣も見たい」
- どの花にも必ず「おすすめの用途」がある。**外れの花を作らない**
- 予算は「めやす」であって上限ではない。**超えても叱られない**
  → 悩みが、罰への恐れに変わらない

**殺すもの**

- 適合度・★・「この花は向いていません」
- おすすめの花を光らせること
- お客さまの言葉が、選んでいる間に見返せないこと ← **前回の失敗**

**確かめる問い**: 一度取った花を戻して、別の花を取る人がいるか。  
メモを2回以上開く人がいるか。

### 【発見】「この花が、ぴったりだ」

| | |
|---|---|
| **誰を考えているか** | 渡す相手。**その人の人生** |
| **お客さまはどこに** | **★手元（メモの中の言葉として）** |
| **強さ** | **山①。この日いちばんの高み** |

### ここが、このゲームの心臓です

```
心臓  =  プレイヤーが「この人にぴったりの花を見つけられた」と感じる、この瞬間
```

**セリフではありません。** 以前、私は呼応セリフを心臓と書いていました。訂正します。

| | 役目 |
|---|---|
| **この【発見】の瞬間** | **心臓。** ここが動かなければ、他のすべては飾り |
| 呼応セリフ（⑬） | その感情を、**そっと後押しするもの** |

セリフは、**あとから来ます。** 先に来たら、それは答え合わせになります。

```
プレイヤーが気づく   →   （沈黙）   →   お客さまの一言
     ↑ 心臓                              ↑ 後押し
```

**この順番だけは、絶対に入れ替えません。**

だから⑬のセリフは、印象に残ろうと頑張りません。  
**日常の一言なのに、あとから思い返すと温かい。** それで十分です。

**何が起きているのか**

```
お客さまの言葉（メモの中）  ┐
                         ├→ プレイヤーの中で結ばれる → 「あ」
花言葉（花の詳細）         ┘
```

**結ぶのはプレイヤーです。ゲームは絶対に線を引きません。**

**発見の三条件**

1. 手がかりは、**お客さまの言葉の中にある**（システムのヒントではない）
2. 答えは、**花の側にある**（花言葉・旬・香り・日もち・ひとこと）
3. その二つを結ぶ線を、**ゲームは一度も引かない**

3つ目を破った瞬間、発見は死にます。「おすすめ！」の2文字で終わります。

**そして、発見は逆向きにも起きます**（→ ⑭1章）

```
人 → 花（40%）                    花 → 人（60%）

メモを読む                         花を見る
   ↓ 合う花を探す                    ↓ かわいい、と思う
「あ、ヒマワリだ」                  「希望、って花言葉なんだ」
                                     ↓ 思い出す
                                  「そういえば、あの人」
```

**右のほうが多い**、というのが今回の訂正です。  
右の道では、**プレイヤーは探していません。** 見ていたら、思い出しただけです。

だから花棚は「探す場所」ではなく、**「見て回る場所」**として作ります。  
探させる作りにすると、60%のほうの発見が起きなくなります。

**呼応には、二種類あります**

| 種類 | 手がかり | 気づきやすさ | 例 |
|---|---|---|---|
| **好みの呼応** | 贈られる人の好きな色・花 | やさしい | 「白い花が好きだったみたいで」→ ユリ |
| **花言葉の呼応** | 贈られる人の状況・人柄 | 深い | 「春から家を出るんです」→ スイートピー（門出） |

やさしいほうを入口にして、深いほうへ進めるようにします。  
**どちらも、ゲームは指し示しません。**

**呼応表**（呼応する花。文面は ⑬セリフ集にあります）

| お客さま | 言葉の中の手がかり | 呼応する花 | 花言葉 |
|---|---|---|---|
| はるか（同僚の誕生日） | 「笑うと本当に元気が出る子」 | ヒマワリ | 憧れ・あなただけを見つめる |
| なおき（恩師の退官） | 「四年間、ずっと見守ってくださった」 | トルコキキョウ | **感謝** |
| さとみ（毎週の食卓） | 「長もちして」「次の金曜まで」 | アルストロメリア | **持続** |
| よしこ（孫の発表会） | 「あの子、緊張しいなものですから」 | ラナンキュラス | **晴れやかな魅力** |
| めい（春から家を出る） | 「春から家を出るので、その前に」 | スイートピー | **門出** |
| りん（自分のための花） | 「あると一日が違うんです」 | ユーカリ | **再生** |
| かおる（新居） | 「家族みんなで見られるような」 | アジサイ | **家族団らん** |
| そうた（入院中の親友） | 「元気が出るものがいいな」 | ガーベラ | **希望** |

> 呼応セリフの文面は **⑬セリフ集（13-lines.md）** にまとめました。
> ここは一緒に調整する場所です。
>
> **セリフは書き直しました。** 説明っぽさを削り、人ごとに話す速さを変えています。
> セリフは心臓ではないので、**うまいことを言わせません。**

**発見の瞬間に、音を鳴らさない**

効果音を鳴らすと、**気づいたのはシステム**になります。  
気づいたのはプレイヤーです。だから**沈黙**にします。

**気づかなかった人を、損させない**

- 呼応花が入っていなくても、笑顔も感想も同じように返ります
- 呼応セリフが出ないだけ。**「取り逃した」と気づかせません**
- 図鑑で花言葉を読み返せる。**あとから気づく道**を残します
  > 「あ、あのときスイートピーを入れていれば」── この後悔が、次の日を作ります

**確かめる問い**: 花の詳細画面で、3秒以上止まる人がいるか。

---

### 【谷】手を動かす時間 ── ここはあえて上げない

山②（感動）を立てるために、**平らな時間**を作ります。

- 新しい情報を出さない。花言葉も助言も、ここでは見せない
- 音を減らす。ピアノの音数を半分にし、風だけ残す
- 決断を求めない。「整える」を押せば、それなりに整う
- ただし**手で動かせる**。動かした人だけが、あとで「自分が作った」と思える

**ここに演出を足さないこと。** 足すと、次の山が山に見えなくなります。

### 【嬉しい】「これ、きっと喜んでくれる」

| | |
|---|---|
| **誰を考えているか** | **渡す相手の顔** |
| **お客さまはどこに** | **★手元（名前だけがそっと戻ってくる）** |
| **強さ** | 中の上。山②の助走 |

**前回との違い**

前回はここを「達成感」と書いていました。**それは自分に向いた感情**です。  
このゲームに要るのは、**相手に向いた喜び**です。

```
×  いいブーケができた（自分の成果）
○  これ、きっと喜んでくれる（相手の顔）
```

**仕掛け**

1. 包み終わった瞬間、**一拍おく（0.4秒の無音）**。
2. その一拍のあと、束にだけ光が当たる（0.62秒）。
3. **そして、渡す相手の名前だけが、そっと一行出る。**（今回の追加）
   > あの子の誕生日に。  
   > 先生の、退官の日に。  
   > お母さんに。

   **評価ではありません。** 誰のために作ったかを、思い出させるだけです。
   これで「達成感」が「嬉しい」に変わります。

4. 「お渡しする」を押すのはプレイヤー。**自動で進めない。**
5. **点数はまだ出さない。** ここで点をつけたら、感情が自分に向いてしまいます。

**殺すもの**

- 点数・星・「完成度」
- 派手なエフェクト（嬉しさは、静けさの中でこそ立ちます）
- 完成した瞬間に評価を出すこと

**確かめる問い**: 「お渡しする」を押すまでに、間があるか。

---

### 【感動】「喜んでもらえて、良かった」

| | |
|---|---|
| **誰を考えているか** | 目の前のお客さま。**そして、その先にいる人** |
| **お客さまはどこに** | 目の前。いちばん近い |
| **強さ** | **山②。この日の最高点** |

**必要なもの**

お客さまが、**ブーケの話ではなく「これからの話」をすること。**

**仕掛け**

1. **順番を守る。** 花のしるし（笑顔の数）より先に、**言葉**を出す。
   点が先に出ると、その瞬間に「評価画面」になります。

   ```
   受け取る（0.9s） → 一拍（0.4s） → 光が差して笑顔（1.1s）
     → 言葉（1行ずつ） → 花のしるし → 紙（褒める → 助言）
   ```

2. **お客さまは、ブーケを褒めない。渡したあとの未来を話す。**
   > ×「素敵なブーケですね」  
   > ○「これを渡したら、あの子どんな顔するかな。」  
   > ○「今日はいい話ができそうです。」

   ここで**三人め（渡す相手）が、もう一度出てきます。** 物語が閉じます。

3. **褒めるが先、助言は後。** これを逆にしない。

4. 発見していた人には、**呼応セリフが、感想より先に**出る。

   > 文面は **⑬セリフ集（13-lines.md）** にあります。
   > このゲームでいちばん大事な文章なので、そこで一緒に調整します。

5. 笑顔は必ず出る。**言葉の温度だけが3段階**変わります。

**殺すもの**

- 点数発表、比較、ランキング
- 助言を褒め言葉より先に言うこと
- お客さまの反応が毎回同じであること

**確かめる問い**: 遊んだ人が、お客さまのセリフを引用できるか。

### 【余韻】「また明日も、花を選びたい」

| | |
|---|---|
| **誰を考えているか** | 帰っていったお客さまと、**まだ会っていない明日の誰か** |
| **お客さまはどこに** | もういない。**気配だけが残る** |
| **強さ** | 弱い。でも、いちばん長く残る |

**必要なもの**

**終わりきらないこと。** きれいに終わると、そこで満足してしまいます。

**仕掛け**

1. **眺める間。** 紙が出そろって3秒後、UIが1.1秒かけて全部消え、
   **ブーケと笑顔だけが残る**。ふれると戻る。
   → ここでスクリーンショットが撮られます。

2. **自動で次へ進めない。**

3. お客さまが帰ったあと、**店が静かになる1.5秒**。
   カウンターに、**花びらが一枚残っている**。

4. **引き止めない。**
   > ×「明日も来てね！」「ログインボーナス」  
   > ○「また来月、寄らせてもらいますね。」

5. 図鑑に一行だけ増える。数ではなく、**出会った記録**として。

**殺すもの**

- 通知、デイリーボーナス、連続記録
- 「明日は○○が来ます」という予告
- 終了時のまとめ画面

**確かめる問い**: 閉じたあと、**時間をおいて**また開く人がいるか。

### そして、この余韻が判断の基準になります

いただいた5つめの問いは、**この【余韻】をそのまま基準にしたもの**です。

```
□ 遊び終わったあと、優しい気持ちでゲームを閉じられるか
```

**これは、他の4つより上に置くべき問いだと思いました。**

1〜4は「この花屋にあるか」を見ています。5つめだけが、**閉じたあとを見ています。**  
どんなに花屋らしくても、閉じたあとに何かが引っかかるなら、入れません。

| 花屋には実在するが、5つめで落ちるもの |
|---|
| 売れ残り・廃棄 |
| お客さまが少し不満そうにする |
| 「今日はここまで」で切れる中断 |
| 「明日は◯◯さんが来ます」という予告 |

最後の一つは、前から**殺すもの**に入っていました。理由が言葉になりました。  
**予告は、閉じさせてくれないからです。**

## 5. 三人めの人

このゲームには、**画面に一度も出てこない人**がいます。

```
プレイヤー  →  お客さま  →  渡す相手
                          ↑ この人が、いちばん大事
```

- 同僚の誕生日を祝いたい、あの子
- 来月ピアノの発表会がある、お孫さん
- 春から家を出る娘を送り出す、お母さん
- 病室にいて、もうすぐ退院する親友

**この人たちは、絶対に画面に出しません。**  
出さないからこそ、プレイヤーが想像します。**想像したものは、忘れません。**

### 三人めを扱う3つの決めごと

1. **お客さまは、自分より、渡す相手のことを多く話す。**
2. **完成の瞬間に、渡す相手の名前だけをそっと出す。**
3. **受け取った瞬間、お客さまは渡す相手の顔を想像する。**（物語が閉じる）

## 6. 感情から導かれた、5つの変更

この感情設計を骨格に置いた結果、**前回の空間設計（①②）を次のように直します。**  
承認をいただいてから直します。

| # | 変更 | どの感情のためか | 割合 |
|---|---|---|---|
| 1 | **エプロンのメモを追加**（④⑤⑥⑦で常に手元にある） | 悩む・発見 | 人生40% |
| 2 | **花の情報そのものを判断材料にする**（108種すべて） | 悩む | **花60%** |
| 3 | **お客さまに「ひとつだけ譲れないこと」を言ってもらう** | 共感・悩む | 人生40% |
| 4 | **完成の瞬間に、渡す相手の名前を一行出す** | 嬉しい | 人生40% |
| 5 | **扉を開ける瞬間に、ベルと光を一段** | ワクワク | — |
| **6** | **★開店前に、棚を見るだけの時間を作る** | **ワクワク・発見** | **花60%** |
| **7** | **★図鑑を本体に上げる。図鑑から一輪の画面へ入れる** | **発見・余韻** | **花60%** |
| **8** | **★花棚を「探す場所」から「見て回る場所」に** | **悩む・発見** | **花60%** |

★ = **今回の追加。** 前の5つは、7つのうち4つが「人生40%」側でした。  
**花60%側の仕掛けが足りていませんでした。** 6〜8で埋めます（→ ⑭）。

6と7以外は**画面を増やしません。** 既にある画面に、仕掛けを足すだけです。

### カメラ設計は、どうなるか

**残します。ただし、順位を下げます。**

カメラは「感情を運ぶための道具」です。目的ではありません。  
たとえば ④→⑤ でカメラが寄るのは、**寄ると悩みが深くなるから**であって、
カメラを動かしたいからではありません。

```
⑭ 花（60%）    ＋    人生（40%）      ← 二つで、このゲームの中身
        ＼            ／
          ⓪ 感情（この二つが出会う瞬間）  ← ここから設計する
              ↓ そのために
           体験（何を考えながら過ごすか）
              ↓ そのために
        ①② 空間・カメラ（どこで、どう見せるか）
              ↓ そのために
        ③〜⑧ UIの決めごと
```

## 8. 長い時間の感情

| 時期 | 起きること | 感情 |
|---|---|---|
| 1日目 | 初めての店、初めてのお客さま | 驚き |
| 3日目ごろ | **常連さん**が、リズム通りに戻ってくる | **「あ、この人また来た」** |
| 5日目 | 窓の外が変わる | **「もう季節が変わったのか」** |
| 12日目ごろ | 図鑑が半分埋まる | 集める楽しみ |
| 30日目ごろ | 常連12人の**変化の二段目**が始まる | 愛着 |
| 60日目ごろ | アルバムを見返して、**顔を思い出せない人**が出てくる | **「この人、どんな人だっけ」** |
| 一年 | 去年の同じ季節のページが開ける | **「去年の春は、この人だった」** |

**60日目の行が大事です。** 忘れてしまうくらい多くの人に会える、ということです。  
だから一期一会は100人以上にします。**思い出せないことが、豊かさになります。**

> 面白さは、花の数ではなく、**人生の数**です。

### 提案：再訪したお客さまが、前回に触れる

> 「この前いただいた花、母がまだ飾ってくれてます」

**三人め（渡す相手）のその後**が聞ける、唯一の場所になります。  
点数は覚えません。覚えるのは「どんな束だったか」だけ。

これが入ると、お客さまが「機能」から「知り合い」に変わります。

## 9. 確かめ方

点数では測れません。遊んでもらって、これを見ます。

| 見るもの | 何が分かるか |
|---|---|
| **お客さまが来る前に、花の詳細を開いたか** | **花60%が働いた**（いちばん大事） |
| **注文と関係のない花のページを見たか** | 花そのものを好きになりかけている |
| **図鑑を、用がないのに開いたか** | 武器が効いている |
| メモを2回以上開いたか | **悩む**が起きた |
| 一度取った花を戻して、別の花を取ったか | **悩む**が深い |
| 花の詳細で3秒以上止まったか | **発見**が起きかけた |
| 「お渡しする」を押すまでに間があったか | **嬉しい**がある |
| 眺める間に画面を撮ったか | **感動**がある |
| **渡す相手のことを覚えているか** | **共感**があった（いちばん大事） |
| 時間をおいて、また開いたか | **余韻**がある |

遊んだ人に聞く質問は、「面白かったですか」ではなく、

> **「どの花を選びましたか。それは、どうしてですか」**

こう返ってきたら、成立しています。

```
「あの人が○○って言っていたから」          ← 人生40%が働いた
「この花がかわいくて、花言葉を見たら…」      ← 花60%が働いた
```

### そして、このゲームの最後の問い

```
×   面白かったですか？

○   好きな花は、できましたか？
```

**これが、このゲーム全体のゴールです。**

「ヒマワリ」と名前が返ってきたら、それで成功です。  
点数でも、遊んだ時間でも、集めた数でもありません。

**図鑑の♡お気に入り**は、この問いにプレイヤー自身が答える場所です（→ ⑭3-2章）。  
だから、そこにご褒美を付けません。**答えを買収してはいけない**からです。
