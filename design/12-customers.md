# ⑫ お客さま設計書 ── どんな人と出会える花屋か

このゲームの主役は、花だけではありません。**人それぞれの想い**です。  
この文書は「どんな機能を作るか」ではなく、**「どんな人と出会える花屋なのか」**を決めます。

---

## 1. このゲームのジャンル

> **心を贈るシミュレーションゲーム**

プレイヤーがするのは、ブーケを作ることではありません。  
**花屋で、誰かの想いを預かること**です。

```
お客さまが、想いを持って店に来る
        ↓
その想いを、いったん預かる      ← ここがこのゲーム
        ↓
花という形にして、返す
        ↓
その想いが、渡す相手のところへ行く
```

---

## 2. 扱うテーマと、扱わないテーマ

このゲームは **「癒し」と「優しさ」**の作品です。  
切なさはあっても、**最後は必ずあたたかい気持ちで終わる**世界にします。

### 扱うテーマ ── 「誰かを想う気持ち」

| 節目 | 暮らし |
|---|---|
| 卒業・入学・進学 | 毎週の食卓の花 |
| 就職・転職・異動 | 自分のための一輪 |
| 結婚・出産 | お店に飾る花 |
| 退職祝い・昇進 | 季節を感じたくて |
| 誕生日・記念日 | 部屋の模様替え |
| 母の日・父の日・敬老の日 | 来客のもてなし |
| 発表会・コンクール | なんとなく、いい日だから |
| 引っ越し・新居 | |
| お見舞い・快気祝い | |
| 仲直り・再会・お礼 | |

### 扱わないテーマ

```
月命日   お墓参り   葬儀   亡くなった家族   離婚   事故   病気の悪化
```

**死と、強い喪失感を直接あつかいません。**

理由: 遊び終わったときに残ってほしいのは「あたたかさ」だからです。  
重いテーマは、それ自体は尊いものですが、このゲームの器には合いません。

### 切なさの、扱いかた

切なさを消すわけではありません。**切なさは、あたたかさの入口として使います。**

| 使ってよい切なさ | 使わない切なさ |
|---|---|
| 春から家を出る娘を送り出す | 二度と会えない人を想う |
| 転勤する同僚との別れ | 別れたきり、連絡が取れない |
| 入院している親友のお見舞い | 治らない病気 |
| 遠くへ引っ越す友人 | いなくなってしまった人 |

**見分け方**: その人と、**また会える**か。会えるなら扱います。

## 3. 二種類のお客さま

```
一期一会のお客さま  ──  人生の節目を持ってくる（多数）
常連のお客さま      ──  暮らしの繰り返しを持ってくる（少数）
```

**この分け方には、理由があります。**

人生の節目（卒業、結婚、出産）は、**一度しか起きません**。だから一期一会。  
暮らし（毎週の食卓、自分のための一輪）は、**繰り返します**。だから常連。

無理に設定したものではなく、**現実の花屋がそうなっている**からこの形にします。

| | 一期一会 | 常連 |
|---|---|---|
| 人数 | **多数**（30人以上・増やせる） | **少数**（6人） |
| 来る理由 | 人生の節目 | 暮らしのリズム |
| 来る頻度 | 一度きり（例外あり） | 毎週・隔週・月に一度・季節ごと |
| プレイヤーの気持ち | **「今日はどんな人だろう」** | **「あ、この人また来た」** |
| 出る割合 | 3日のうち2日 | 3日のうち1日 |

### 一期一会でも、もう一度だけ会える例外

**その節目に、続きがあるとき**だけ、二度目があります。

| 一度目 | 二度目 |
|---|---|
| 卒業のお祝い | 入学のお祝い |
| お見舞い | **快気祝い**（「あいつ、退院したんです」） |
| 引っ越しの報告 | 新居に落ち着いてから |
| 就職が決まった | 一年たって、はじめての後輩に |

**お見舞い → 快気祝い**は、このゲームの世界観をいちばんよく表す一組です。  
心配して花を買った人が、笑って戻ってくる。**切なさが、あたたかさに変わる**見本にします。

## 4. 常連さん（6人）

常連は**曜日と季節のリズム**で来ます。ランダムではありません。  
だから「あ、金曜だから、さとみさんの日だ」と分かるようになります。

| id | 名前 | 年ごろ | 暮らし | リズム | 買う理由 |
|---|---|---|---|---|---|
| `regular-01` | さとみさん | 40代 | 家族の世話を焼くのが好きな母 | **毎週金曜** | 食卓の花 |
| `regular-02` | りんさん | 30代 | ひとり暮らし | **隔週** | 自分のための一輪 |
| `regular-03` | あおいさん | 20代 | 隣の通りでカフェを営む | **毎週火曜** | 店のカウンターに |
| `regular-04` | よしこさん | 70代 | 和の趣味がある。孫がいる | **月に一度** | 孫の行事、季節の花 |
| `regular-05` | はるかさん | 20代 | よく笑う会社員。贈りもの上手 | **月に一度** | 誰かの誕生日 |
| `regular-06` | たけしさん | 60代 | 定年後。妻と二人暮らし | **月に一度** | 理由もなく、妻に |

### たけしさんについて

新しく加えたい常連です。**理由のない花**を買う人を、一人置きたいと考えました。

> 「いや、何の日でもないんですけどね。  
> 　……たまには、いいかと思って。」

節目でも記念日でもなく買う人がいると、**花のある暮らし**そのものが描けます。
このゲームがいちばん最後に伝えたいことを、この人が背負います。

### よしこさんの変更

前の設計では「月命日に白い花を買う人」でしたが、**方針にあわせて差し替えます。**

```
前   月命日。亡くなった連れ合いのために、白い花
後   月に一度。孫の行事や、季節の花を楽しみに
```

70代の女性・和の趣味・静かな色を好む、という**人物像はそのまま残します。**  
変えるのは、来る理由だけです。

> 「孫がね、来月ピアノの発表会なんです。  
> 　あの子、緊張しいなものですから。」

### 常連さんが、少しずつ変わる

**同じ人が、まったく同じことを言い続けると、置き物になります。**  
かといって大きく変わると、安心して帰ってこられる場所でなくなります。

そこで、**変化は一言だけ**にします。3段階まで。

| 常連 | 1〜3回目 | 4〜7回目 | 8回目〜 |
|---|---|---|---|
| さとみ | 食卓の花を買いに | 「子どもが花の名前を覚えてきて」 | 「上の子が、自分で選びたいと」 |
| りん | 自分のための一輪 | 「机の上、あれから空けてるんです」 | 「花瓶、もうひとつ買いました」 |
| あおい | 店に飾る花 | 「お客さんに花の名前を聞かれて」 | 「うちの店、花がある店って言われます」 |
| よしこ | 孫の行事に | 「孫が、押し花を作ったんですよ」 | 「あの子、花屋さんになりたいって」 |
| はるか | 誰かの誕生日に | 「私、贈りもの上手って言われて」 | 「今度は自分にも買ってみようかな」 |
| たけし | 理由もなく、妻に | 「妻が、花瓶を出しっぱなしにしてて」 | 「今度は一緒に来ようかと」 |

**どれも、良い方向にしか動きません。** 悪くなる変化は作りません。

## 5. 一期一会のお客さま

### 名簿の作り方

節目ごとに用意します。**同じ節目でも、人が違えば話が変わります。**

| 節目 | 人数のめやす | 例 |
|---|---|---|
| 卒業・入学・進学 | 4人 | 家を出る高校生／教え子を送る先生／孫の入学に来た祖父 |
| 就職・転職・異動 | 3人 | 初出社の朝に／送る側の同僚／単身赴任へ発つ人 |
| 結婚・出産 | 4人 | 友人の結婚式／自分の入籍の日／生まれた姪へ |
| 退職祝い・昇進 | 3人 | 恩師の退官／定年の父へ／同期の昇進 |
| 誕生日・記念日 | 5人 | 同僚へ／恋人へ／自分の誕生日に |
| 母の日・父の日・敬老の日 | 4人 | 高校生／息子から／孫から |
| 発表会・コンクール | 3人 | ピアノ／バレエ／はじめての舞台 |
| 引っ越し・新居 | 3人 | 新居祝い／送り出す隣人／自分の新しい部屋へ |
| お見舞い・快気祝い | 3人 | 親友のお見舞い／退院の日／付き添う家族 |
| 仲直り・再会・お礼 | 4人 | けんかした友人へ／十年ぶりの再会／助けてもらったお礼 |
| **合計** | **36人** | ここから増やしていけます |

### 一人ぶんに必要なもの

**多く作れることより、一人ひとりが本物であることを優先します。**

```
名前・年ごろ・人物像       （どんな人か）
来店のようす              （1行）
暮らしが見える一行         （その人の人生）
セリフ 3行                （渡す相手の話を含む）
ひとつだけ譲れないこと      （1行）
渡す相手                  （誰に）
予算・色・雰囲気の希望
呼応する花（1〜2種）と、呼応セリフ
受け取ったときの言葉 ×3段階
帰りぎわの一言
```

**この13項目がそろわない人は、名簿に入れません。**  
数を増やすために薄い人を作ると、一人ひとりの重みが下がります。

### 一期一会の人こそ、濃く書く

一度しか会えないからこそ、**その一度が濃くないと、ただの通行人**になります。

> ×「友人の結婚式に持っていく花束をお願いします」  
> ○「明日、友だちが結婚するんです。  
> 　 高校のとき、私が泣いてるのを黙って隣にいてくれた子で。  
> 　 ……なんて言えばいいか、まだ決まってないんですけど」

## 6. 誰が来るかの決め方

```
毎日、こう決まります

  ① 今日が常連さんのリズムに当たるか
       当たる → その常連さんが来る（3日に1日くらい）
       当たらない → ②へ

  ② 今の季節に合う「節目」を選ぶ
       春 = 卒業・入学・就職・引っ越し
       夏 = 発表会・お見舞い・暑中見舞い
       秋 = 結婚・敬老の日・実りの報告
       冬 = 出産・年末のお礼・仲直り

  ③ その節目の中から、まだ会っていない人を選ぶ
       全員に会っていたら、二度目のある人（快気祝いなど）を選ぶ
```

**季節と節目が合っていること**が大事です。  
桜が見える窓の向こうで、卒業の花を包む。それだけで物語になります。

## 7. 一期一会の人を、忘れないために

**お客さまを増やすなら、その人たちが残る場所が要ります。**  
一度会って消えるだけなら、人が「使い捨て」になってしまいます。

### 提案：図鑑を「店の記録帳」に広げる

いまの図鑑は花のページだけです。ここに**お客さまのページ**を足します。

```
店の記録帳
 ├ 花のページ      21種の花言葉（いまの図鑑）
 └ お客さまのページ  会った人／渡した束／その人が言ったこと
```

**お客さまのページに書くこと**

```
┌────────────────────────────┐
│  はるかさん      春・3日目       │
│                              │
│  同僚の誕生日に                │
│  「あの子、笑うと本当に          │
│   元気が出る子なんです」         │  ← その人の言葉を、そのまま
│                              │
│      🌻🌼🌸  （渡した束）        │  ← 小さく、そのときの束
│                              │
│  「これを渡したら、あの子         │
│   どんな顔するかな」            │  ← 受け取ったときの言葉
└────────────────────────────┘
```

**点数は書きません。** 書くのは、その人の言葉と、渡した束だけです。

これがあると、

- 一期一会の人が、**会ったあとも残る**
- **「どんな人と出会える花屋か」**が、遊んだ人にも見える
- 常連さんのページは、**来るたびに行が増える**（関係が育つ）

### 記録帳は、花屋にあるか

あります。**顧客ノート**は、実際の花屋にあるものです。  
「あのお客さまは白が好き」「去年は何を包んだか」を書きつけておくノート。

## 8. 常連さんが、前回に触れる

常連さんは、**前に渡した束を覚えています。**

> 「この前いただいた花、まだ咲いてますよ」  
> 「先週の、子どもが名前を覚えたみたいで」  
> 「あの黄色いの、母がとても喜んでました」

### 覚えておくこと

```
覚える     どんな束だったか（明るい／静か／ナチュラル／上品）
          いちばん多かった花の名前
          季節

覚えない   点数
          評価
          何本入っていたか
```

**点数を覚えると、通信簿になります。** 覚えるのは印象だけにします。

### 触れかたの決めごと

- **一言だけ。** 2行以上にしない
- **評価しない。**「良かった」「もっとこうすれば」を言わない
- **その後の話をする。** 花がどうなったか、渡した相手がどうしたか
- 前回が何であれ、**必ずあたたかい**

## 9. 新しいものを入れるときの、4つの問い

これから何かを足したくなったら、**必ずこの4つに答えます。**  
ひとつでも「いいえ」なら、採用しません。

```
□ 1. 本当にこの花屋に、自然に存在するものか
□ 2. お客さまとの関係が、深まるか
□ 3. プレイヤーが、渡す相手を想像できるか
□ 4. 花そのものを、もっと好きになれるか
```

**「ゲームとして面白いか」は、判断の基準にしません。**

### いままでの案を、この4つで見直しました

| 案 | 1 花屋にある | 2 関係が深まる | 3 相手を想像 | 4 花を好きに | 判定 |
|---|---|---|---|---|---|
| エプロンのメモ | ○ エプロンにメモは実在する | ○ | ○ | △ | **採用** |
| 花のひとことに判断材料 | ○ 花屋は必ず教えてくれる | ○ | ○ | ◎ | **採用** |
| 完成時に渡す相手の名前 | ○ 心の中で思う | ○ | ◎ | △ | **採用** |
| 眺める間 | ○ 包んだ花を眺める時間はある | △ | ○ | ◎ | **採用** |
| 呼応セリフ | ○ | ◎ | ◎ | ◎ | **採用** |
| 店の記録帳（お客さまのページ） | ○ 顧客ノートは実在する | ◎ | ○ | ○ | **採用** |
| 常連さんのリズム（曜日） | ◎ 花屋の常連は曜日で来る | ◎ | ○ | △ | **採用** |
| ~~ブーケの得点表示~~ | × 花屋に点数はない | × | × | × | **不採用** |
| ~~花の育成・温室~~ | △ 花屋は花を育てない（仕入れる） | × | × | △ | **保留** |
| ~~お客さまの好感度ゲージ~~ | × | × | × | × | **不採用** |

**温室について**: 素材は用意しましたが、この4つを通すと弱いことが分かりました。
「花屋は花を育てるのではなく、市場から仕入れる」からです。  
入れるなら**「今朝の市場で、何が入ってきたか」**のほうが花屋らしくなります。

## 10. 名簿を増やすときの手順

```
1. 節目を決める（②の表から）
2. 渡す相手を決める        ← ここから先に決める
3. その人の暮らしを1行で書く
4. セリフ3行を書く（渡す相手の話を必ず入れる）
5. ひとつだけ譲れないことを決める
6. 呼応する花を1〜2種と、呼応セリフを書く
7. 4つの問いで確かめる
```

**2番目が大事です。** 買う人ではなく、**もらう人から**決めます。  
もらう人が見えていないお客さまは、薄くなります。
