# ⑫ お客さま設計書 ── どんな人と出会える花屋か

このゲームの主役は、花だけではありません。**人それぞれの想い**です。  
この文書は「どんな機能を作るか」ではなく、**「どんな人と出会える花屋なのか」**を決めます。

---

## 1. このゲームのジャンル

> **心を贈るシミュレーションゲーム**
>
> **「花を知り、花を好きになり、その花で誰かの想いを届けるゲーム」**

```
花    60%   ← 主役であり、入口（→ ⑭花の設計書）
人生  40%   ← この文書が受け持つところ
```

**この文書は、40%のほうです。** 60%のほうが上にあることを、忘れないようにします。  
お客さまの物語が、花の話を上回ってはいけません。

プレイヤーは、**二人のことを同時に想います。**

```
プレイヤー  →  お客さま  →  贈られる人
                （目の前）    （画面に出てこない）
```

**お客さまだけに寄りすぎないこと。**  
お客さまは想いを預けに来た人で、想いの行き先はその先にいます。

```
想いが生まれる（お客さまの中）
        ↓
想いを預かる            ← ここがこのゲーム
        ↓
花という形にする
        ↓
想いが届く（贈られる人へ）
```

## 2. 扱うテーマと、扱わないテーマ

このゲームは **「癒し」と「優しさ」**の作品です。  
切なさはあっても、**最後は必ずあたたかい気持ちで終わる**世界にします。

### 扱うテーマ ── 「誰かを想う気持ち」

| 節目 | 暮らし |
|---|---|
| 卒業・入学・進学 | 毎週の食卓の花 |
| 就職・転職・異動 | 自分のための一輪 |
| 結婚・出産 | お店に飾る花 |
| 退職祝い・昇進 | 季節を感じたくて |
| 誕生日・記念日 | 部屋の模様替え |
| 母の日・父の日・敬老の日 | 来客のもてなし |
| 発表会・コンクール | なんとなく、いい日だから |
| 引っ越し・新居 | |
| お見舞い・快気祝い | |
| 仲直り・再会・お礼 | |

### 扱わないテーマ

```
月命日   お墓参り   葬儀   亡くなった家族   離婚   事故   病気の悪化
```

**死と、強い喪失感を直接あつかいません。**

理由: 遊び終わったときに残ってほしいのは「あたたかさ」だからです。  
重いテーマは、それ自体は尊いものですが、このゲームの器には合いません。

### 切なさの、扱いかた

切なさを消すわけではありません。**切なさは、あたたかさの入口として使います。**

| 使ってよい切なさ | 使わない切なさ |
|---|---|
| 春から家を出る娘を送り出す | 二度と会えない人を想う |
| 転勤する同僚との別れ | 別れたきり、連絡が取れない |
| 入院している親友のお見舞い | 治らない病気 |
| 遠くへ引っ越す友人 | いなくなってしまった人 |

**見分け方**: その人と、**また会える**か。会えるなら扱います。

## 3. 二種類のお客さま

```
一期一会のお客さま  ──  人生の節目を持ってくる（多数）
常連のお客さま      ──  暮らしの繰り返しを持ってくる（少数）
```

**この分け方には、理由があります。**

人生の節目（卒業、結婚、出産）は、**一度しか起きません**。だから一期一会。  
暮らし（毎週の食卓、自分のための一輪）は、**繰り返します**。だから常連。

無理に設定したものではなく、**現実の花屋がそうなっている**からこの形にします。

| | 一期一会 | 常連 |
|---|---|---|
| 人数 | **100人以上**（上限なし。あとから足せる） | **10〜15人**（ここは増やさない） |
| 来る理由 | 人生の節目 | 暮らしのリズム |
| 来る頻度 | 一度きり（例外あり） | 毎週・隔週・月に一度・季節ごと |
| プレイヤーの気持ち | **「今日はどんな人だろう」** | **「あ、この人また来た」** |
| 出る割合 | 3日のうち2日 | 3日のうち1日 |

### なぜ、この人数なのか

> **面白さは、花の数ではなく、人生の数です。**

一期一会は**いくらでも足せる作り**にします。季節ごと、行事ごとに増やしていける器を
先に用意しておきます。100人はあくまで**出発点**で、上限ではありません。

常連は逆です。**10〜15人で止めます。**  
覚えていられる人数を超えると、常連が常連でなくなるからです。
「あ、金曜だ」と思える人は、顔と暮らしを覚えている人だけです。

```
一期一会  ──  増やすほど、世界が広くなる     → 上限なし
常連      ──  増やすほど、一人が薄くなる     → 10〜15人で止める
```

### 一期一会でも、もう一度だけ会える例外

**その節目に、続きがあるとき**だけ、二度目があります。

| 一度目 | 二度目 |
|---|---|
| 卒業のお祝い | 入学のお祝い |
| お見舞い | **快気祝い**（「あいつ、退院したんです」） |
| 引っ越しの報告 | 新居に落ち着いてから |
| 就職が決まった | 一年たって、はじめての後輩に |

**お見舞い → 快気祝い**は、このゲームの世界観をいちばんよく表す一組です。  
心配して花を買った人が、笑って戻ってくる。**切なさが、あたたかさに変わる**見本にします。

## 4. 常連さん（12人）

常連は**曜日と季節のリズム**で来ます。ランダムではありません。  
だから「あ、金曜だから、さとみさんの日だ」と分かるようになります。

**12人のうち、9人が「暮らしの中の花」を買う人**です。  
節目のために来る人（はるかさん、よしこさん）は、常連の中では少数派にしました。

| id | 名前 | 年ごろ | 暮らし | リズム | 買う理由 | 話す速さ |
|---|---|---|---|---|---|---|
| `regular-01` | さとみさん | 40代 | 家族の世話を焼くのが好きな母 | **毎週金曜** | 食卓の花 | 実際的 |
| `regular-02` | りんさん | 30代 | ひとり暮らし | **隔週** | 自分のための一輪 | ひとりごと |
| `regular-03` | あおいさん | 20代 | 隣の通りでカフェを営む | **毎週火曜** | 店のカウンターに | 明るい |
| `regular-04` | よしこさん | 70代 | 和の趣味がある。孫がいる | **月に一度** | 孫の行事、季節の花 | おっとり |
| `regular-05` | はるかさん | 20代 | よく笑う会社員。贈りもの上手 | **月に一度** | 誰かの誕生日 | 明るい |
| `regular-06` | たけしさん | 60代 | 定年後。妻と二人暮らし | **月に一度** | 理由もなく、妻に | 年配 |
| `regular-07` | のぶさん | 70代 | 早起き。散歩の帰りに寄る | **毎週日曜** | **一輪だけ** | 年配 |
| `regular-08` | ふみえさん | 60代 | 家をきれいにしておきたい人 | **毎週木曜** | **玄関に飾る** | おっとり |

### たけしさんについて

**理由のない花**を買う人です。

> 「いや、何の日でもないんですけどね。  
> 　……たまには、いいかと思って。」

節目でも記念日でもなく買う人がいると、**花のある暮らし**そのものが描けます。
このゲームがいちばん最後に伝えたいことを、この人が背負います。

### 「暮らしの中の花」を、もっと

たけしさんと同じ役目の人を、6人ふやしました。**この6人には節目がありません。**  
花を買う理由が「そういう暮らしだから」だけの人たちです。

| 人 | その人の一言 |
|---|---|
| **のぶさん**（毎週日曜・一輪だけ） | 「一本でいいんです。……日曜だけね、そう決めてまして」 |
| **ふみえさん**（毎週木曜・玄関） | 「玄関にあると、帰ってきたときに、ねぇ」 |
| **けんたさん**（隔週水曜・棚に） | 「そろそろ棚のが終わるので。今なら何ですか」 |
| **ゆうこさん**（隔週土曜・ピアノ教室） | 「土曜は生徒が来るので。子どもが見るものですから」 |
| **あきらさん**（月に一度・単身赴任先） | 「殺風景なんですよ、あの部屋。ひとつあるだけで違うので」 |
| **みおさん**（季節ごと・母と二人の食卓） | 「バイト代、入ったので。……母、こういうの好きなんです」 |

**のぶさんの「一輪だけ」は、このゲームで唯一、束を作らない日**になります。  
選ぶ花は1本。包むのも、紙一枚。**それでも、いちばん時間をかけて選ぶ日**にしたい。

> ブーケを作らない日があることで、
> このゲームが「ブーケを作るゲーム」ではないと、遊びながら分かります。

### よしこさんの変更

前の設計では「月命日に白い花を買う人」でしたが、**方針にあわせて差し替えます。**

```
前   月命日。亡くなった連れ合いのために、白い花
後   月に一度。孫の行事や、季節の花を楽しみに
```

70代の女性・和の趣味・静かな色を好む、という**人物像はそのまま残します。**  
変えるのは、来る理由だけです。

> 「孫がね、来月ピアノの発表会なんです。  
> 　あの子、緊張しいなものですから。」

### 常連さんが、少しずつ変わる

**同じ人が、まったく同じことを言い続けると、置き物になります。**  
かといって大きく変わると、安心して帰ってこられる場所でなくなります。

そこで、**変化は一言だけ**にします。3段階まで。

| 常連 | 1〜3回目 | 4〜7回目 | 8回目〜 |
|---|---|---|---|
| さとみ | 食卓の花を買いに | 「子どもが花の名前を覚えてきて」 | 「上の子が、自分で選びたいと」 |
| りん | 自分のための一輪 | 「机の上、あれから空けてるんです」 | 「花瓶、もうひとつ買いました」 |
| あおい | 店に飾る花 | 「お客さんに花の名前を聞かれて」 | 「うちの店、花がある店って言われます」 |
| よしこ | 孫の行事に | 「孫が、押し花を作ったんですよ」 | 「あの子、花屋さんになりたいって」 |
| はるか | 誰かの誕生日に | 「私、贈りもの上手って言われて」 | 「今度は自分にも買ってみようかな」 |
| たけし | 理由もなく、妻に | 「妻が、花瓶を出しっぱなしにしてて」 | 「今度は一緒に来ようかと」 |
| のぶ | 日曜に一輪だけ | 「先週のが、まだ元気でしてね」 | 「二本にしてみようかな。……いや、一本で」 |
| ふみえ | 玄関に飾る花を | 「お隣が、いい香りねって」 | 「玄関、明るくなったって言われまして」 |
| けんた | 棚に、季節の花 | 「妻がこれ何て花って聞くので、覚えました」 | 「今日は妻に頼まれて来ました」 |
| ゆうこ | 教室の玄関に | 「生徒が、これ知ってるって」 | 「発表会にも飾ろうかと思って」 |
| あきら | 単身赴任先の部屋に | 「水を替えるのが、日課になりました」 | 「来月、こっちに家族が来るんです」 |
| みお | 母と二人の食卓に | 「母が、写真撮ってました」 | 「今度は自分で選んでいいって言われて」 |

**どれも、良い方向にしか動きません。** 悪くなる変化は作りません。

**のぶさんだけ、ほとんど変わりません。** 8回目の「……いや、一本で」まで、  
ずっと一輪です。**変わらないことが、この人の変化**です。

## 5. 一期一会のお客さま

### 名簿の作り方

節目ごとに用意します。**同じ節目でも、人が違えば話が変わります。**

前の版は36人でした。**少なすぎました。** 一年ぶんも持ちません。  
**最初に100人。そのあとも、上限を決めずに足していきます。**

| 節目 | 第一弾 | ゆくゆく | 例 |
|---|---|---|---|
| 卒業・入学・進学 | 12人 | 20人〜 | 家を出る高校生／教え子を送る先生／孫の入学に来た祖父 |
| 就職・転職・異動 | 10人 | 15人〜 | 初出社の朝に／送る側の同僚／単身赴任へ発つ人 |
| 結婚・出産 | 12人 | 20人〜 | 友人の結婚式／自分の入籍の日／生まれた姪へ |
| 退職祝い・昇進 | 8人 | 12人〜 | 恩師の退官／定年の父へ／同期の昇進 |
| 誕生日・記念日 | 14人 | 25人〜 | 同僚へ／恋人へ／自分の誕生日に |
| 母の日・父の日・敬老の日 | 10人 | 15人〜 | 高校生／息子から／孫から |
| 発表会・コンクール | 8人 | 12人〜 | ピアノ／バレエ／はじめての舞台 |
| 引っ越し・新居 | 8人 | 12人〜 | 新居祝い／送り出す隣人／自分の新しい部屋へ |
| お見舞い・快気祝い | 8人 | 12人〜 | 親友のお見舞い／退院の日／付き添う家族 |
| 仲直り・再会・お礼 | 10人 | 15人〜 | けんかした友人へ／十年ぶりの再会／助けてもらったお礼 |
| **合計** | **100人** | **160人〜** | **上限は決めません** |

### 「増やせる作り」を、先に用意する

100人は目標ではなく、**出発点**です。あとから足すときに、
コードを触らずに人だけ増やせる形にしておきます。

```
1人 = 1つのデータのかたまり（17項目）
     ↓
節目のフォルダに置くだけで、名簿に加わる
     ↓
季節・行事の条件に合った日に、その人が来る
```

**あとから足せる単位**

| 単位 | 例 | 増やし方 |
|---|---|---|
| 一人 | 新しいお客さま1人 | 17項目を書いて置く |
| 節目 | 「はじめての一人暮らし」 | 節目を1つ足して、そこに人を入れる |
| 季節の行事 | 母の日／クリスマス／お正月 | その日に来る人だけをまとめる |

> **面白さは、花の数ではなく、人生の数です。**  
> 花が108種、人生が160通り。**掛け合わせた数だけ、選び方があります。**

### 一人ぶんに必要なもの

**多く作れることより、一人ひとりが本物であることを優先します。**

```
名前・年ごろ・人物像         （どんな人か）
話す速さ                    （明るい／おっとり／緊張／年配／実際的／ひとりごと）
来店のようす                （1行）
暮らしが見える一行           （その人の人生）
セリフ 3行                  （贈られる人の話を必ず含む）
ひとつだけ譲れないこと        （1行）

── ここから下が、贈られる人のこと ──
贈られる人（誰に）
その人がどんな人か           （メモに書く1行）
その人の好きな色・花          （あれば。好みの呼応の手がかり）
渡す場所・場面

予算・色・雰囲気の希望
呼応する花（1〜2種）と、呼応セリフ
受け取ったときの言葉 ×3段階
帰りぎわの一言
```

**この17項目がそろわない人は、名簿に入れません。**
**とくに「贈られる人」の4項目が空の人は、絶対に入れません。**  
数を増やすために薄い人を作ると、一人ひとりの重みが下がります。

### 正直に書いておきます

17項目 × 100人は、**書く量としては相当あります。**  
それでも、項目を減らして人数を増やす形にはしません。

```
薄い100人   →  通行人が100人いる店になる
濃い100人   →  100の人生に出会える店になる
```

**先に濃い20人を作り、遊べる形にしてから、80人を足していきます。**  
量を先に埋めると、あとから濃くする作業は、まず起きないからです。

### 一期一会の人こそ、濃く書く

一度しか会えないからこそ、**その一度が濃くないと、ただの通行人**になります。

> ×「友人の結婚式に持っていく花束をお願いします」  
> ○「明日、友だちが結婚するんです。  
> 　 高校のとき、私が泣いてるのを黙って隣にいてくれた子で。  
> 　 ……なんて言えばいいか、まだ決まってないんですけど」

## 6. 誰が来るかの決め方

```
毎朝、こう決まります

  ⓪ 今朝の市場から、今日だけの花が1〜2種届く
       その季節の花＋今日の花 が、今日の棚になる

  ① 今日が「季節の行事」の日か
       母の日・父の日・敬老の日・クリスマス・お正月・七夕
       当たる → その行事の人が来る
       当たらない → ②へ

  ② 今日が常連さんのリズムに当たるか
       金曜 → さとみさん   日曜 → のぶさん   木曜 → ふみえさん
       火曜 → あおいさん   隔週水 → けんたさん   隔週土 → ゆうこさん
       当たる → その常連さんが来る（3日に1日くらい）
       当たらない → ③へ

  ③ 今の季節に合う「節目」を選ぶ
       春 = 卒業・入学・就職・引っ越し
       夏 = 発表会・お見舞い・暑中見舞い
       秋 = 結婚・敬老の日・実りの報告
       冬 = 出産・年末のお礼・仲直り

  ④ その節目の中から、まだ会っていない人を選ぶ
       全員に会っていたら、二度目のある人（快気祝いなど）を選ぶ

  ⑤ 決まった人の「呼応する花」が、今日の棚にあるか確かめる
       なければ、棚に足す        ← 意地悪にしない
```

**⑤が大事です。** 市場で棚が変わっても、**その人にぴったりの花は必ずある**ようにします。  
「今日はない」は悩みを深くするためのもので、詰ませるためのものではありません。

**季節と節目が合っていること**も大事です。  
桜が見える窓の向こうで、卒業の花を包む。それだけで物語になります。

**日付を持つと、①と②が本物になります。**  
「5月の第2日曜だから母の日」「金曜だからさとみさん」が、そのまま書けるからです。

## 7. 一期一会の人を、忘れないために

**お客さまを増やすなら、その人たちが残る場所が要ります。**  
一度会って消えるだけなら、人が「使い捨て」になってしまいます。

### 記録帳ではなく、アルバムにします

**「記録帳」という言葉が、まちがいのもとでした。** 記録には、点数がついてしまいます。  
作るのは**アルバム**です。**あとから見返すためだけ**にあるページ。

```
店のアルバム
 ├ 花のページ      108種の図鑑（→ ⑭花の設計書 3章）  ← このゲームの武器
 └ 人のページ      会った日／その人／贈った相手／花／その人の一言
```

**花のページのほうが、大きな存在です。** 人のページは、そこにぶら下がります。  
花のページからは、その花を選んだ日のことが読めます（両方向につながります）。

### 1人ぶんは、これだけ

```
┌──────────────────────────────────────┐
│                                        │
│   2027.5.12                            │  ← 日付
│   はるかさん   同僚の誕生日              │  ← 誰の、何のため
│                                        │
│         🌻                              │  ← 渡した花
│                                        │
│   「あ、ヒマワリ。あの子っぽいです」       │  ← その人の一言
│                                        │
└──────────────────────────────────────┘
```

**これだけです。** これ以上は足しません。

| 書くこと | 書かないこと |
|---|---|
| 日付 | **点数** |
| お客さまの名前 | **評価・星・ランク** |
| 誰に贈るものだったか | 「よくできました」の類 |
| 渡した花 | 使った本数・金額の合計 |
| そのとき言ってくれた一言 | 何日目に何をしたかの履歴 |

**評価する言葉を、一つも置きません。**  
アルバムは、うまくできたかを確かめる場所ではなく、**思い出す場所**だからです。

### 見返したときに、起きてほしいこと

```
「……あ、この人いたな」
「そうだ、ヒマワリにしたんだった」
「この日、なんで悩んだんだっけ」
```

**点数があると、この3つは起きません。** 数字が先に目に入るからです。

### 日付があるということ

いただいた例（`2027.5.12`）に、**日付**が入っていました。  
これは大きい提案だと思ったので、はっきり書いておきます。

日付を持つと、こうなります。

| できること | 中身 |
|---|---|
| **アルバムが時系列になる** | 「去年の春」「一年前の今日」が言える |
| **常連さんの曜日が本物になる** | 金曜だからさとみさん、日曜だからのぶさん |
| **季節の行事が来る** | 母の日、クリスマス、お正月、七夕 |
| **一年たつ** | 「もう一年ですね」と言える人が出てくる |

いまの設計は「春・3日目」でした。**これを年月日にしたい**と考えています。  
窓の外の季節は、そのまま日付から決まります。

```
いま   春・3日目
案     2027.5.12（金）
```

> ただし、**画面に日付を大きく出しません。** 出すのはアルバムの中だけ。
> 上の帯は、いままでどおり「春・3日目」のような静かな表記のままにします。
> 日付は、あとから見返したときにだけ意味を持てば十分です。

### アルバムは、花屋にあるか

あります。**顧客ノート**は、実際の花屋にあるものです。  
「あのお客さまは白が好き」「去年は何を包んだか」を書きつけておくノート。

そして**点数は書かれていません。** そこまで含めて、実際の花屋のとおりです。

## 8. 常連さんが、前回に触れる

常連さんは、**前に渡した束を覚えています。**

> 「この前いただいた花、まだ咲いてますよ」  
> 「先週の、子どもが名前を覚えたみたいで」  
> 「あの黄色いの、母がとても喜んでました」

### 覚えておくこと

```
覚える     どんな束だったか（明るい／静か／ナチュラル／上品）
          いちばん多かった花の名前
          季節

覚えない   点数
          評価
          何本入っていたか
```

**点数を覚えると、通信簿になります。** 覚えるのは印象だけにします。

### 触れかたの決めごと

- **一言だけ。** 2行以上にしない
- **評価しない。**「良かった」「もっとこうすれば」を言わない
- **その後の話をする。** 花がどうなったか、渡した相手がどうしたか
- 前回が何であれ、**必ずあたたかい**

## 9. 新しいものを入れるときの、5つの問い

これから何かを足したくなったら、**必ずこの5つに答えます。**  
ひとつでも「いいえ」なら、採用しません。

```
□ 1. 本当にこの花屋に、自然に存在するものか
□ 2. お客さまとの関係が、深まるか
□ 3. プレイヤーが、渡す相手を想像できるか
□ 4. 花そのものを、もっと好きになれるか
□ 5. 遊び終わったあと、優しい気持ちでゲームを閉じられるか   ← 追加
```

**「ゲームとして面白いか」は、判断の基準にしません。**

### 5番目について

いただいた基準です。**これは他の4つより上に置くべきものだと思いました。**

1〜4は「花屋らしいか」を見る問いです。  
5番目だけは、**遊んだ人の心に何が残るか**を見ています。

```
1〜4  ──  これは、この花屋にあるか
  5   ──  これは、優しい気持ちのまま終われるか
```

花屋らしくても、閉じたあとに何か引っかかるものは、入れません。  
たとえば「今日は売れませんでした」は、花屋には実際にありますが、**5番で落ちます。**

| 5番で落ちるもの | なぜ |
|---|---|
| 売れ残り・廃棄 | 実在するが、優しい気持ちで閉じられない |
| お客さまが少し不満そう | 「もっとうまくやれたのに」が残る |
| 「今日はここまで」で終わる中断 | 途中で終わった感じが残る |
| 次回予告・「明日は◯◯さんが来ます」 | 閉じさせてくれない |

### いままでの案を、この5つで見直しました

| 案 | 1 花屋にある | 2 関係が深まる | 3 相手を想像 | 4 花を好きに | 5 優しく閉じる | 判定 |
|---|---|---|---|---|---|---|
| エプロンのメモ | ○ エプロンにメモは実在する | ○ | ○ | △ | ○ | **採用** |

| 完成時に渡す相手の名前 | ○ 心の中で思う | ○ | ◎ | △ | ◎ | **採用** |
| 眺める間 | ○ 包んだ花を眺める時間はある | △ | ○ | ◎ | ◎ | **採用** |
| 呼応セリフ | ○ | ◎ | ◎ | ◎ | ◎ | **採用** |
| 店のアルバム（人のページ） | ○ 顧客ノートは実在する | ◎ | ○ | ○ | ◎ | **採用** |
| 常連さんのリズム（曜日） | ◎ 花屋の常連は曜日で来る | ◎ | ○ | △ | ○ | **採用** |

## 9-2. 温室をやめて、市場にします

### 温室は、なくします

前の版では「保留」にしていました。**やめます。**

```
理由   花屋は、花を育てません。市場から仕入れます。
       育てる話を入れると、この店が何の店なのか、ぼやけます。
```

素材（`assets/greenhouse/stage-0〜3.png`）は用意されていますが、**使いません。**

> **⚠ ご確認いただきたいこと**  
> `IMAGE_ASSETS.md` は「変更せずに実装する」と指示をいただいた仕様書です。  
> そのため §7 温室の項は、**こちらでは消していません。**  
> 温室をなくす方針でよければ、あの文書の §7 を削除するか、
> 「（不使用）」と付記するか、どちらにするかご指示ください。

### 代わりに「今日の市場」

朝、市場から帰ってきたところから一日が始まります。

```
┌──────────────────────────┐
│                            │
│   今朝の市場                │
│                            │
│   シャクヤクが入りました      │
│   ヒマワリ、いい顔してます    │
│   デルフィニウム、今日だけ     │
│                            │
└──────────────────────────┘
```

**これは、育成ではありません。** 育てる手間も、待ち時間もありません。  
**「今日、店に何があるか」が日によって違う**というだけの仕掛けです。

| 市場が持ってくるもの | 中身 |
|---|---|
| **今日だけの花** | その季節の棚に、その日だけ1〜2種が加わる |
| **旬の顔** | 同じ花でも「今日のは特にいい」という日がある |
| **選べなさ** | 今日ない花は、今日は選べない |

### 「今日ない」は、意地悪ではないか

いいえ。**これは実際の花屋そのもの**です。そして、良いことが起きます。

```
「これが一番いいと思ったのに、今日はない」
        ↓
「じゃあ、この人には他に何が合うだろう」
        ↓
  もう一度、その人のことを考える      ← ここが、このゲームの心臓
```

**選べる花が毎日同じだと、選ぶ理由が薄くなります。**  
少しだけ変わることで、毎日ちゃんと悩めます。

ただし**5番の問い**を守るため、こうします。

- 「今日ない」を**赤字や警告で出しません。** 棚にないだけです
- 「入荷しませんでした」とは言いません。**あるものだけを並べます**
- 呼応する花は、**必ずその日の棚にあります**（意地悪にしない）

### 市場は、育成になりうるか

いただいたとおり、**育成を入れるなら市場のほうが花屋らしい**です。  
ただ、いまは育成そのものを入れないでおきたいと考えています。

```
入れる    今日、何が入ってきたか（毎朝ちがう）
入れない  仕入れの選択、在庫管理、お金のやりくり
```

**プレイヤーは店員であって、経営者ではありません。**  
数字を管理しはじめた時点で、5番の問いに引っかかります。

## 10. 名簿を増やすときの手順


**2番目が大事です。** 買う人ではなく、**もらう人から**決めます。  
もらう人が見えていないお客さまは、薄くなります。
